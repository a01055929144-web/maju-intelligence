GitHub Personal Access Token(PAT) 권한 안내
=========================================

목적
----
Codex, Claude Code 또는 로컬 터미널에서 GitHub 저장소에 push하기 위한 최소 권한 토큰 발급 기준입니다.

주의
----
1. PAT는 비밀번호와 같습니다.
2. 채팅창, README, .env, 코드 파일, 커밋에 저장하지 않습니다.
3. 가능하면 Claude Code 또는 로컬 터미널에서만 일회성으로 입력합니다.
4. 작업 완료 후 GitHub Settings에서 토큰을 revoke(폐기)하는 것을 권장합니다.


추천 방식: Fine-grained Personal Access Token
---------------------------------------------
GitHub 경로:
Settings
> Developer settings
> Personal access tokens
> Fine-grained tokens
> Generate new token

설정값:
1. Token name
   - 예: maju-intelligence-codex-push

2. Expiration
   - 7일 또는 30일 추천

3. Resource owner
   - a01055929144-web

4. Repository access
   - Only select repositories

5. Selected repositories
   - a01055929144-web/maju-intelligence

6. Repository permissions
   - Contents: Read and write
     필수입니다. 코드 커밋과 push에 필요합니다.

   - Metadata: Read-only
     자동 포함됩니다.

   - Pull requests: Read and write
     PR 생성/수정까지 할 때만 필요합니다.

   - Actions: Read-only
     GitHub Actions/CI 상태 확인이 필요할 때만 권장합니다.

   - Workflows: Read and write
     .github/workflows 파일을 수정해야 할 때만 필요합니다.

7. 불필요한 권한
   - Administration
   - Secrets
   - Deployments
   - Webhooks
   - Delete repository


Classic Token을 사용할 경우
---------------------------
가능하면 Fine-grained token을 추천합니다.
Classic token을 꼭 써야 한다면 아래만 사용합니다.

1. private repository push
   - repo

2. public repository push
   - public_repo

3. GitHub Actions workflow 파일 수정
   - workflow

절대 체크하지 않는 권한:
   - delete_repo


로컬에서 안전하게 사용하는 방법
-------------------------------
방법 1. GitHub CLI 로그인

PowerShell:
gh auth login

안내에 따라 GitHub.com, HTTPS, 토큰 입력을 선택합니다.


방법 2. 현재 터미널 세션에서만 임시 환경변수 사용

PowerShell:
$env:GITHUB_TOKEN="발급한_토큰"
git push

이 방식은 현재 터미널 세션에서만 유지됩니다.
파일에 저장하지 않습니다.


Claude Code 또는 Codex에 전달할 안내문
--------------------------------------
아래 문구를 그대로 전달하면 됩니다.

"GitHub 저장소 push 권한용 PAT를 사용할 예정입니다.

권장 방식:
- fine-grained PAT 사용
- Repository access: Only select repositories
- 대상 저장소: a01055929144-web/maju-intelligence
- Contents: Read and write
- Metadata: Read-only
- Pull requests: PR 생성 시만 Read and write
- Actions: CI 확인 시만 Read-only
- Workflows: .github/workflows 수정 시만 Read and write
- Expiration: 7일 또는 30일

주의:
- 토큰은 코드, .env, README, 커밋에 저장하지 않습니다.
- 세션에서만 사용합니다.
- 작업 완료 후 GitHub Settings에서 토큰을 revoke합니다."


현재 프로젝트 기준
------------------
저장소:
a01055929144-web/maju-intelligence

필수 최소 권한:
Contents: Read and write

일반 개발, 커밋, push만 한다면 위 권한 하나면 충분합니다.
