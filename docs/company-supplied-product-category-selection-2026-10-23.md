# 유통사 납품 품목 복수 선택 설계

상태: SQL 승인 대기. 운영 DB와 화면에는 아직 적용하지 않는다.

## 선택 규칙

- 단계와 관계없이 복수 선택한다. 예: `축산/부산물`, `수산`, `주류/사케`를 동시에 저장할 수 있다.
- 상위 분류를 고르면 하위 항목은 모두 선택 상태로 표시하되, 저장은 상위 키 하나만 남긴다.
- 상위 분류가 선택된 동안 하위 체크박스는 비활성화한다.
- 상위를 해제하면 하위 항목을 개별 선택할 수 있다.
- 화면은 영업 지역 선택과 같은 체크박스 계층을 사용한다. 선택 항목을 위로 모으고 모바일 바텀시트 내부에서 스크롤한다.

## 저장 위치

`company_supplied_product_categories(company_id, category_key)`를 사용한다. `companies.business_type`은 회사 업태이고 납품 가능 품목과 의미가 달라 재사용하지 않는다. 분류 라벨과 계층은 코드 사전으로 관리하며 저장값은 안정적인 영문 키로 둔다.

SQL 초안: `docs/sql-drafts/company-supplied-product-categories.sql`

## 적용 순서

1. SQL 검토·승인 및 운영 적용
2. 회사 정보 화면에 단계별 복수 체크박스 추가
3. 서버 API에서 `manage_company` 권한과 `company_id` 격리 검증
4. 리드 추천·견적 자동화가 선택 품목을 읽도록 연결
