# 유통사 납품 품목 복수 선택 설계

상태: 저장 테이블 운영 적용 완료(2026-10-23). 화면 구현 전 현장 분류 확정 대기.

## 선택 규칙

- 단계와 관계없이 복수 선택한다. 예: `축산/부산물`, `수산`, `주류/사케`를 동시에 저장할 수 있다.
- 상위 분류를 고르면 하위 항목은 모두 선택 상태로 표시하되, 저장은 상위 키 하나만 남긴다.
- 상위 분류가 선택된 동안 하위 체크박스는 비활성화한다.
- 상위를 해제하면 하위 항목을 개별 선택할 수 있다.
- 화면은 영업 지역 선택과 같은 체크박스 계층을 사용한다. 선택 항목을 위로 모으고 모바일 바텀시트 내부에서 스크롤한다.

## 저장 위치

`company_supplied_product_categories(company_id, category_key)`를 사용한다. `companies.business_type`은 회사 업태이고 납품 가능 품목과 의미가 달라 재사용하지 않는다. 분류 라벨과 계층은 코드 사전으로 관리하며 저장값은 안정적인 영문 키로 둔다.

SQL 초안: `docs/sql-drafts/company-supplied-product-categories.sql`

## 적용 순서

1. SQL 검토·승인 및 운영 적용
2. 회사 정보 화면에 단계별 복수 체크박스 추가
3. 서버 API에서 `manage_company` 권한과 `company_id` 격리 검증
4. 리드 추천·필터가 선택 품목을 읽도록 연결. 견적 자동화는 보류 모듈이므로 연결하지 않는다.

## 납품 품목 체계 초안

| 1단계 | 저장 키 | 2단계 후보 |
|---|---|---|
| 축산 | `livestock` | 소고기, 돼지고기, 닭·오리, 부산물(곱창·막창·대창·순대·내장), 족발·편육, 육가공 |
| 수산 | `seafood` | 활어, 선어, 냉동수산, 패류·갑각류, 건어물 |
| 주류 | `alcohol` | 와인, 사케, 맥주, 소주, 위스키, 전통주 |
| 한식 식자재 | `korean-food` | 장·양념, 김치·반찬, 쌀·곡물, 두부·계란, 면·떡 |
| 중식 식자재 | `chinese-food` | 중화소스·향신료, 면, 딤섬·만두, 중식 냉동품 |
| 일식 식자재 | `japanese-food` | 간장·소스, 다시·가쓰오, 김·절임, 면, 초밥재료 |
| 양식 식자재 | `western-food` | 유제품·치즈, 파스타·밀가루, 소스·오일, 햄·베이컨 |
| 공산품 | `processed-food` | 통조림, 냉동식품, 면류, 조미료, 음료, 포장·소모품 |
| 야채 | `vegetables` | 엽채, 근채, 버섯, 향신채 |
| 과일 | `fruit` | 국내과일, 수입과일, 냉동과일 |
| 베이커리 원료 | `bakery-ingredients` | 밀가루, 버터, 설탕, 생크림 |
| 커피·음료 원재료 | `beverage-ingredients` | 원두, 시럽, 파우더 |
| 식용유·튀김 재료 | `frying-supplies` | 식용유, 튀김유, 튀김가루 |
| 안주류 | `bar-food` | 건안주, 냉동안주, 탕·볶음 안주 |
| 분식 재료 | `snack-food-ingredients` | 어묵, 떡, 튀김 |
| 치킨 원료 | `chicken-ingredients` | 염지닭, 파우더 |
| 일회용품·소모품 | `disposables` | 용기, 장갑, 물티슈 |

세부 키는 `livestock/offal`, `seafood/shellfish`, `alcohol/sake`처럼 저장한다. 상위 키와
다른 분류의 하위 키를 동시에 선택할 수 있다.

| 버거 | 축산, 양식 식자재, 식용유·튀김 재료 | 야채, 일회용품·소모품 |
| 뷔페·급식 | 한식·중식·일식·양식 식자재 전반 | 축산, 수산, 야채, 과일 |

## 매장 업종 단계 초안과 운영 보유량

1단계는 `음식점`, `카페·디저트`, `주점`, `급식·뷔페`로 두고 음식점 아래에 한식·중식·
일식·양식·분식·치킨·피자·버거·배달을 둔다. 향후 카카오 `category_name` 원문 경로를 저장하면 3단계에
고기구이·국밥·횟집·초밥·이자카야·중화요리·파스타 등 세부 유형을 붙인다.

현재 카카오 키워드 적재는 `category_name`을 저장하지 않고 검색 키워드를 `industry`에 넣는다.
따라서 운영에서 실제 기록으로 확인 가능한 건수는 한식 887, 중식 453, 일식 328, 양식 317,
주점 268, 카페/디저트 107건이다. 세부 카카오 경로별 건수는 현재 데이터로 복원할 수 없으며,
후속 적재부터 원문 `category_name`을 별도 필드에 보존해야 한다.
