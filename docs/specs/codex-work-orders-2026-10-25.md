1. 요금제 기준 = 영업 지역 안 월 신규 매장 수(임시 영업·제외 빼고). `plans`(코드·이름·월 리드 상한·월 금액·직원 상한(선택)·사용 여부), 금액은 관리자 화면 입력(하드코딩 금지). 지역 선택 시 지난 3개월 평균으로 "예상 월 리드 N곳 → 추천 요금제". 상한 초과 시 숨김·추가 청구 없이 "다음 달 변경 권장"만. 변경은 다음 청구일부터.
2. `subscriptions` 보완: `plan_code`, `trial_ends_at`, `grace_until`, `scheduled_plan_code`. 월별 사용량 기록(회사·월·신규 리드·직원 수·요금제).
3. 청구: 체험 종료·청구 3일 전 안내(화면+이메일), 실패 시 1·3·5일 재시도 → 7일 유예 → 읽기 전용(삭제 금지). 청구를 `business-status` 크론에서 분리, 회사·청구월 유니크로 중복 결제 방지.
4. 고객사 화면: 요금제·이번 달 리드 사용량·다음 청구일·카드 변경·이력·영수증·요금제 변경·해지 방법.
5. 보고: 토스 라이브 키 유무(값 출력 금지), 세금계산서 발행 방법, 정기결제 고지 문구 초안.

## [WO-9] GPS 보완

원칙: 업무 중에만, 끊김·떨림 없이, Free·Hobby 한도 안에서. 규칙은 `domains/delivery/staff-location.ts`로 이동.

확인된 문제: 정류장 선택 시에만 표시(`current_customer_id` 필수)라 이동 중 사라짐, 영업 직원은 전송 없음 / 정확도 필터 없음(떨림·튐) / 8초 전송+매번 이력 저장, 지도 4초 조회(직원 10명 기준 월 호출 100만+, 이력 연 1천만 행+) / 내비 전환 시 `pagehide`에서 offline 전송 / 옛 좌표가 최신 위치를 덮음(서버 시간 순서 검사 없음) / 지도가 4초마다 차량 내용을 다시 그림.

1. "근무 시작/종료" 버튼(오늘 코스·영업 화면 공통), 근무 중이면 정류장 사이에서도 표시, 근무 종료·로그아웃 즉시 중지, 12시간 자동 종료. 차량 이름은 선택 정류장 없으면 직원 배정 차량. `list_latest_operational_staff_locations` 조건 변경·근무 칸 SQL 초안 → 승인.
2. 필터(도메인 함수+테스트): 오차 100m 초과 버림(첫 위치만 "부정확" 표시), 이동 < `max(15m, 오차/2)`는 정지로 마커 고정, 시속 150km 초과 버림. 서버: `recorded_at`이 기존보다 오래되면 최신 위치를 덮지 않음(이력에만).
3. 전송량: 이동 중 10초 / 정지 60초, 이력 저장은 25m 이상 이동 또는 2분마다. 지도 조회 10초, 실시간 차량 없으면 30초. 현재 `staff_location_events` 행 수·용량, 변경 전후 월 호출 수 추정 보고.
4. 웹에서 화면 숨김은 "화면 대기(내비 사용 중) · 마지막 HH:mm"로 표시하고 지도에서 빼지 않음. offline은 근무 종료·로그아웃 때만.
5. 웹 근무 중 화면 꺼짐 방지(Wake Lock, 끄기 가능).
6. 지도: 내용 바뀔 때만 `setContent`, 애니메이션은 지금 보이는 위치에서 재시작, 정지 중 애니메이션 없음. 색: 실시간/화면 대기/지연/마지막 운행.
7. 위치 권한 안내(안드로이드·아이폰 "정확한 위치"), 대표 화면에 "위치 꺼짐 직원" 표시.
8. 오늘 이동 경로 선이 있는지 확인, 없으면 선택한 차량만 표시.
9. 실제 휴대폰 시험: 걷기, 10분 정지, 내비 5분, 화면 끄기, 터널 끊김 후 복귀 결과 보고.

## [WO-10] 직원용 앱

안드로이드 먼저, 아이폰 다음. 화면이 꺼지거나 내비를 써도 근무 중 위치가 끊기지 않게 한다.

방식: Capacitor 껍데기가 운영 웹을 그대로 열고 위치만 네이티브로 전송. 화면·기능은 웹 배포로 바로 반영.

1. `apps/mobile-shell/`: Capacitor(안드로이드), 운영 주소 로드, 외부 링크(내비·전화·문자)는 해당 앱으로, 뒤로가기 = 웹 뒤로가기.
2. 백그라운드 위치: 오픈소스 플러그인(`@capacitor-community/background-geolocation` 등) 우선, 유료 플러그인은 비교표만. 위치 포그라운드 서비스 + 상시 알림 "MAJU 근무 중 · 위치 공유", 근무 시작 시에만 켜고 종료·12시간·로그아웃 시 끔. 배터리 최적화 예외 안내 화면.
3. 웹 ↔ 앱: 웹 "근무 시작/종료"가 앱이면 네이티브 위치, 웹이면 브라우저 위치(공통 인터페이스).
4. 인증: 백그라운드 전송은 기기 토큰(직원·회사 범위, 폐기 가능, 보안 저장소). `/api/staff/location/batch`(오프라인 대기분 시간순, WO-9 필터 동일). 기기 토큰 테이블 SQL 초안 → 승인. 테넌트 분리·요청 제한·감사 로그.
5. 동의: 권한 요청 전 앱 안 고지(무엇을·언제·왜·보관 기간), 동의 기록(직원·시각·문구 버전), 본인 위치 기록 보기·동의 철회.
6. 배포 준비 보고: Play Console 백그라운드 위치 신고서·시연 영상, 개인정보처리방침·위치정보 이용약관 초안, 파일럿용 테스트 설치 파일 배포(Firebase App Distribution 등).
7. 시험: 화면 끄고 30분 운행, 내비 사용, 터널 끊김, 배터리 소모(시간당 %), 근무 종료 후 전송 0건.
8. 아이폰은 안드로이드 안정화 후(백그라운드 "항상 허용" 사유 문구, 심사 대비 네이티브 기능 목록).
