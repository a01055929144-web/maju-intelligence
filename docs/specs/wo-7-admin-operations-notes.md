# WO-7 운영자 화면 운영 메모

## 이번 구현 범위

- `/admin`: 사용 중 고객사, 최근 7일 활동 직원, 연락·방문, 최근 30일 견적·계약과 수집 실패·7일 미사용 고객사를 실제 저장 데이터에서 집계한다.
- `/admin/system`: 환경변수는 이름과 설정 여부만 표시하며 값은 브라우저로 보내지 않는다.
- DB 용량은 `admin_database_usage()` 승인 전에는 조회하지 않는다. 승인 후 500 MB 대비 사용률, 350 MB 경고, 큰 테이블 10개를 표시한다.

## 주 1회 핵심 데이터 내보내기 제안

Free 요금제의 자동 백업 공백을 보완하기 위해 매주 일요일 새벽에 아래 테이블을 회사별 NDJSON 또는 CSV로 내보낸다.

- `normalized_customers`
- `business_permit_leads`
- `lead_actions`
- `route_plan_confirmations`

내보내기는 service role만 실행하고, 고객사별 파일을 분리해 비공개 Storage 또는 운영자가 관리하는 암호화 저장소에 보관한다. 성공 시각·행 수·파일 해시를 감사 로그에 남기고 8주 보관을 기본으로 한다. 자동 실행과 Storage 버킷 생성은 별도 승인 후 진행한다.

## 다음 단계

- 결제 실패·카드 미등록: 결제 공급자 상태가 연결된 뒤 실제 결제 이벤트 기준으로 추가한다.
- 온보딩 중단: 영업 지역·직원 초대·첫 연락 기록 등 완료 조건을 확정한 뒤 고객사 건강도 표에 추가한다.
- 외부 API 호출량·Vercel 호출량: 공급자별 집계 로그가 생긴 뒤 표시한다. 추정 숫자는 운영 화면에 넣지 않는다.
