  - 매장 상세: **매장 하나 = 하나의 ID**(리드→거래처 전환 시 같은 ID 유지). 탭 = 개요 · **배송 기록** · 영업 기록 · 파일 · 수정 기록 · (주문·매출 원장: 설계만, 화면 숨김). 배송 기록 = 날짜별 완료 시각·기사·GPS 거리·사진 원본·공유 여부·문구, 기간 필터·사진 모아 내려받기("배송 안 됐다" 문의 대응). 휴대폰 배송 완료 사진·기록이 여기와 동일 데이터(누락 금지 테스트).
  - 설계 원칙(나중 매장 주문·매출 원장·매장용 화면 대비): 배송 증빙·주문·전표·원장 모두 같은 매장 ID 참조, 매장 사장님 화면은 같은 데이터를 "본인 매장 범위"로만 조회하게 권한 경계 분리.
