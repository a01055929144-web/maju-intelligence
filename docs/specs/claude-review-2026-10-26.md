- 수정: "리드" 탭은 지도에 머물며 오른쪽 패널을 리드 목록(신규/영업)으로 전환 + 지도에 리드 핀 표시. "표로 보기" 링크만 /leads로(모든 이동에 companyId 등 기존 쿼리 유지).
  같은 패턴(focusOrigin·resetWorkspace의 router.push)도 쿼리 유지.

### G2 리드 상세 — 트랙 B
- 지도 오른쪽 리드 목록(신규·영업)에 상세 열기 없음 → 항목 클릭 시 리드 상세 열기(목록 페이지와 같은 상세 컴포넌트).
- 리드 표의 오른쪽 상세 패널이 정보가 많아 좁음 → 전용 상세 페이지 /leads/[id](새 탭 열기 버튼 + 패널의 "크게 보기"), 뒤로가기=목록, 같은 ?lead 동기화 규칙 유지.
  상세 페이지 구성: 상단 요약(상호·단계·개업일·담당자) / 영업 채널 / 연락 기록 타임라인 / 매장 정보 / 사용자 칸.
- 가독성: 글 대신 아이콘 중심(채널: 문자·DM·톡톡·메일·팩스·방문 아이콘, 단계: 색 칩, 개업 경과: "D+12" 배지, 보유 채널: 아이콘 점등).
  라벨은 짧게, 설명은 마우스 올림(툴팁)·작은 글씨. 아이콘은 lucide로 통일(이모지 문자 사용 금지 — 기기마다 모양이 달라짐). 시안 먼저 캡처로 보고.

### G3 영업 채널 "보낼 문구" 띄어쓰기·가독성 — 트랙 B
