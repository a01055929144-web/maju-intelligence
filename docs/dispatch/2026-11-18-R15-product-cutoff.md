# R15 상품별 주문 마감 (2026-11-18 03:1x · 컨트롤타워)

대표 지시(03:07): 상품별 주문 마감시간 설정을 진행. 
현재: 회사 · 권역 · 매장 마감은 운영 중. 상품별은 **S-3b 초안만 병합(#1075)** — `product_catalog.order_cutoff_days_before`(0~365) · `order_cutoff_time`(Asia/Seoul), 둘 다 NULL = 끔, 둘은 같이 채우거나 같이 비움.
운영 DB 적용은 **대표 승인 후**. 그 전에는 화면 · 함수 모두 "칸이 없으면 숨김/무시"로 안전하게 동작해야 한다.

| 번호 | 할 것 | 방 | 선행 |
|---|---|---|---|
| **CX-114** | 마감 계산 규칙을 도메인 함수 하나로: `effectiveCutoff(회사, 권역, 매장, 품목, 배송일)` → **가장 이른 마감** 반환 + 어느 규칙인지(회사/권역/매장/품목). 단위 테스트(자정 넘김 · 당일 0일 · 품목 NULL · 배송 요일 밖) | 쉬는 방 | 없음 |
| **CX-115** | 상품 관리: 품목 상세 · 표에 "주문 마감 [며칠 전][시각]" 입력(둘 다 비우면 회사 기준) · 여러 품목 일괄 지정 · 칸 없는 DB면 입력 숨김 | 쉬는 방 | CX-114 |
| **CX-116** | 매장 화면(PC·모바일·표 보기·장바구니): 품목별 마감이 회사보다 이르면 "이 상품 ○일 ○시 마감" 배지 · 지난 품목은 담기 막고 장바구니에서 "마감 지남 — 다음 배송일로" 안내 | 09방(매장 화면) | CX-114 |
| **CX-117** | 주문 접수 서버 차단: CX-62 공용 주문 함수에 품목 마감 검사 추가(에러 `product_cutoff_passed` + 품목명) · PG17 테스트 · **SQL은 초안까지** | CX-62 담당 방 | S-3b 적용 승인, CX-62 |

## 규칙
- 마감 계산은 **CX-114 함수 하나만** 쓴다(화면 · API · 서버 같은 결과). UI에서 따로 계산 금지.
- 기본 OFF: 품목 마감이 비어 있으면 지금과 동작 100% 동일 — 회귀 테스트 필수.
- 공통: Ponytail · e2e 1440/390 · 가로 스크롤 0 · 배포는 컨트롤타워.
- DB: S-3b 적용은 대표 승인 문구 후 컨트롤타워가 직접. 적용 전 CX-115/116은 "칸 없음" 경로로 병합 가능.
