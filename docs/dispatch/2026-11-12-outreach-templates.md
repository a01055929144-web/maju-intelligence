# CC-31 영업 문구 — 매장용·유통사용 분리 + 템플릿 3종 + 고객사 맞춤 (2026-11-12 18:31 대표)

> 컨트롤타워 설계 · 담당 Claude Code. Owner Domain: `lead`. Related: `organization`(회사 정보), `pricing`(단가표 링크).

## 대표 요청 (원문 요지)

- "비브처럼 유통사를 영업하고 싶어하는 곳들도 있어. 매장 영업 멘트와 유통사 영업 멘트를 구분해서 만들도록 해."
- "매장/유통사 멘트 3가지 정도 템플릿 구성해놓고 고객사 맞춤으로 작성해주는 걸로 하자."
- (18:28) 유통사 영업 멘트는 약하면 안 된다 — 비브는 "신규 오픈 매장이 노출된다"를 앞에.

## 지금 문제 (코드 확인)

- 영업 문구는 회사당 1개(`company setting lead_dm`), 리드가 매장이든 유통사든 같은 문구. 없으면 코드 기본 문구("식자재를 납품하는 업체입니다…").
- `{업종}`이 비면 "음식점", `{품목}`은 음식점 추천 품목 → 유통사 리드에 "미분류 매장에서 많이 쓰시는…" 같은 문장이 나감(11/12 비브 화면).
- 유통사 영업을 하는 회사는 비브만이 아님 — 도매·중도매·산지 업체가 유통사에 **공급**을 영업할 수 있다. 비브는 유통사에 **서비스**를 판다. → 유통사 문구도 회사마다 내용이 다르다.

## 결정

| 항목 | 결정 |
| --- | --- |
| 문구 종류 | **매장용**(대상 `restaurant`) · **유통사용**(대상 `distributor`) 두 벌. 리드의 `target_type`로 자동 선택 |
| 템플릿 | 종류마다 **기본 템플릿 3개**(코드에 고정, 아래). 회사는 하나를 골라 고쳐서 **회사 문구**로 저장 |
| 고객사 맞춤 | 회사 문구는 그 회사 정보로 미리 채워진 상태로 시작(회사명·영업 지역·주력 품목). **MAJU 관리자가 고객사 대신 작성**할 수 있음(관리자 › 회사 › 설정 도우미 › 영업 문구) — 고객사가 직접 고칠 수도 있음 |
| 리드별 | 지금처럼 "이번에만 고쳐도 됨"(리드 상세에서 그 리드만 수정, 회사 문구는 그대로) |
| 노출 | 유통사용 문구 칸은 유통사 영업을 켠 회사(`DISTRIBUTOR_SALES`)만 보임. 매장용은 모두 |
| 비브 | 유통사용 = **서비스 판매 문구**(신규 오픈 매장 노출 강조, 아래 V1~V3)를 관리자 맞춤으로 넣음. 매장용은 쓰지 않음 |

## 변수 (문구 안 `{…}`)

| 변수 | 값 | 매장용 | 유통사용 |
| --- | --- | --- | --- |
| `{상호}` | 리드 상호 | ○ | ○ |
| `{회사명}` | 보내는 회사 이름(회사 정보) | ○ | ○ |
| `{지역}` | 리드 주소의 시·군·구(없으면 회사 영업 지역 첫 번째) | ○ | ○ |
| `{업종}` | 리드 업종(없으면 그 문장 줄째 생략 — "음식점" 대체 금지) | ○ | ✕ |
| `{품목}` | 업종 추천 품목(제외 품목 반영, 없으면 줄 생략) | ○ | ✕ |
| `{주력품목}` | 회사 정보의 주력 품목(없으면 줄 생략) | ○ | ○ |
| `{신규수}` | `{지역}` 최근 30일 신규 인허가 음식점 수(회사 수집 데이터, 0·없음이면 그 줄 생략) | ✕ | ○ |

- **값이 비는 변수가 든 줄은 통째로 뺀다**(어색한 "미분류 매장에서…" 방지). 순수 함수로 테스트.

## 기본 템플릿 — 매장용 (식자재 공급 → 음식점)

**S1 단가표 먼저 (지금 기본 문구를 다듬은 것)**
```
안녕하세요, {상호} 대표님.
{지역}에서 식자재를 납품하는 {회사명}입니다.

{업종} 매장에서 많이 쓰시는 {품목} 단가표를 먼저 보내드리고 싶습니다.
지금 쓰시는 단가와 비교해 보시고, 관심 있는 품목이 있으면 맞춤 견적을 드리겠습니다.

결제 조건은 협의해서 맞춰드립니다.
편하게 답장 주세요.
```

**S2 신규 오픈 축하**
```
{상호} 대표님, 오픈 준비 중이시죠?
{지역} 식자재 납품 {회사명}입니다.

오픈 초기에는 품목·수량이 자주 바뀌어서, 소량·당일 주문이 되는 곳이 편합니다.
{주력품목} 위주로 단가표를 먼저 드리고, 링크에서 바로 주문하실 수 있게 해 드릴게요.

단가표 받아 보시겠어요?
```

**S3 비교 견적**
```
{상호} 대표님, {회사명}입니다.

지금 쓰시는 거래처 단가표를 사진으로 보내주시면,
같은 품목으로 비교 견적을 하루 안에 드립니다.
바꾸지 않으셔도 괜찮습니다. 비교만 해 보세요.
```

## 기본 템플릿 — 유통사용 (공급 → 유통사, 도매·산지 업체용)

**D1 공급 제안**
```
안녕하세요, {상호} 대표님.
{주력품목} 공급하는 {회사명}입니다.

{지역} 유통사에 안정적인 물량과 도매 단가로 공급하고 있습니다.
단가표를 먼저 보내드리고, 필요하신 품목은 샘플도 드리겠습니다.

편하게 답장 주세요.
```

**D2 결품·단가 대응**
```
{상호} 대표님, {회사명}입니다.

결품이나 단가 급등 때 바로 대체 공급이 필요하시면 연락 주세요.
{주력품목}은 당일·익일 출고가 가능합니다.

이번 주 도매 단가표 보내드릴까요?
```

**D3 거래 조건**
```
{상호} 대표님, {회사명}입니다.

정기 물량 기준으로 단가와 결제 조건을 맞춰드립니다.
지금 받으시는 조건을 알려주시면 비교 조건을 바로 드리겠습니다.
```

## 비브 맞춤 (유통사용, 관리자가 비브 회사 문구로 넣음 · 대표 선택)

**V1 신규 오픈 매장 먼저 (기본으로 추천)**
```
안녕하세요, {상호} 대표님.
식자재 유통사 영업 서비스 비브입니다.

대표님 영업 지역에 새로 문 여는 음식점을 매일 찾아 드립니다.
인허가가 막 난 신규 매장이라, 아직 거래처를 정하지 않은 곳에 가장 먼저 연락하실 수 있습니다.
최근 30일 {지역}에서 새로 연 음식점만 {신규수}곳입니다.

· 지도에서 신규 매장 위치·업종을 바로 확인
· 단가표를 링크로 보내고, 매장은 그 링크에서 바로 주문
· 들어온 주문은 한 화면에 모입니다

10분만 시간 내주시면 대표님 지역 신규 매장을 직접 보여드릴게요.
```

**V2 짧고 강하게**
```
{상호} 대표님, 비브입니다.

{지역}에 새로 오픈하는 음식점, 매일 알려 드립니다. (최근 30일 {신규수}곳)
거래처 정하기 전 신규 매장에 제일 먼저 단가표를 보내세요.

대표님 지역 신규 오픈 매장 목록, 무료로 보내드릴까요?
```

**V3 문제 제기형**
```
안녕하세요, {상호} 대표님.

새로 오픈한 음식점은 오픈 초기에 식자재 거래처를 정합니다.
그때를 놓치면 다른 유통사가 먼저 들어갑니다.

비브는 대표님 영업 지역의 신규 인허가 음식점을 매일 찾아 지도에 띄워 드리고,
단가표 전송부터 매장 주문 받기까지 한 화면에서 이어지게 해 드립니다.

대표님 지역 신규 매장 현황을 10분 안에 보여드릴게요.
```
- 주의(대표 확인): 연락처는 공개된 경우에만 있음 — 데모에서 설명. "오픈 초기에 거래처를 정한다"는 경험칙.
