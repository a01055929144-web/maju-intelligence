# CC-30 가격 관리 재구성 — 고객사가 단순하게 (2026-11-11 23:36 대표 요청)

> 컨트롤타워 설계 · 담당 Claude Code. 근거: [단가 구성 표](../design/2026-11-11-pricing-layers.md). **기능은 그대로 두고 보이는 면만 다시 짠다.** 공통 화면 기준(탭·CommonDataTable·제목줄·주 버튼 1개·12px 이상)을 따른다.

## 대표 요청

"기능은 좋은데, 고객사 입장에서 단순하고 직관적으로 관리할 수 있도록 재구성이 필요해."

## 왜 어려운가 (지금)

- 가격을 정하는 곳이 10개(기본·분류·상품·직접 단가·템플릿·약정가·행사·임박·노출 대상·발행 고정)이고 메뉴 3곳(마진 설정·행사·임박·거래처 상세 계약 단가)에 흩어져 있다.
- 매장별 가격을 정하는 방법이 둘이다: **템플릿**(등급)과 **약정가**(견적 수락 → 거래처 상세 "계약 단가", 지금은 보기·끝내기만).
- 기본 마진은 "판매가 반영"을 눌러야 바뀌고 템플릿은 바로 계산된다 → 반영을 잊으면 옛 가격으로 단가표가 나간다.
- "이 매장에 이 품목이 왜 이 가격인가"를 한 화면에서 볼 수 없다.
- 마진 설정이 탭 4개(기본·분류별·상품 예외·전체 판매가)라 같은 표를 네 번 나눠 본다.

## 고객사가 실제로 묻는 질문 3개 = 탭 3개

| 질문 | 탭 | 한 줄 |
| --- | --- | --- |
| 얼마에 사서 얼마에 파나? | **판매가** | 전체 상품 표 하나에서 마진·가격을 바로 고친다 |
| 이 매장엔 얼마에 파나? | **매장 가격** | 매장(또는 등급)을 고르면 그 매장 최종 가격과 이유가 보인다 |
| 이번 주 싸게 파는 건? | **행사·임박** | 지금 화면 그대로, 대상 고르기만 단순하게 |

## 메뉴 (판매)

```
매입가 업로드
상품관리
가격 관리      ← 탭: 판매가 · 매장 가격 · 행사·임박   (마진 설정 + 행사·임박 합침)
견적서·단가표
인쇄 기본값
```
- 옛 주소 `/revenue/pricing/margins` → `가격 관리?tab=판매가`, `/revenue/pricing/promotions` → `?tab=행사·임박`(이동만, 북마크 유지).
- 거래처 상세 "계약 단가" 카드 → "이 매장 가격 보기" 링크(`?tab=매장 가격&customer=`).

## CC-30a 판매가 탭 (마진 설정 4탭 → 표 하나) — CC-28 흡수

- **틀**: 왼쪽 공용 분류 트리(CC-26, 폴더 옆 마진 배지) + 오른쪽 CommonDataTable 하나. 제목줄 오른쪽 `기본 마진 15% · 10원 올림 [바꾸기]`, 등급이 켜진 회사는 그 옆 `[기본 ▾]`(고른 등급을 편집).
- **표 열**: 상품 · 규격 · 분류 · 매입가 · 마진 · 판매가 · 이익 · 이익률 · 출처 배지 (열 편집으로 숨김).
- **고치는 법은 두 가지뿐**:
  1. 표에서 **마진 칸** 또는 **판매가 칸**을 눌러 바로 입력 → 마진을 넣으면 `상품`, 판매가를 넣으면 `고정`. 칸 비우기 = 상속으로 되돌림.
  2. 트리 폴더 ⋯ → **"이 분류 마진 정하기"** (하위까지 기본 켬, 하위에 다른 값이 있으면 덮어쓸지 확인).
  - 여러 줄 선택 → 공용 툴바 "마진 일괄 변경 / 고정 해제" (주 버튼 1개).
- **판매가 반영 버튼 없앰 (11/11 23:45 대표 확정)**: 저장 = 즉시 판매가 반영(기존 반영 API를 저장 뒤 자동 호출, 해당 상품만). 화면 아래 토스트 "판매가 32개 바뀜 [되돌리기]"(직전 1회). 발행된 문서는 지금처럼 고정.
- **분류 마진은 상위 폴더를 따라간다**(발견 2번 수정): 기본도 등급과 같이 "가장 가까운 상위 폴더 마진". → 바뀌는 상품 목록을 먼저 뽑아 대표 확인 후 적용.
- 옛 "고급(그룹 직접 관리)"은 ⋯ 메뉴 안으로만.

## CC-30b 매장 가격 탭 (등급 + 매장 개별 가격을 한곳에) — CC-19c 흡수

- **왼쪽**: 매장 목록(검색) — 매장명 · 등급 칩 · "매장 가격 N개". 맨 위에 등급 목록(기본·도매·VIP · 매장 수)도 같이 — 등급을 고르면 그 등급 가격표.
- **오른쪽 (매장을 고르면)**: 상단 `등급 [도매 ▾]`(바꾸면 이 매장 등급 변경) + 표: 상품 · 기본 판매가 · **이 매장 가격** · 차이 · 출처 배지(`등급`/`매장`/`견적`) · 기간.
  - "이 매장 가격" 칸을 눌러 바로 입력 → 매장 개별 가격(시작일 오늘, 끝 없음, 더보기로 기간). 비우기 = 끝내기.
  - 견적 수락으로 생긴 가격은 `견적` 배지 + 원본 견적 링크.
- **데이터**: 매장 개별 가격 = 기존 `customer_price_agreements`에 `source_quote_id = null`로 추가(**스키마 변경 없음 예상** — 단위·과세 칸은 상품 기본값). 등급 = `normalized_customers.margin_template_id`. 새 API: `POST/PATCH /api/customers/[id]/contract-prices`(지금은 GET·닫기만).
- 등급 편집(등급 만들기·마진)은 판매가 탭 `[기본 ▾]`에서 — 여기서는 고르기만.
- 기능 스위치: 등급 부분만 `MARGIN_TEMPLATES`(꺼진 회사는 등급 칩 없이 매장 가격만).

## CC-30c 행사·임박 탭 (CC-29 화면 단순화)

- 서랍의 대상 고르기 기본 2개만: `전체 매장`(기본) · `특정 매장만 [매장 고르기]`. **"제외"와 "등급으로 고르기"는 더보기**(CC-29 기능 그대로, 화면만 접음).
- 목록 "정상가" = 그 상품의 지금 판매가(판매가 탭 값) — 발견 3번 수정, 할인율도 이 값 기준.
- 주문 가격 규칙(CC-29 SQL에 포함, 발견 1번): **행사 대상이면 행사가 > 매장 가격(약정) > 발행본 가격**, 대상이 아니면 매장 가격 → 등급가 → 기본가, 행사 재고 차감 없음.

## CC-30d 문서에서 가격 자동

- 견적서: 받는 매장을 고르면 **그 매장 가격(매장 > 등급 > 기본)** 자동, 줄마다 출처 배지. 오른쪽 설정 "가격 기준" 칸은 없앰(매장이 정함).
- 단가표(받는 매장 없음): 오른쪽 설정 `등급 [기본 ▾]` 하나.
- 줄 가격을 문서에서 직접 고치면 `문서에서 고침` 배지(이 문서만, 판매가·매장 가격은 안 바뀜).

## CC-30e 전표와 가격의 관계 (11/11 23:45 대표 질문 "ERP 매입·매출은 전표 발행인데 분류 맞지?")

**분류는 맞다** — 가격과 거래는 따로 간다(블루프린트 "매입가와 매입 거래" 원칙).

| 구분 | 무엇 | 돈·재고가 움직이나 | 화면 |
| --- | --- | --- | --- |
| 가격(이 문서) | 매입가·마진·판매가·매장 가격·행사가 | 아니오 — 계산 기준 | 가격 관리 |
| 가격 안내 문서 | 견적서·단가표(확정 시 가격 고정) | 아니오 | 견적서·단가표 |
| 주문 | 매장이 보낸 요청(접수 시 가격 고정) | 아니오 | 주문함 |
| **매출 전표** | 실제 출고·채권(거래명세서·세금계산서 근거) | **예** | 매입·매출관리 |
| **매입 전표** | 실제 입고·채무 | **예** | 매입·매출관리 |
| 매입가 업로드 | 가격 계산용 원가 기록 | 아니오(재고·채무 안 만듦) | 매입가 업로드 |

**코드 확인으로 찾은 틈 (고칠 것)**

| # | 문제 | 등급 | 고칠 것 |
| --- | --- | --- | --- |
| E1 | 매출 전표 품목 단가 = 계약 단가 → 없으면 **상품관리 `default_sales_price`**. 가격 관리의 판매가(`pricing_items.price`)·등급가를 안 씀 → **"판매가"가 두 곳**(상품관리 판매가 ≠ 마진 판매가)이라 전표와 단가표 금액이 다를 수 있음 | P1 | 매출 전표 단가도 CC-30 가격 출처 함수 하나로: 매장 가격 > 등급가 > 판매가. 주문에서 만든 전표는 **주문 줄 가격 그대로**. 상품관리 "판매가" 칸은 가격 관리 판매가를 보여주기만(직접 입력은 가격 관리 "고정"으로) |
| E2 | **매입 전표를 확정해도 매입가에 반영 안 됨** — 매입가는 엑셀 업로드로만 들어옴 → 같은 매입을 두 번 입력 | P2 | 매입 전표 확정 → 매입가 기록 자동 추가(CX-06 변동률 규칙·정정/취소 제외 동일). 엑셀 업로드는 ERP 없는 회사용으로 유지 |
| E3 | 주문 → 매출 전표 연결 미완성(블루프린트 G1/G2) | — | 기존 계획대로(주문 확인 → 출고 → 매출 전표). 이때 E1 규칙 적용 |

- 순서: E1은 CC-30d(문서 가격 자동)와 같이, E2는 CC-30b 뒤. 둘 다 DB 스키마 변경 없음 예상(E2는 확정 RPC 수정 → SQL 승인).

### 공통 틀 (PC 1440)

### ① 판매가 탭
```
가격 관리                       기본 마진 15% · 10원 올림 [바꾸기]  [단가표 만들기]
판매가 | 행사·임박
┌ 분류 ───────────┐ ┌───────────────────────────────────────────────────┐
│ 🔍 분류 찾기     │ │ 🔍 상품 검색   (바뀐 상품) (고정 가격)       열 편집  엑셀 ▾│
│ 전체        748 │ │ ☐ 상품   규격  분류    매입가  마진   판매가  이익  출처  │
│ 농산   15%   ⋯ │ │ ☐ 배추   1포기 채소류  2,000   12%   2,240  240  마진   │
│  └ 채소류 12% ⋯ │ │ ☐ 두부   300g 가공    1,000    —    1,500  500  고정   │
│ 축산   기본  ⋯ │ │                                                        │
└─────────────────┘ └───────────────────────────────────────────────────┘
 (줄 선택 시 toolbar가 바뀜)  3개 선택 · [마진 일괄 변경] [고정 해제] · 선택 해제
 (저장 후 아래 토스트)        판매가 32개 바뀜 · [되돌리기]
```
| 위치 | 버튼 | 종류 | 동작 |
| --- | --- | --- | --- |
| 제목줄 | 단가표 만들기 | **주** | 지금 판매가 전체 품목으로 단가표 작성 화면 |
| 제목줄 | 바꾸기 | 보조 | 기본 마진·올림 작은 서랍(예시 카드: 매입가 → 판매가·이익) |
| 왼쪽 폴더 ⋯ | 이 분류 마진 정하기 | 메뉴 | 한 줄 입력 `[ 12 ]% ☑ 하위까지 · 저장` |
| 표 칸 | 마진 / 판매가 | 칸 편집 | Enter·칸 밖 클릭 = 저장(즉시 반영), Esc = 취소. 판매가 입력 시 고정 확인 한 줄 |
| toolbar | 바뀐 상품 · 고정 가격 | 칩(필터) | 최근 매입가 변동 / 고정 가격만 |
| toolbar | 엑셀 ▾ | 메뉴 | 내보내기만 |
- **폴더 이동·이름 바꾸기는 여기 없음**(상품관리 한 곳에서만). 이 ⋯ 메뉴는 마진 하나.
- 빈 상태: 매입가 0건 → "매입가를 먼저 올려 주세요 [매입가 업로드]".
- 이익 ≤ 0 줄은 빨강 + 툴바 칩 "손해 N개" 자동 표시.

### ② 행사·임박 탭
```
가격 관리                                                    [+ 행사 등록]
판매가 | 행사·임박
(행사) (임박)    진행 중 3 · 예정 1 · 끝남 12            🔍 상품 검색   열 편집
상품   규격   정상가   행사가   할인   기간         남은 수량   대상
라면   5입   4,500    3,900   13%   11/11~11/17   80/100    전체 매장
```
| 위치 | 버튼 | 종류 |
| --- | --- | --- |
| 제목줄 | + 행사 등록 (임박 칩 선택 시 `+ 임박 등록`) | **주** |
| 줄 클릭 | 서랍 열기(수정) | — |
| 서랍 아래 | 취소 · **저장** · (수정일 때) 끝내기는 더보기 안 | 주는 저장 1개 |
- 서랍(오른쪽 480px · 휴대폰 전체 화면): 상품 → 가격(정상가·할인율 자동) → 기간(임박은 유통기한) → 수량 → **대상: 전체 매장 [바꾸기]** → 더보기(노출 이름·매장당 한도·제외·등급).
- 왼쪽 영역 없음(행사는 수가 적어 표만). 정상가 = 판매가 탭 값.

### ③ 매장 가격 탭 (매장별 가격을 쓰기 시작하면 나타남)
```
가격 관리                                           [등급 관리]  [견적서 만들기]
판매가 | 행사·임박 | 매장 가격
┌ 매장 ───────────┐ ┌───────────────────────────────────────────────────┐
│ 🔍 매장 찾기     │ │ A마트 강남점 · 등급 [도매 ▾]                          │
│ A마트 강남  도매 3│ │ 🔍 상품 검색  (이 매장만 다른 가격)          열 편집  엑셀 ▾│
│ B식당      기본  │ │ 상품   기본 판매가  이 매장 가격  차이   출처   기간       │
│                 │ │ 두부      1,500       1,200    -300  매장   11/11~     │
└─────────────────┘ └───────────────────────────────────────────────────┘
```
| 위치 | 버튼 | 종류 |
| --- | --- | --- |
| 제목줄 | 견적서 만들기 | **주** (고른 매장 앞, 이 매장 가격으로) — 매장 미선택 시 비활성 + 툴팁 |
| 제목줄 | 등급 관리 | 보조 → 서랍(등급 이름 · 마진 % · 매장 수 · 분류 예외는 더보기) |
| 매장 머리 | 등급 [▾] | 선택 — 바꾸면 즉시 저장 + 토스트 되돌리기 |
| 표 칸 | 이 매장 가격 | 칸 편집, 비우기 = 끝내기(확인 한 줄) |
- 매장 0곳 선택 상태: 오른쪽에 "왼쪽에서 매장을 고르세요".

### 검토에서 고친 점
| # | 문제 | 결정 |
| --- | --- | --- |
| 1 | 판매가 탭 주 버튼이 없음(칸 편집뿐) → 다음 할 일이 안 보임 | 주 = **단가표 만들기**(매입가 → 판매가 → 단가표 흐름) |
| 2 | 폴더 ⋯에 이동·이름·마진이 섞임(지금 마진 화면에도 폴더 이동 있음) | 가격 관리 ⋯ = 마진만, 폴더 정리는 상품관리 |
| 3 | 매장 가격 탭이 중간에 끼면 탭 위치가 바뀜 | 항상 맨 끝 |
| 4 | 저장 버튼이 칸마다 생기면 버튼 수십 개 | 칸 편집은 Enter 저장 + 토스트 되돌리기, 저장 버튼 없음 |
| 5 | 행사 서랍의 "끝내기"가 저장 옆에 있으면 잘못 누름 | 더보기 안으로 |
| 6 | 휴대폰에서 왼쪽 트리 260px가 화면을 먹음 | 상단 선택 한 줄로 |

## 대표 직접 사용 확인 (고객사 질문 대신 — 11/11 23:51 대표 "내가 직접 사용")
배포 후 제이에스리테일에서 대표가 아래 6개를 해 보고 막힌 곳만 알려 주면 바로 고친다.
1. 매입가 업로드 → 가격 관리에서 바뀐 상품 칩으로 확인
2. 채소류 마진 바꾸기(⋯ → 이 분류 마진) → 토스트 되돌리기
3. 상품 하나 판매가 직접 입력(고정) → 고정 해제
4. 행사 등록 → 단가표 만들기 → 행사 블록 자동 포함 확인
5. 매장 하나에 이 매장 가격 입력 → 견적서 만들기 → 그 가격 자동
6. 휴대폰(390)으로 1·2번 반복
