## CC-17 분류 폴더 이동 (상품관리)

- **왼쪽 트리에서 폴더 이동**: 폴더 메뉴(⋯) → "다른 상위로 옮기기"(대·중 선택) · "이름 바꾸기". 하위 폴더·상품이 통째로 따라간다. 같은 이름 폴더가 이미 있으면 "합치기" 확인.
- **상품 끌어다 놓기**: 오른쪽 표에서 고른 상품을 왼쪽 폴더로 끌어 놓으면 이동(지금의 "옮길 분류 선택"도 유지 — 키보드·휴대폰용).
- **데이터 정합성(중요)**: 폴더 이동은 `product_catalog.category`(하위 전부)와 `margin_group_categories.category`(하위 경로 전부)를 **한 번에** 바꿔야 한다. 둘 중 하나만 바뀌면 마진이 풀린다 → **RPC 하나로 원자 처리**(`move_product_category(company_id, from_path, to_path)`): 회사 경계, 대상 상품 수 반환, 되돌리기용 이력. SQL 초안 + down + PG17 + 승인표(**운영 적용은 대표 승인 문구**). 발행된 문서 버전은 그때 값 그대로(스냅샷) — 바꾸지 않는다.
- **Done**: 폴더 옮기기·이름 바꾸기·합치기 후 상품 수·마진 연결 유지 PG17 테스트, PC 1440·390 e2e, CI, Ponytail.
