## 단계

### 46-0 품질 진단 (코드·DB 변경 없음, 먼저)

- 운영 읽기 조회로 회사별 표: 칸별 채움률(좌표·전화 유선/010·업종·카카오·네이버·구글·인스타·면적·개업일·영업 상태·메뉴), 원천별, 마지막 보강 시각 분포, 중복 의심 수, 폐업인데 '신규'로 남은 수, 업종 '기타' 비율.
- 결과 `docs/qa/lead-quality-2026-11-14.md` → 컨트롤타워 검토 → 아래 단계 범위·순서 확정.

### 46-1 보강 속도 (가장 큰 효과)

- 하루 30곳 → **보강 대기열**: 회사·리드별 상태(대기/성공/실패·사유/다음 재시도). 지금 `lead_enrichment_events` 재사용, 대기열 표가 필요하면 SQL 초안.
- 실행: ① 크론은 그대로 두되 한 번에 처리량을 시간 예산(60초) 안에서 최대로 ② **관리자 화면 `리드 정보 보강` 버튼**(회사 선택 → 100곳씩 끊어 진행 막대, 탭을 닫아도 다음에 이어서) ③ 첫 일괄 보강은 **dry-run(몇 곳이 채워질지) → 컨트롤타워 검토 → 대표 승인 → 실행**(운영 데이터 대량 변경이므로).
- 외부 API 한도 안에서: 카카오 로컬·네이버 검색의 일일 호출 한도·초당 제한을 설정값으로 두고 넘지 않게(남은 양 표시). 정확한 한도는 각 콘솔에서 확인해 `docs/work-orders/owner-change-later.md`에 이름·값 아닌 **수치만** 기록.

### 46-2 카카오·네이버 매칭 품질

- 매칭 규칙 한 곳(`domains/lead/place-match.ts`): 상호 정규화(지점·괄호·공백) + 주소 거리(같은 건물·100m 이내) + 전화 일치 → **신뢰도 점수**. 높음=자동 연결, 중간=`확인 필요` 큐(후보 2~3개 중 고르기), 낮음=연결 안 함.
- 저장: 장소 링크·외부 id·카테고리·공개 전화·좌표 보정·`matched_by`·`confidence`·`fetched_at`. 지금 칸(`kakao_place_url` 등)에 링크, 나머지는 외부 장소 표(SQL 초안: `lead_external_places(company_id, lead_id, provider, external_id, url, category, phone, lat, lng, confidence, matched_by, fetched_at)`).
- 업종 재분류: 카카오 카테고리로 `industry_primary` 보정(기존 `domains/lead/industry-classification.ts` 규칙 사용, '기타' 줄이기).

### 46-3 구글

- 구글 Places는 **약관상 장소 id 말고는 오래 저장하지 않는 것이 원칙**(평점·리뷰 수 등은 화면 열 때 조회·짧게 캐시). 그래서 **place_id만 저장**, 리드 상세를 열 때 평점·리뷰 수·영업시간을 가져와 보여 줌.
- 유료 API — 1만 곳 일괄 조회 비용이 큼 → **기본은 상세를 열 때만**, 일괄은 대표 승인(예상 호출 수·비용 표 먼저). 키가 없으면 지금처럼 조용히 건너뜀.

### 46-4 규모(면적) — CC-42c 흡수

- 정부 인허가 API로 면적(`storeAreaSqm`) 보강: 원천 기록 있는 곳부터, 없는 옛 CSV 리드는 상호+주소로 인허가 검색 매칭(46-2 규칙) → dry-run → 승인.
- 면적 30%↑ 되면 규모 필터 켜기(회사별), "규모 모름" 따로 선택. 평 단위 표시(㎡/3.3).

### 46-5 품질 규칙·정리

- 폐업: 인허가 상태·국세청 결과가 폐업이면 목록 기본에서 빼고 `폐업` 칩(지금 '신규 수집'에 남은 폐업 정리).
- 중복: 같은 장소 id·같은 전화·이름+주소 비슷 → **중복 묶음 확인 화면**(자동 병합 없음, 기존 soft merge 재사용).
- 전화 구분: 010/유선/050(안심번호) 표시 — 맞춤 견적(CC-43)은 010만.
- 품질 점수(0~100): 좌표·전화·카카오·네이버·업종·면적·영업 상태 가중합 → 목록 정렬·필터 `정보 부족`.

### 46-6 화면

- 리드 상세 `외부 정보` 카드: 카카오·네이버·구글·인스타 링크(새 탭) · 카테고리 · 공개 전화 · 평점·리뷰 수(구글, 열 때 조회) · 면적(평) · 영업 상태 · 출처·갱신일 · `다시 찾기` · 후보 고르기.
- 리드 목록·지도: 칩 `카카오 연결` `네이버 연결` `정보 부족` `폐업`, 필터, 품질 점수 열(공용 표).
- 관리자: 회사별 채움률 표(46-0과 같은 숫자, 매일 갱신)·보강 실행·남은 API 한도.
