## D-2 주문 → 오늘 코스 자동 연결 (D단계 핵심)
- 주문함에서 "확인"한 매장 주문 → **배송일 코스의 정류장**(거래처·호차는 거래처 권역/기본 호차)으로 자동 추가. 취소되면 빠짐. 첫 거래(needs_review) 주문은 확인 전엔 코스에 안 들어감(#460 경계).
- 같은 거래처 같은 날 여러 주문은 정류장 하나로 묶음.
- 기존 `app/api/routes/confirm-order`·`today`·`sequence` 재사용. DB 변경이 필요하면 SQL 초안 → 승인.
- **Done**: 주문 확인 → 코스 등장 → 취소 → 빠짐, 회사 격리, 정류장 묶음 PG17·e2e.

## D-3 기사 휴대폰 화면 (웹)
- 오늘 순서 → [도착] → 사진·메모 → [완료 | 일부 | 문제] 한 손 조작. 공통 화면 기준(버튼·12px+).
- **웹에서 할 수 있는 최대한의 위치 보강**
  - **운행 중 화면 꺼짐 방지**(Screen Wake Lock — 안드로이드 크롬·최신 아이폰 사파리 지원): "운행 시작"을 누르면 화면이 꺼지지 않게. 운행 종료 시 해제.
  - **도착·완료 순간 위치를 반드시 함께 저장**(그 순간 새로 측정, 캐시 재사용 금지) → GPS가 끊겨도 정류장 기록은 정확.
  - 화면으로 돌아오면 즉시 1회 측정·전송, 끊긴 구간은 "기록 없음"으로 표시(지어내지 않음).
  - 운행 중 다른 앱(내비)으로 넘어가면 위치가 멈춘다는 안내를 기사 화면에 1회.
- **Done**: 390px e2e(도착·사진·완료·일부·문제), Wake Lock 사용 가능/불가 분기 테스트, 완료 기록에 위치·시각 저장.
