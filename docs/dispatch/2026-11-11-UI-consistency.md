## 기준 (이 표가 정답)

- **글자**: 본문 14px · 표 13px · 보조 12px · 제목 20/16px · 숫자는 `tabular-nums` 오른쪽 정렬. **12px 미만 금지**(인쇄용 A4 문서 `pricing-document-preview`는 제외).
- **탭**: `components/ui/tabs.tsx` 하나(밑줄형 기본, 칩형 옵션). `role=tablist`·화살표 키·선택 표시 공통. URL 쿼리와 연결 옵션.
- **표**: 새로 만들지 않고 **기존 `CommonDataTable`이 표준**이다. 목록형 표는 모두 이것으로 옮기고, **열 편집**(보이기·숨기기·순서·고정 + 이번에 추가하는 **열 너비 조절**·기본으로 되돌리기)을 세 화면 모두 같은 방식으로 제공한다. 보강: 머리줄 고정(sticky)·줄 높이 40px·숫자 열 오른쪽·빈/로딩/오류 상태·휴대폰(≤640px) 카드 목록 전환.
  - 열 편집 저장: 1단계는 지금처럼 브라우저 저장(`maju:table:<화면>:<사용자>`). 2단계(별도 DB 승인)로 계정 저장 — 다른 PC에서도 같은 열 구성.
  - 입력 표(문서 편집 종이·주문서 수량 입력 등)와 인쇄 문서는 대상이 아니다.
- **제목줄**: `components/ui/page-header.tsx`(제목·설명·오른쪽 버튼 자리) — 세 셸이 같은 것을 쓴다.
- **버튼·배지·카드·입력**: 기존 `components/ui/*`와 `maju-*` 클래스만. 새 색·모서리 값을 화면 안에서 만들지 않는다.
