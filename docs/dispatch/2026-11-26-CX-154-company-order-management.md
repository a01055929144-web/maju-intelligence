## 대표 피드백

1. 주문 상세를 볼 수 없다.
2. [확인]을 누르면 목록에서 사라진다. (원인: 상태 필터 기본값이 `submitted`("새 주문(접수됨)") — 확인하면 `received`로 바뀌어 필터 밖으로 빠짐)
3. 지난 주문서가 보이지 않는다. (같은 원인 + 기간 조회 없음)
4. 메뉴 이름이 "주문 확인"이 아니라 **"주문 관리"**여야 하고, 주문을 관리할 수 있어야 한다.

## 할 것 (Owner Domain: order · 파일: `app/orders/page.tsx`, `components/order-inbox-workspace.tsx`, 메뉴 한 줄 `lib/customer-navigation.ts`)

1. **이름**: 메뉴·페이지 제목 "주문 확인" → "주문 관리". 메뉴 설명 "매장 주문 접수·확인·배송 관리".
2. **목록 기본 = 전체 + 최근 30일**, 상태 탭으로 바꿈: `전체 | 새 주문 n | 확인됨 | 배송 중 | 배송 완료 | 취소`(개수 표시). 기간: 오늘 · 내일 배송 · 이번 주 · 30일 · 직접 선택(배송일 기준/접수일 기준).
3. **[확인] 눌러도 사라지지 않음**: 행은 그대로 두고 상태 배지만 "확인됨"으로 바뀜(필터가 "새 주문"일 때도 이번 화면에서는 남기고 흐리게 + "확인됨" 표시, 새로 고침하면 빠짐).
4. **주문 상세**: 행(매장명·주문번호) 클릭 → 상세 화면(또는 오른쪽 패널). 내용: 주문번호·접수 시각·배송일·매장·배송지·적치 위치·배송 연락처(#1439 값, 비밀번호는 있음/없음만)·주문자·요청사항·품목 표(품목·규격·단위·수량·단가·공급가·세액·합계·행사 배지)·합계·상태 이력·매출 전표 연결 상태. 기존 `components/storefront-order-detail.tsx`가 맞으면 재사용.
5. **상태 관리**: 상세에서 다음 단계 버튼 하나 — 접수됨 → [확인] → 확인됨 → [배송 출발] → 배송 중 → [배송 완료] → 배송 완료. 취소는 접수됨·확인됨에서만, 사유 필수. 서버에 상태 전이 함수가 없으면 **새 DB 함수는 SQL 초안까지만**(운영 적용은 대표 승인) 하고, 이미 있는 확인 처리만 먼저 연결.
6. **매장 쪽과 같은 상태 이름** (`domains/order/store-order-status.ts` 라벨 하나) — CX-153 매장 "배송 확인" 화면과 같은 단계가 보여야 함.
7. 엑셀·인쇄·열 편집은 유지. 출고 준비(`/orders/fulfillment`)와 겹치는 기능은 만들지 말고 상세에서 "출고 준비로" 링크.
