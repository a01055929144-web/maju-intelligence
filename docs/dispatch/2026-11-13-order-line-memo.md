## 1. 요청 종류 4가지 — 종류가 "누가 보는지"를 정한다

| 종류 | 뜻 | 예 |
| --- | --- | --- |
| **상품** | 크기·상태·손질 | 오이 큰 걸로, 덜 익은 걸로, 껍질 벗겨서 |
| **포장** | 나눠 담기·용기 | 소분해 주세요, 1kg씩 나눠서, 박스 말고 봉투 |
| **배송·보관** | 넣는 곳·시간·취급 | 냉동고에 넣어 주세요, 냉장 보관, 깨지기 쉬움 |
| **불만** | 지난 입고 문제 | 지난번 상태 안 좋았어요, 양이 적었어요 |

칩을 누르면 종류가 자동. 직접 쓴 글은 기본 "상품", 점주가 바꿀 수 있음(작은 선택).

## 2. 자주 쓰는 문구 (칩)

한 번 누르면 들어가고, 다시 누르면 빠짐. 칩 + 직접 쓰기 합쳐 **50자**.

| 종류 | 칩 (기본 제공) |
| --- | --- |
| 상품 | `큰 것으로` `작은 것으로` `덜 익은 것으로` `잘 익은 것으로` `손질해서` |
| 포장 | `소분해 주세요` `따로 담아 주세요` |
| 배송·보관 | `냉동 보관` `냉장 보관` `깨지기 쉬움` `문 앞에 두세요` |
| 불만 | `지난번 상태 불량` `지난번 양 부족` |

- 고객사가 설정에서 칩을 **추가·이름 변경·숨기기**(품목 분류별로 다르게는 나중에). 기본 칩은 지울 수 없고 숨기기만.
- 점주가 같은 품목에 지난번 쓴 요청은 다음 주문에 **"지난번 요청 다시 쓰기"** 한 번 누르기.
