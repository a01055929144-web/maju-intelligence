# CX-139 새 매장 첫 화면이 비지 않게 (11/24 17:04 대표 결정: "다")

**고객 행동:** 매장이 단가표 QR → 카카오 가입 → 매장 등록을 마치면 **바로 그 단가표와 전체 상품(가격 포함)을 보고 주문**한다.
**Owner Domain:** store(매장 포털) · Related: pricing(공유 링크), customer · 담당: Claude Code · CX-138 U1(#1392) 다음, U2~U6보다 먼저.

## 11/24 대표 시험(홍곱창 신촌점)에서 확인된 원인
1. **가격 숨김:** CX-122 적용(11/23) 후 `cx123_store_price_visible` → `store_price_visible_v1` = 매장 `price_visibility_status='confirmed'`일 때만 가격. 새 매장은 모두 `pending` → 회사가 [외식업 확인] 누르기 전 가격·상품이 안 보임.
2. **받은 문서 없음:** 매장 홈 문서 = 그 매장 고객 앞 `storefront_links` + (가입이 공유 링크에서 시작된 경우) `store_owner_activation_requests.share_link_id` 원본 문서. 홍곱창은 11/10 가입이라 둘 다 없음(storefront_links 0).
3. **전체 상품 없음:** 전체 상품은 `storefront_links source=catalog` 링크가 있어야 보임. 회사 플래그 `FEATURE_STORE_CATALOG_LINK_COMPANY_IDS`가 운영에 없음 → 링크 관리 화면에 "전체 상품 링크" 선택지도 안 보임.
