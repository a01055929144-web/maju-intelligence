"포장 공산품" 구분이 필요하면 분류가 아니라 상품 **태그/속성**으로(이번 범위 밖). 단위 테스트: 별칭 전부가 표준 경로로 바뀌고, 표준 체계에 같은 이름 소분류가 두 대분류에 중복되지 않음(`장류`·`소스·드레싱`·`커피·차` 등 검사).
2. **중복 점검 화면**: 상품관리 › 분류·마진 탭에 "비슷한 분류 점검" 카드 — 같은 소분류 이름이 다른 대분류에 있음 / 체계에 없는 대분류 / 하위가 빈 상품을 보여 주고, [합치기](= 폴더 이동 RPC, 합치기 확인·판매가 재계산)로 바로 처리.
