## 2. 규칙 (대표 결정)

### 2-1. 확정 = 주문 확정 (돈이 생기는 순간)

| 시점 | 전표 | 원장 | 재고 |
| --- | --- | --- | --- |
| 매장 장바구니 | 없음(확정 아님) | — | — |
| **매장이 "주문하기"로 주문 확정**(온라인, `submitted`) | 매출 전표 **확정** 자동(`source_key='order:<id>'`, 멱등) | 매출 + (미수) | 출고 − |
| **직원이 전화·카톡 주문을 수기 전표로 저장**(오프라인) | 저장 = 확정(같은 규칙) | 매출 + | 출고 − |
| 확정 뒤 수정(매장이 접수 전 고침 · 유통사 결품·수량 조정 · 시가 단가 변경) | **전표 수정(revision +1)** | **차액만** 원장에 1건 | 차액만 재고 |
| 세금계산서 발행 뒤 | 수정 막힘(기존 잠금) → 반품·추가 전표로 | | |
| 취소 | `cancel_business_document` | 반대 금액 | 되돌림 |
| 일부 반품 | 반품 전표(`sale_return`, 원전표 연결, 줄·수량 선택) | 매출 − | 입고 + |

- 확정 처리가 실패하면 주문은 들어가되 주문 확인 화면에 **"전표 연결 실패 · 다시 시도"**(숨기지 않음, 멱등 재시도). 실패한 주문은 유통사 "접수"를 막는다.
- **단가 규칙**: 모든 줄 단가 필수. 시가 줄은 확정 때 **매입가 기준 제안 단가**(매입가 + 그 상품 마진, 기존 가격 계산 재사용)로 넣고 표시 `시가(제안)` — 유통사가 실제 단가로 바꾸면 전표 수정(차액 원장). **0원은 유통사가 무상 사유(`보충 · 샘플 · 서비스 · 기타`)를 고른 줄만**(매장은 0원 줄을 만들 수 없음). 사유는 줄 메모.

### 2-2. 명세서 출력 = 발행 기록 (원장과 별개)

- 출력(거래처용·내부 보관용 모두, PDF 저장 포함)은 원장·재고를 바꾸지 않고 **발행 기록**만: 처음 발행 시각·누가·횟수 → `business_document_events`(kind `printed`, 몇 번째 revision을 찍었는지).
- 발행 뒤 전표가 수정되면 **"재발행 필요"** 표시. 주문 확인·전표 목록에 "명세서: 미발행 / 발행 n회 / 재발행 필요" 칸.
- **묶음 출력**: 날짜 + **차량별** · **담당자별** · 선택한 여러 주문. 차량 = 거래처의 배송 단위(`delivery_route_units.current_vehicle_id`), 담당자 = 전표 담당자 스냅샷. 차량별은 코스 순서가 있으면 그 순서, 없으면 거래처명 순. 한 번에 인쇄, 각 전표에 발행 기록.

### 2-3. 수령 확인 (서명 — 미수 분쟁 대비)

- **온라인(매장 화면)**: 그날 받은 전표의 품목·수량·단가·금액·총액을 보여 주고 **[이상 없음 확인]** 한 번 = 전자 수령 확인(누가·언제·어느 revision). 확인 뒤 전표가 바뀌면 "다시 확인 필요".
- **[이상 있음]**: 품목·수량·메모 → 유통사 주문 확인 화면에 알림 → 수정·반품으로 처리.
- **오프라인**: 종이 명세서에 서명 → 직원·기사가 사진을 찍어 그 전표에 첨부(선택, 기존 첨부 저장소). 없으면 "수령 확인 없음".
- 미수(원장) 화면에 전표별 **수령 확인 상태**(확인 · 이상 신고 · 없음 · 사진).

### 2-4. 과세·면세와 세금계산서 (대표 결정 + 11/16 확인)

- **상품은 줄마다 과세/면세 구분 그대로**(주문 줄 `tax_type` → 전표 줄). 직접 재배가 아니어도 가공하지 않은 식료품의 공급은 면세(부가가치세법 제26조) — 유통도 같음.
- **배송비 = 과세 줄 1개**(대표 결정). 참고: 상품에 딸린 배송은 원칙상 그 상품 공급에 포함되지만(부수 용역, 제14조), 과세로 처리하는 것은 세금을 덜 내는 쪽 위험이 없는 보수적 선택. 세무사 확인 권장.
- 명세서에 **과세 소계(공급가액·세액) / 면세 소계** 따로 표시.
- 세금계산서 초안은 **과세 줄 → 세금계산서, 면세 줄 → 계산서**로 나눠 만든다. 기존 세금계산서 초안 기능이 면세를 어떻게 다루는지 먼저 확인하고, 섞여 있으면 둘로 나누는 것을 CX-39에.
