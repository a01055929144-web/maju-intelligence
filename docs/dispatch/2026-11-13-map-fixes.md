# CC-42 지도: 거래처 마커 · 필터 바꿀 때 화면 튐 · 규모 필터 (2026-11-13 20:29 대표)

## 1. 거래처 마커가 안 보임 — **대부분 데이터 문제**

- 운영 조회(11/13 20:3x): 제이에스리테일 `normalized_customers` **1곳**(거래중), 비브 0곳. 거래처 가져오기 기록(`customer_imports`) 42건은 있으나 실제 거래처 행은 1곳 — 11/3 운영 정리 이후 거래처를 다시 올리지 않은 상태.
- 즉 지도에 그릴 거래처가 1곳뿐. **대표 작업: 매출처(거래처) 엑셀을 화면에서 업로드**(개인정보라 채팅·저장소 금지 규칙).
- Claude Code 확인(42a): 그 1곳이 등급별 보기·리드 유형 필터(`mapLeadTypeFilter` 기본 'new', 726줄)와 무관하게 보이는지, 주소 좌표 변환 실패 시 "좌표 못 찾은 거래처 N" 안내가 있는지. 거래처 0~1곳일 때 지도 위 안내 "거래처가 1곳입니다 · [거래처 올리기]".

## 2. 신규·영업 필터를 바꾸면 출발지로 화면이 이동 — 버그 (42a)

- 원인: `kakao-address-map.tsx` 마커 구성이 바뀌면(`markersSignature`) 지도를 다시 만들고 끝에 `fitViewport()` 실행 → 리드는 자동 범위에서 빠지고(648줄 `primaryFound`) 거래처가 1곳·0곳이라 **출발지 1점에 맞춰 레벨 5로 이동**.
- 고칠 것: **처음 열 때·`전체 보기` 버튼·검색 결과로 이동할 때만** 화면 맞춤. 필터·보기 바꾸기는 마커만 바꾸고 지금 화면(중심·확대)을 유지. 지도 재생성도 하지 않고 마커 레이어만 교체.
- e2e: 확대·이동 → 신규/영업 전환 → 중심·레벨 그대로.

## 3. 규모 필터가 없음 — 데이터가 0.4%뿐이라 스위치 꺼둠 (42c)

- 운영: 제이에스리테일 리드 11,709곳 중 **면적 있는 곳 48곳**, 비브 0곳. 원천 기록 중 정부 인허가 API(`gov_restaurant_api`) 기록에만 `storeAreaSqm`이 있고(498건 중 116건), 서울 열린데이터·카카오 검색 기록엔 면적이 없음.
- 고칠 것:
  1. 면적 보강 스크립트(정부 인허가 API, 이미 쓰는 키·호출 한도 그대로): 리드의 `source_record_key`로 면적 조회 → `store_area_sqm` 채움. **먼저 건너뛰기 실행(dry-run)으로 채워질 수 예상** → 컨트롤타워 검토 → 대표 승인 문구 → 실행(cron 06:00~07:30 피함).

## 4. 검색 결과를 검색창 아래가 아니라 옆 목록에 (42b, 20:58 대표)

- 지금: 검색하면 검색창 아래 **떠 있는 목록**(거래처·리드·카카오 미등록 매장 섞임, 줄마다 `거래처로 등록`)이 지도를 가림. 오른쪽 패널(`신규 · 영업 · 거래처` 탭 + 목록)은 그대로라 같은 정보가 두 곳.
- 바꿀 것 (네이버 지도처럼):
  1. 검색어를 넣으면 **오른쪽 패널이 `검색 결과` 탭으로 바뀜**(탭 줄 맨 앞, `검색 결과 N ×`). 검색창 아래 떠 있는 목록은 없앰(자동완성은 최근 검색어 5개만).
  2. 결과는 묶음으로: **거래처 N** → **영업 리드 N** → **신규 리드 N** → **카카오 미등록 매장 N**(지금 `kakao_keyword_search` 결과). 묶음 제목 누르면 접기.
  3. 줄: 상호 · 주소 · 업종 · 상태 칩 · 오른쪽 동작(거래처 → `지도에서 보기`, 리드 → `상세`, 미등록 → `거래처로 등록`). 체크 → 아래 `선택 N곳 거래처로 등록`(지금 일괄 등록 그대로).
  4. **줄에 마우스 올리면 그 마커 강조**, 누르면 그 마커로 이동(확대 유지·필요할 때만 레벨 5). 패널 위 `결과 전체 보기` 버튼을 눌렀을 때만 결과 전체에 화면 맞춤(42a 원칙 — 검색만으로 화면이 튀지 않음).
  5. 지도 위 결과 마커는 **번호 핀**(1·2·3…)으로 목록 번호와 같게, 이름표는 겹치면 숨기고 마우스 올릴 때만(지금 주황 이름표가 겹쳐 읽기 어려움).
  6. `×` 또는 Esc → 검색 지우고 **이전 탭·이전 화면 위치로 복귀**.
  7. 휴대폰(390): 패널 대신 **아래에서 올라오는 목록**(반 높이, 끌어서 전체), 같은 묶음·동작.
- 재사용: 지금 검색 함수(거래처·리드·카카오 결과 합치는 부분, `sales-route-map-workspace.tsx` 1126~1138줄 근처)·일괄 등록 로직 그대로, **표시 위치만** 오른쪽 패널로. 지도 파일이 11,468줄이라 새 부품 `components/map-search-results-panel.tsx`로 분리해서 넣을 것(D-6 지도 분리 방향).
