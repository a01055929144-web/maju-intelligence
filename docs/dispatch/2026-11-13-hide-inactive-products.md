## 증상

## 원인 (운영·코드 확인)

- 상품관리 삭제(CC-24)는 **쓴 적 없는 상품만 완전 삭제, 문서·매입 기록에 쓰인 상품은 숨김(`product_catalog.is_active=false`)**. "2026/10 계"는 쓰인 적이 있어 숨김 처리됨(11/13 11:56). 제이에스리테일 숨김 상품 2개, 둘 다 `pricing_items` 행 있음.
- 판매가 표(`components/pricing-sales-price-table.tsx` 34줄)는 숨김 상품도 목록에 넣고 이름 옆에 "(비활성)"만 붙임 → 분류 개수·칩 개수·선택·일괄 변경·"이 판매가로 단가표 만들기"에도 섞임.

## 고칠 것

1. 판매가 표·카탈로그 상세·매장 가격의 품목 목록: **숨김 상품 기본 제외**(개수·분류 트리·칩·손해 경고·"아직 반영 안 된 변경 N" 포함).
2. 표 위 작은 칩 `숨긴 상품 2` → 누르면 숨김만 보기(회색, 가격 칸 잠금, `다시 판매` 버튼은 상품관리로 이동 링크).
3. "이 판매가로 단가표 만들기"·문서 품목 고르기(`pricing-product-picker`)·매장 주문 화면에서 숨김 상품이 빠지는지 확인(storefront는 이미 `is_active` 거름 — 나머지 두 곳 확인·보완).
4. 상품관리 삭제 완료 문구를 "N개 완전 삭제 · M개 숨김(문서·매입 기록에 쓰여 보관 — 가격·문서·주문 화면에서 안 보임)"으로.

5. **(20:13 대표) 손해만 골라 보기**: 지금 "손해 N개 — 이익이 0원 이하" 문구(`pricing-sales-price-table.tsx` 75·101줄)는 개수만 보여 줌. 기존 칩 줄(`바뀐 상품` · `고정 가격`)에 **`손해 N`(빨강)** · **`이익 낮음 N`**(이익률이 기본 마진의 절반 미만, 노랑) 칩 추가 — 누르면 그것만 표에. 경고 문구는 눌러지는 링크로 같은 필터를 켬. 0개면 칩 숨김. 숨김 상품은 세지 않음(1번).
   - 같은 칩을 매장 가격·카탈로그 상세 표에도(같은 부품이면 자동).
   - 이익률 기준은 `domains/pricing`에 한 곳(화면에 숫자 하드코딩 금지).
