# CC-44 공용 표 키보드: 엑셀처럼 상하좌우 이동·단축키 (2026-11-13 20:31 대표)

> 컨트롤타워 설계 · 담당 Claude Code. 공용 부품(`components/common-data-table.tsx`) 한 곳 → 공용 표 14개 화면 자동. DB 없음. 선행: CC-38a(선택·번호), CC-41(금액칸 — `type="number"`가 ↑↓로 값을 바꾸는 문제 제거).

## 지금

- 표 안 키보드는 **열 너비 조절(←→)뿐**. 칸 사이 이동은 Tab으로 입력칸만 순서대로, 줄 이동·선택·복사 단축키 없음. 금액칸 일부는 `type="number"`라 ↑↓를 누르면 **값이 1씩 바뀜**(실수 위험).

## 동작 (엑셀과 같게)

| 키 | 동작 |
| --- | --- |
| ↑ ↓ ← → | 칸 이동(현재 칸 진한 테두리). 입력 중이면 ↑↓는 **저장하고 위/아래 칸으로**, ←→는 글자 안에서 움직이다 끝에 닿으면 옆 칸으로 |
| Enter | 입력칸이면 편집 시작 → 다시 Enter = 저장 후 **아래 칸**(같은 열 연속 입력) · Shift+Enter = 위 칸 |
| Tab / Shift+Tab | 저장 후 오른쪽/왼쪽 **입력칸** |
| Esc | 입력 취소(원래 값) · 편집 아니면 칸 선택 해제 |
| F2 또는 글자 입력 | 그 칸 편집 시작(글자 입력은 덮어쓰기) |
| Space | 현재 줄 선택 켜기/끄기(1열 체크) |
| Shift+↑↓ · Shift+클릭 | 여러 줄 범위 선택 |
| Ctrl/⌘+A | 지금 걸러진 줄 전체 선택(표에 초점 있을 때만) |
| Ctrl/⌘+C | 선택 줄(없으면 현재 칸)을 엑셀에 붙일 수 있게 탭 구분 복사(보이는 열·번호 포함) |
| Home / End · Ctrl+Home / Ctrl+End | 줄 처음/끝 · 표 처음/끝 |
| PageUp / PageDown | 한 화면씩, 페이지 끝이면 다음 페이지 |
| `/` | 표 검색칸으로 |
| `?` | 단축키 도움말(작은 창) |

- 마우스로 칸을 누르면 그 칸이 현재 칸. 스크롤은 현재 칸이 보이게 자동.
- 표 밖(검색칸·메뉴·서랍)에 초점이 있으면 표 단축키 안 먹음. 브라우저 기본 단축키(⌘+F 등) 막지 않음.
- 휴대폰 카드 보기는 해당 없음(터치).

## 붙여넣기 (2단계, 44b)

- 엑셀에서 한 열을 복사해 판매가·마진 칸에 Ctrl/⌘+V → **미리보기 창**("12줄 바뀜: 이전 → 새 값") → 확인해야 저장(100개씩 나눠 보냄, CC-38a 규칙). 형식이 틀린 줄은 빨강·건너뜀. 실수 방지가 더 중요해서 확인 없이 바로 저장하지 않음.
