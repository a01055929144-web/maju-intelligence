## 11/20 실제 API 검증에서 확인한 CX-121 게시 관문

- #1211 서버 계약은 병합됐지만 #1109의 실제 API·격리 PG17 시험에서 **연장 초안을 저장한 뒤 일반 publish로 새 버전을 만들 수 있는 우회**가 확인됐다. 기대 결과는 `409`와 기존 버전 2건 유지였으나, 수정 전 결과는 `200`과 버전 3건이었다. 따라서 #1109는 Draft를 유지한다.
- 06방은 기존 일반 게시 서버 경계에서 연장 초안의 재검토 토큰·revision을 검증하는 #1215 후속을 우선 처리한다. 09방은 화면 파일과 실패 회귀를 보존하고, #1215 병합 뒤 **실제 API 처리기·서버 저장소·격리 PG17** 경로에서 우회가 차단되는지 다시 확인한다. SQL만 직접 호출한 시험 또는 화면 버튼 차단만으로는 완료로 보지 않는다.
- 통과 기준: 재검토 없는 일반 publish는 새 버전·연장 게시 기록·기존 발행본·과거 주문을 변경하지 않는다. 정상 연장 게시, 같은 요청 재시도, 다른 회사 접근 거절도 유지한다. 전체 CI와 1440/390 화면 시험이 초록이고 배포 잠금이 없을 때만 #1215 → #1109 순서로 병합한다.
