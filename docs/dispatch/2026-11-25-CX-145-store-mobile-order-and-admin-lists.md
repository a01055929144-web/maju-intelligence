# CX-145 — 매장 모바일 주문 정리 · 매출처 틀 통일 · 관리자 점주/매장 목록 (2026-11-25 대표 피드백)

대표 실사용 테스트(홍곱창, 카카오 로그인, 11/25 17:37) 결과. 한 PR = 한 고객 행동, 순서대로. 새 화면은 기존 공통 컴포넌트 재사용, 기능 플래그는 기존 것 사용(대표 회사 ON 상태).

## 우선 1 — S1 매장 주문 불가 (P1)
- 증상: 홈에 받은 단가표 품목·가격은 보이는데 [주문] 탭은 "아직 주문 가능한 단가표가 없습니다".
- 확인된 사실(운영): 이 매장의 storefront_links = catalog 링크 1개(f5a07a24…, can_order=true, 11/25 발급) + document 링크 1개(11/24 "전부 회수"로 revoked). 주문 탭은 document 링크만 보는 것으로 보임 → catalog 링크와 관계 기준 받은 단가표(CX-141 readStoreRelationHome)를 주문 대상으로 못 씀.
- 할 일: 주문 탭 = 받은 단가표 / 전체 상품(catalog) 중 고름 → 품목 수량 → 주문 확인 → 주문. 가격은 self_order_price_v2(약속가→카탈로그→기본) 그대로. 회수된 문서 링크에 의존하지 않기. e2e(모바일 390) 주문 1건 성공 시나리오 필수.

## 우선 2 — S2~S4 매장 홈 모바일 정리 (한 PR)
- S2 행사·임박 상품: 표기·시인성이 약함. 목록 행에 [행사] 배지 + 기한을 같은 줄에, 가격 옆. 별도 노란 카드 묶음 대신 목록 상단 고정 + 배지.
- S3 홈 하단 "MAJU 매장 / 홍곱창 신촌점(배송지 주소·구성원·견적서·단가표와 주문)" 카드 제거 → 배송지·구성원은 [매장 정보] 탭에만.
- S4 받은 문서를 인쇄용 문서(2열 표·회사 머리글)로 그대로 넣은 "공유 문서" 화면 걷어내기 → 품목 목록 한 형식(품목·규격·단위 / 가격 / 과세 여부)으로 통일. 원본 문서는 "원본 보기" 링크로만.
- 목표: 모바일에서 홈 → 품목 확인 → 주문까지 한 손으로 깔끔하게.

## 우선 3 — 고객사 화면
- C2 매출처(거래처) 목록에서 상호를 누르면 그 매장 상세로 바로 이동(지금은 겉돎).
- C1 매출처 화면 레이아웃을 매입처와 같은 틀(같은 공통 셸·탭·목록 표)로 교체. 예전 /crm/timeline 레이아웃 정리(기능은 유지, 위치만 이동).
- C3 매장 초대: "매장 점주 개통 링크 만들기" 대신 **고객사 직원 초대와 같은 방식**(기존 초대 컴포넌트·흐름 재사용)으로 간단하게. 초대 유효시간 30분은 너무 짧음 — 직원 초대와 같은 기준으로. 서버 경로(prepare/activate, CX-142 마무리)는 재사용.
