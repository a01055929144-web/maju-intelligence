## CX-00 Ponytail 검토방 — Claude Code PR 점검 (상시 · 최우선 응답)

- **대상**: 제목이 `[CC-*]`이고 본문에 `Ponytail: 검토 요청`인 Draft PR.
- **할 일**: 해당 브랜치를 받아 Ponytail로 점검 → 최소 변경·재사용·중복 제거·죽은 코드 제거를 **같은 브랜치에 보완 커밋**(기능 범위·화면 구성은 바꾸지 않음) → 로컬 검증(tsc·lint·test·build·auth-boundaries) → PR 본문 첫 줄을 `Ponytail: 사용함 (Codex 검토)`로 바꾸고 점검 요약(바꾼 것 / 그대로 둔 이유) 코멘트.
- **범위 밖 발견**: 고치지 말고 PR 코멘트 + 현황판 "막힘/후속"에 적는다.
- **추가(여유 시)**: Claude가 11/03~11/05 직접 만든 PR #223~#246 중 `docs/qa/20261106-ponytail-category-pricing-review.md`에 포함되지 않은 범위를 표로 정리하고, 필요한 정리 PR을 `codex/CX-00b-*`로 작게 나눠 올린다.
