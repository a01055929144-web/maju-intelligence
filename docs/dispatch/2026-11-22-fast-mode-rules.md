# 빠른 모드 운영 규칙 (대표 지시 · 2026-11-22 17:00부터)

컨트롤타워가 대표 승인 없이 할 수 있는 일과 계속 승인을 받아야 하는 일을 나눈다. 기능 구현은 Codex 몫이다.
README [승인 경계](README.md#승인-경계-모두-공통--변경-없음)는 아래 "계속 대표 승인" 항목이 우선하며, 이 문서는 그 위에 얹는 미리 승인 범위다.

## 미리 승인 (대표가 매번 묻지 않아도 되는 일)

| 구분 | 규칙 |
|---|---|
| 운영 배포 | 매일 **12:00 · 18:00** 묶음. **main CI 초록일 때만.** 배포 순서는 README "배포 담당"(잠금 줄 → CI 확인 → 배포 → 스모크 → 기록)을 그대로 따른다 |
| 배포 후 확인 | `/login` `/dashboard` `/leads` `/revenue/pricing` `/revenue/products` `/store` 스모크 + 오류 로그 |
| 회귀 | 직전 READY 배포로 **즉시 되돌림** |
| 장애 수정 | 시각과 상관없이 **즉시 단독 배포** |
| 기능 켜기 | **대표 회사에만, 돈이 오가지 않는 기능**: 배포 후 켜고 보고 |
| PR 병합 | 기능 OFF 코드 PR · 문서 PR: CI 초록이면 병합 |
