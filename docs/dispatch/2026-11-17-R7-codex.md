## CX-62 상세 — 매출 전표는 고객사가 "접수"할 때 만든다
1. `app/api/storefront/route.ts`: 매장 주문 저장 · 수정 때 `syncStoreOrderSaleDocument`를 **부르지 않습니다**. 주문은 `submitted` 상태로만 저장합니다.
2. `app/api/orders/route.ts` "접수"(confirm)
   - 순서: `confirm_order_sale_document`(+ revision > 1이면 `revise_order_sale_document`) → 전표 연결 확인 → `status = received`
   - 전표가 실패하면 접수하지 않고, 지금처럼 "전표 연결 다시 시도"를 띄웁니다.
   - 같은 요청을 두 번 보내도 전표는 1건이어야 합니다(RPC가 멱등).
3. 접수 뒤 수정 · 취소: 접수된 주문을 매장이 고칠 수 없으면 지금 그대로 둡니다. 고객사가 고치면 `revise_order_sale_document`, 취소하면 전표 취소(역분개)를 씁니다. 이미 있는 흐름이면 시험만 추가합니다.
4. **스위치 하나로 합치기**: `erpOrderDocumentsEnabled`를 `isFeatureEnabled("ERP_ORDER_DOCUMENTS", companyId)`로 바꿉니다. 옛 env(`ERP_ORDER_DOCUMENTS` · `ERP_ORDER_DOCUMENTS_COMPANY_IDS`)는 읽지 않게 하고 PR에 적습니다.
   - **이 PR이 배포되면 제이에스리테일은 전표 생성이 켜집니다**(15:3x에 `FEATURE_ERP_ORDER_DOCUMENTS_COMPANY_IDS` 설정됨). 그래서 1 · 2와 같은 PR로 냅니다.
5. 시험
   - 주문 저장만으로는 전표 0건
   - 접수 → 전표 1건 · 원장 · 재고 반영
   - 접수 두 번 → 1건
   - 전표 실패 → 주문 `submitted` 유지
   - 수정된 주문 접수 → 최신 revision 기준

- 탭 또는 필터: **받은 단가표 / 받은 견적서 / 전체 상품**. 위에 검색창(품목명 · 규격) 하나를 둡니다. 공용 표(CommonDataTable)를 씁니다.
- 줄마다 **확정 단가**를 보여 줍니다. 단가표 · 견적서 · 등급 · 계약 단가 중 서버 규칙(`lib/pricing/storefront.ts`와 같은 순서)으로 고릅니다.
- 확정 단가가 없는 품목(전체 상품): **"최근 출고가 11/12 9,800원(참고)"**를 보여 줍니다. 기존 `recentPrices`를 다시 쓰고, 이 매장에 나간 출고(매출 전표 · 접수된 주문 줄) 기준입니다. 출고 이력도 없으면 "단가 문의"를 보여 줍니다.

- 스위치: `STORE_RECEIVED_DOCUMENTS_HOME`(제이에스리테일 켜짐).

## CX-64 상세 — 전표 쉽게 삭제 (매출 · 매입 모두, 주문에서 온 것 · 직접 입력한 것 모두)
- 목록과 상세에 **[삭제]** 버튼 하나를 둡니다.
  - 작성중: 지금처럼 바로 지웁니다.
  - **확정: "삭제" = 취소(원장 · 재고 되돌림)**입니다. 사유는 선택 입력이고, 비우면 "삭제"로 기록합니다. `window.prompt`는 쓰지 않고 확인 창(`useConfirm`) 한 번으로 끝냅니다.
  - 확정 전표를 행째 지우지는 않습니다(장부 추적 · 세금계산서 때문). 대신 취소된 전표는 **목록 기본 필터에서 숨기고** "삭제한 전표 보기"로만 봅니다.
- 주문에서 온 매출 전표를 지우면, 그 주문을 "접수 전(`submitted`)"으로 되돌릴지 "주문 취소"로 할지 확인 창에서 고르게 합니다. 기존 RPC로 되면 DB를 바꾸지 않습니다. 안 되면 SQL 초안 + down + PG17로 따로 냅니다(운영 적용은 대표 승인).
- 여러 건을 고르고 한 번에 삭제할 수 있게 합니다(공용 표 선택).
- 반품 · 수금이 연결된 전표는 삭제를 막고 이유를 보여 줍니다. 예: "수금 1건이 연결돼 있습니다".
- 시험: 작성중 삭제 · 확정 삭제 → 원장 · 재고 되돌림 · 목록에서 숨김 · 연결 있으면 막힘 · 주문 되돌리기.
