## CX-34 `lib/store.ts` 분리 1단계 — 순수 함수만 (03)

[분리 계획](../architecture/2026-11-15-store-ts-split-plan.md) "권장 이동 순서" 1번.

- 대상: DB·fetch·Supabase를 부르지 않는 순수 함수(주소·이름 정규화, 기간 계산, 상태 결정, 파일명·경로 정리). 계획 문서 배정표대로 `domains/<도메인>/` 아래로 옮기고, **`lib/store.ts`에서 같은 이름으로 다시 내보낸다**(호출부 import 변경 없음).
- 한 PR = 한 도메인 묶음, `lib/store.ts`에서 줄어드는 줄 수를 PR 본문에. 단위 시험은 함께 이동(Vitest `domains/*` 안은 상대 경로 import).
- **이 작업 동안 `lib/store.ts`는 03방만 고친다**(다른 방·Claude Code는 손대지 않음). PR은 한 번에 하나만 열기.
- Do Not Touch: `supabaseRequest` 계열 · RLS·회사 범위 확인 함수 · 감사 기록 함수 · `convertPermitLeadToCustomer`(Claude Code 48-5 예정).
- 완료: 동작 변화 없음(전체 시험 통과 + `npm run check:auth-boundaries`), `lib/store.ts` 줄 수 감소.
