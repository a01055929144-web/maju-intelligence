### 원인 (`lib/store.ts` 9800~9935행 `syncGovRestaurantLeads` · `lib/gov-area-fanout.ts`)

1. **요청 제한 12초가 너무 짧다**(`GOV_REQUEST_TIMEOUT_MS = 12_000`) — 큰 구는 정부 API가 12초를 넘겨 매번 끊김, 재시도 없음(`retry: false`).
2. **실행 전체 예산 40초**(`GOV_COLLECTION_BUDGET_MS`, 후처리 10초 빼면 요청 30초) · 동시 3 → 12초짜리 두 바퀴면 끝, 나머지 지역은 매번 "이월".
3. **이월이 다음 실행으로 실제로 넘어가지 않는다**: 다음 실행은 `status=eq.success`인 실행의 `areaCursors`만 읽음 → 실패·부분 실행에서 진행한 커서와 못 한 지역은 버려지고, 같은 순서(같은 큰 구부터)로 다시 시작 → **같은 지역에서 매일 막힘**.
4. 실패 알림이 약함: "이틀 연속 0건" 경고는 성공 실행 뒤에만 걸림 — 일반음식점이 나흘째 0건이어도 화면 경고 없음.
