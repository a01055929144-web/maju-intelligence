## 바꿀 것

### 1. 1열 선택 · 2열 번호 (모든 공용 표 기본)

- **선택(40px)**: 머리 체크 = 지금 걸러진 줄 전체 선택(페이지 넘어도 유지, "전체 N개 선택됨 · 해제"). 고정 열(좌우로 밀어도 안 움직임).
- 선택하면 표 위에 **공통 일괄 도구 띠**(문서 편집기 띠와 같은 모양): `선택 N개` · **엑셀 내려받기** · **인쇄** · 화면별 동작(prop `bulkActions`로 화면이 추가 — 예: 상품관리 숨기기, 매장 가격 기간 바꾸기, 링크 회수) · `선택 해제`.
- 화면이 이미 자체 선택을 쓰면(`selection` prop) 그것을 우선, 없으면 부품이 내부 상태로.
- **번호(48px)**: 지금 걸러진·정렬된 순서의 1부터(페이지 2면 101부터). 오른쪽 정렬·회색. 끌기·숨기기 없음. 엑셀 내려받기에 "번호" 열 포함.
- 휴대폰 카드 보기(`phoneCards`)는 카드 왼쪽 위에 체크만(번호 생략).
- 끄는 옵션: `selectable={false}`·`numbered={false}`(관리자 읽기 전용 표 등 꼭 필요할 때만).

### 2. 열 너비 끌기 — 좌우 스크롤 없이

- 머리글 칸 사이 경계에 **보이는 손잡이**(마우스 올리면 진한 세로선 + `↔` 커서, 손잡이 폭 8px).
- 끌면 **바로 오른쪽 열이 그만큼 줄어듦**(표 전체 폭은 그대로 → 좌우 스크롤 안 생김). 최소 48px, 오른쪽 열이 최소면 더 안 늘어남.
- 저장은 **비율(%)**로 — 화면 크기가 달라도 같은 모양. 열을 숨기거나 다시 켜면 나머지 비율로 다시 나눔.
- 더블클릭 = 그 열 내용에 맞춤(오른쪽 열과 나눔). 키보드 ←→ 유지.
- 지금의 "넓히면 좌우 스크롤" 동작 삭제. 열이 정말 많아 최소폭 합이 화면보다 클 때만 표 상자 안에서 좌우 스크롤(지금 규칙 유지).

### 3. 회사 고정 (고객사가 정하면 모두 같은 표)

- **대표·관리자**: 너비·열 순서·숨김·줄 높이·보기 개수를 바꾸면 **회사 전체에 저장**(놓을 때 자동 저장, 위 작은 글씨 "회사 표 설정에 저장됨 · 되돌리기"). 열 편집 메뉴에 `기본값으로 되돌리기`.
- **직원**: 회사 설정 그대로 봄. 손잡이·열 편집 숨김(바꿀 수 없음 = 고정). 정렬·검색·필터·선택은 자유(저장 안 함).
- localStorage는 회사 설정을 불러오기 전 깜빡임 방지용 캐시로만.
- 표마다 키: 지금 `settingsKey` 그대로(예 `pricing-sales:<회사>`) → DB 키는 `settingsKey`에서 회사 부분 뺀 이름.

## DB (SQL 초안 → 컨트롤타워 검토 → 대표 승인)

- `company_table_layouts(company_id, table_key text, layout jsonb, updated_by_user_id, updated_at)` PK(company_id, table_key). `layout` = `{columns:[{key,hidden,widthPct,pinned}], density, pageSize}` 크기 제한(16KB)·형식 체크.
- RLS 켜고 정책 없음(service_role만) · 읽기/쓰기는 서버 API `/api/table-layouts`(회사 구성원 읽기, 대표·관리자 쓰기, 회사 격리).
- 감사: 쓰기마다 `admin_audit_logs`(`table_layout_saved`, table_key).
- down: 테이블 삭제(설정만, 업무 데이터 아님).
