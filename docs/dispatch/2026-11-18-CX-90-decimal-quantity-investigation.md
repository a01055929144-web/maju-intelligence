# CX-90 소수 수량 단가 재집계

## 결론

- 생산 데이터는 읽기 전용으로 확인했으며 수정하지 않았다.
- 최신 업로드 `L3BZRFP12SX2ZJW.xlsx`의 활성 저장행은 1,368개다.
- 저장 수량 자체가 소수인 행은 0개다.
- `공급가액 ÷ 원문 단가`로 역산한 수량이 소수인 행은 258개다.
- 역산 수량 0.3은 25개, 0.25는 0개, 1.5는 8개다.
- 저장된 `unit_cost_ex_vat`가 원문 `unit_price`와 다른 행은 0개다. 따라서 이미 잘못 저장된 원가 행도 0개다.

## 원인 판정

원문 파일의 수량 열에는 정수가 들어오지만 공급가액은 실제 소수 중량을 반영한 행이 섞여 있다. 예를 들어 수량은 1로 표시되고, 공급가액은 원문 단가의 0.3배인 형태다. 이 경우 `공급가액 ÷ 표시 수량`으로 단가를 다시 계산하면 가격이 왜곡된다.

현재 저장 경로는 단가를 금액과 수량으로 재계산하지 않는다. 파서의 원문 단가를 날짜별 저장 요청의 `unitPrice`와 영수증의 `unit_price`에 그대로 전달한다.

## 회귀 방지

- 수량 0.3, 0.25, 1.5에서 원문 단가가 파서와 영수증 저장행에 그대로 유지되는지 검증한다.
- 같은 세 수량에서 날짜별 저장 요청의 `unitPrice`와 적용 원가가 원문 단가를 유지하는지 검증한다.
- 대표 확인 전에는 금액 로직 변경, 생산 데이터 보정, 기능 전환, 배포를 하지 않는다.
