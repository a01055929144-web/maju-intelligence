## 표준 v2

1. **좌우 스크롤 없음(PC 1280px 이상)**
   - 표 너비 = 상자 너비(`table-layout: fixed`, `min-w-max` 제거). 열 너비는 비율(가중치) — 이름·상품 같은 긴 열이 남는 폭을 가져가고 숫자 열은 내용 폭.
   - 긴 글자는 **두 줄까지 줄바꿈** 후 말줄임(마우스 올리면 전체).
   - 폭이 모자라면 **중요도 낮은 열부터 자동 숨김**(열 정의에 `priority` 1~3) + 표 머리에 "열 3개 숨김 · 열 편집" 안내. 좌우 스크롤은 휴대폰(카드 목록)과 사용자가 열을 직접 넓혔을 때만.
   - 칸 편집(마진·가격 입력)은 **숫자 칸 최소 96px 보장** — 좁아져도 입력칸이 잘리지 않게.
2. **세로는 페이지 스크롤** — 표 안 별도 스크롤 상자 제거, 머리줄은 화면 위에 붙음(`position: sticky; top: 헤더 높이`). 첫 열(상품·매장 이름)도 고정.
3. **보기 개수 `100 · 500 · 1000 · 전체`** (기본 100, 마지막 선택 기억 — 화면별 localStorage). 500개 이상은 **가상 스크롤**(보이는 줄만 그림)로 느려지지 않게. 서버 페이지인 화면(리드 등)은 "전체"를 최대 5,000개로 하고 넘으면 안내.
4. **검색창 기본 포함** — 표 위 왼쪽, 표 열 중 `searchable` 열(이름·코드·주소·전화 등)에서 찾기, 한글 초성 아님(일반 포함 검색), 입력 0.2초 뒤 반영, 개수 "검색 결과 N / 전체 M".
5. **큰 분류 필터 기본 포함** — 표에 분류가 있으면(상품 계열) **대분류 칩**(농산·축산·수산·공산품·비식품·기타, 분류 폴더 순서·개수) + **중분류 선택**. 매장 계열은 **매장 등급·카탈로그** 필터. 화면별 추가 필터는 칩으로 같은 줄에.
6. **필터 줄 한 줄 규칙**: `[검색] [대분류 칩…] [중분류 ▾] [화면별 칩] ······ [보기 100 ▾] [열 편집]`. 좁으면 줄바꿈, 휴대폰은 검색 + "필터" 버튼(아래 시트).
7. **선택**: 체크 열은 머리에 **전체 선택**(필터된 전체 vs 이 페이지 선택 구분 문구 "필터된 342개 모두 선택"), 선택 줄 툴바는 표 위에 붙음.

## 화면별 재점검 목록 (대표 캡처 기준)

**가격 관리 › 매장 가격** (`/revenue/pricing/store-prices`, 11:42 캡처)

- 왼쪽 매장 목록 320px(매장 1곳) → 표 위 **매장 선택 상자 + 검색**, 왼쪽 칸 제거.
- "등급 관리" → CC-32a대로 "카탈로그".
- 표 안 별도 세로 스크롤 상자 제거(P·표준 2).
- **데이터 이상**: 상품 "2026/10 계"(분류 기타, 기본 판매가 31,045,980원, 매입가 28,223,618) — 월 합계 줄이 매입가 업로드에서 상품으로 들어온 것. 1,000,000원 넘는 상품은 이것 1개. → 대표가 상품관리 › 삭제(CC-24)로 지우고 업로드 "다음에도 제외"(CC-24b). 재발 방지: 매입가 업로드 미리보기에서 상품명이 `계|합계|소계`로 끝나거나 날짜로 시작하는 줄·단가가 다른 줄 중앙값의 100배 넘는 줄은 **자동으로 "제외" 체크 + 주황 표시**.

**가격 관리 › 판매가 / 마진 설정** (`/revenue/pricing/margins`, 11:43 캡처)
- `max-w-6xl` → P1. 판매가 열이 잘림.
- 위 4줄(템플릿 칩 상자 · 기본 마진 + 큰 버튼 · "반영 안 된 변경 49개 [지금 반영] [직전 반영 되돌리기]" · 설명 상자) → P2~P4 한 줄. **"반영 안 된 변경 49개"**: 즉시 반영(CC-30a) 뒤에도 옛 대기분 49개가 남아 띠가 보임 → 한 번 반영 처리(컨트롤타워 확인 후)하고 띠는 0이면 숨김 유지.
