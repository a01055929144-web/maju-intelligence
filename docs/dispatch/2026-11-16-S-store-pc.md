## 2. 고칠 방향 — 매장이 스스로 주문 (대표 16:25)

**원칙: 링크 발급을 기다리지 않는다. 조건이 확인되면 매장이 바로 주문한다.** 링크(#토큰)는 비회원이 처음 들어오는 문(공유·가입)으로만 남긴다.

### 2-1. 주문 가능 조건 (모두 맞으면 주문 메뉴가 자동으로 열림)

| # | 조건 | 판단 근거(이미 있는 것) | 안 맞을 때 매장에 보이는 것 |
| --- | --- | --- | --- |
| ① | 매장 확인 | `store_accounts`: 사업자 상태 정상(`business_status_verified_at`) · 약관 동의 | "사업자 확인 필요" + 다시 확인 버튼 |
| ② | 거래처 연결 | `store_accounts.customer_review_status` = 확인(고객사 1번 확인). 회사 설정 **"새 매장 자동 확인"** 켜면 ①만으로 통과 | "유통사 확인 대기 중" |
| ③ | **배송 가능** | 배송지가 회사 배송 권역 안 + 그 권역 배송 요일·마감(`store_order_territory_rules`) | "이 주소는 배송 권역 밖입니다" / 다음 가능 배송일 |
| ④ | **결제 방법** | 회사 기본(`store_order_settings.payment_mode`) → 거래처별 덮어쓰기(`store_order_customer_rules.payment_mode`). 지금은 후결제만(선결제·카드는 결제 연동 뒤) | "결제 방법 확인 중" |
| ⑤ | **결제 조건**(후결제) | **새 칸 필요**: 결제일 규칙(예: 월말 마감 → 다음 달 10일) · 외상 한도(원, 비우면 한도 없음) — 회사 기본 + 거래처별 덮어쓰기. 한도 판정은 E 원장 미수 잔액으로(E 적용 전에는 한도 판정 끔) | "외상 한도를 넘었습니다 — 입금 뒤 주문" |
| ⑥ | 가격 | 매장에 보낸 최신 단가표·견적(수락·발행본) → 없으면 매장 등급·카탈로그 가격 → 없으면 회사 기본 판매가 | (가격 없는 품목만 주문 목록에서 빠짐) |

- 매장 홈·주문 메뉴 위에 **"주문 준비" 체크 목록**(①~⑤ 중 안 된 것만, 무엇을 하면 되는지 한 줄). 고객사 주문 확인 화면에도 매장별 같은 목록(어디서 막혔는지).
- 고객사가 링크를 발급하는 길은 그대로 둔다(비회원 초대용).

### 2-2. 메뉴

- 회원 세션 → 소속 매장 1곳이면 자동, 2곳 이상이면 사이드바 위 **매장 고르기**(기억). 모든 메뉴가 그 매장 기준. 매장에는 판매가만(원가·마진·매입처 비노출).
