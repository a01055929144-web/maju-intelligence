## 2. 고칠 방향 — 매장이 스스로 주문 (대표 16:25)

**원칙: 링크 발급을 기다리지 않는다. 조건이 확인되면 매장이 바로 주문한다.** 링크(#토큰)는 비회원이 처음 들어오는 문(공유·가입)으로만 남긴다.

### 2-0. 전체 흐름 (대표 16:33 확인)

1. **고객사 → 링크 보냄**: 단가표·견적서 공유 링크(카톡·문자). 링크에는 받는 상대(거래처 또는 리드)가 묶여 있다.
2. **매장 → 로그인 없이 문서 확인**: 품목·단가를 본다. 열람 기록이 고객사에 남는다.
3. **마음에 들면 [이 단가로 주문 시작]** → 카카오 로그인 → 점주 가입(사업자번호 확인 · 약관 동의 · 배송지 주소). 링크의 상대와 자동 연결(리드였으면 거래처로 전환 — 2-3 ①).
4. **주문 가능 조건 판정(2-1)**: 안 된 것만 "주문 준비" 목록으로.
5. **조건 통과 → 바로 주문**: 장바구니 → 주문하기 = 주문 확정(E단계: 원장·재고 반영).
6. **다음부터는 링크 없이**: `/store`에 카카오 로그인 → 주문 · 주문 내역 · 명세서 · 수령 확인. 새 단가표를 받으면 그 문서가 가격 기준.

- 이미 가입한 점주가 링크를 다시 열면 가입 안내 대신 **"이 단가표로 주문하기"**(S-3).
- 링크 없이 먼저 가입(초대코드·직접 가입)한 매장도 4번부터 같다(가격은 2-1 ⑥ 순서).

- 고객사가 링크를 발급하는 길은 그대로 둔다(비회원 초대용).
