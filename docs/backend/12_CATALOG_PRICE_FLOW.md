## 1. 용어 (화면 · 문서 · 지시서 모두 이 말만 쓴다)

| 용어 | 뜻 | 내부 이름 |
|---|---|---|
| **매입 이력** | 올린 파일의 거래 기록. 가격을 바꾸지 않음 | `purchase_receipt_lines`, `supplier_product_cost_history` |
| **현재 매입가** | 판매가 계산에 쓰는 매입가(상품마다 1개, 기준일 포함) | `product_catalog.purchase_price(_date)` |
| **기본가** | 현재 매입가 × 회사 기본 마진(분류 · 품목 마진 포함) | `pricing_p0_effective` |
| **카탈로그** | 기본가에 분류별 %를 다르게 준 가격 묶음. 매장마다 1개 지정 | `margin_templates`, `normalized_customers.margin_template_id` |
| **기본 카탈로그** | = 기본가 = **전체 상품**. 카탈로그를 지정받지 않은 모든 매장의 가격. 새 매장은 항상 여기서 시작 | `margin_template_id is null` |
| **단가표 · 견적서** | 고객사가 골라 보낸 문서. 게시한 순간 가격이 문서에 고정 | `pricing_document_versions` |
| **약속가** | 보낸 단가표 · 견적서의 가격. 유효기간까지 유지 | 게시본 `content.lines[].price` |
| **유효기간 · 연장** | 약속가가 지켜지는 마지막 날. 연장 = 그날의 최신 가격으로 **다시 계산해 새로 게시**(같은 링크) | `content.validUntil` |
| **매장 가격** | 매장이 주문할 때 실제 적용되는 가격(아래 3절 순서로 하나) | `self_order_price` |
| **가격 공개 매장** | 가입 후 전체 상품 **가격까지** 보는 매장(외식업 확실) | 신설(CX-122) |
| **주문 가능 매장** | 가격 공개 + 고객사 확인 + 배송 권역 + 결제 조건 | `store_order_eligibility` |

금지어: "등급가"(→ 카탈로그 가격), "판매가 탭"(→ 기본 카탈로그), "반영"(→ 현재 매입가 변경 / 이력만 저장 중 하나로 정확히).

## 2. 전체 플로우

```
[고객사] 매입 파일 올림 ─▶ ① 현재 매입가 변경(기본) ─▶ 기본가 · 카탈로그 자동 재계산
                       └▶ ② 이력만 저장(골라야만) ─▶ 가격 그대로
                                   │
            문서 목록: "다시 계산 필요 N품목" (보낸 단가표 · 견적서는 그대로 = 약속가)
                                   │
[고객사] 단가표 · 견적서 보냄(링크 · A4) ─▶ [매장] 가입 없이 문서만 보기(약속가)
                                   │
[매장] 카카오 가입 + 매장 정보 ─▶ 외식업 확인 ──┬─ 확실 ─▶ 전체 상품 + 가격 보기(기본 카탈로그)
                                              ├─ 불확실 ─▶ 전체 상품 이름만 · "고객사 확인 후 가격 공개"
                                              └─ 개업 준비 ─▶ 고객사 대표번호 전화
                                   │
[고객사] 매출처 확인(매출처 관리에서 생성 · 연결) ─▶ 배송 권역 · 결제 조건 ─▶ 주문 가능
                                   │
[매장] 주문하기 ─▶ 매장 가격(3절) 그 순간 값으로 주문 줄에 고정
```

## 3. 매장 가격 결정 순서 (대표 결정 ①)

1. **유효기간 안의 약속가** — 그 매장이 받은 단가표 · 견적서 중 가장 최근 게시본, 해당 품목 · 단위가 있을 때.
2. 그 외 → **매장에 지정된 카탈로그 가격**.
3. 지정 없음 → **기본가(기본 카탈로그)**.
- 유효기간이 지나면 약속가는 자동으로 빠지고 2 · 3의 **최신 가격**(현재 매입가 기준)이 적용된다.
- **연장**하면: 연장 시점 최신 가격으로 문서를 다시 계산 → 바뀐 품목 미리보기 → 새 게시본(새 약속가) · 같은 링크. 옛 가격을 그대로 연장하는 버튼은 만들지 않는다.
- 시가 품목(`order_pricing_mode='market'`) · 행사가 · 품목 마감은 기존 규칙 그대로.
- 이 순서는 **서버 함수 하나**에만 둔다(화면 계산 금지).

## 4. 가격 공개 판정 (대표 결정 ②: 음식점 · 외식업이 확실하면 공개)

| 판정 | 조건(하나라도) | 보이는 것 |
|---|---|---|
| **확실** | ⓐ 고객사가 보낸 링크로 가입(이미 매출처) ⓑ 국세청 계속사업자 + 공공데이터 영업신고(일반 · 휴게음식점 · 제과점, 영업 중)와 사업자번호 또는 주소 + 상호 일치 ⓒ 고객사가 "외식업 확인" 처리 | 전체 상품 + 기본 카탈로그 가격 |
| **불확실** | 위 어느 것도 아님(도소매 · 유통업 등 포함) | 전체 상품 이름 · 규격 · 분류만. 가격 칸 "고객사 확인 후 공개" |
| **개업 준비** | 사업자 없음 | 고객사 대표번호 전화 버튼(기존) |
- 판정 결과 · 근거는 매장 정보 화면(고객사)과 관리자 매장 화면에 표시. 고객사가 수동으로 바꿀 수 있고 기록이 남는다.

## 5. 새 매장 기본값 (대표 결정 ③)
- 새 매장 = **기본 카탈로그(회사 기본가)**. 다른 카탈로그는 고객사가 매장 가격 탭에서 지정.
