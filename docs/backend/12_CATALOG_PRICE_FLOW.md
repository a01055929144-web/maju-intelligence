## 3. 매장 가격 결정 순서 (대표 결정 ①)

1. **유효기간 안의 약속가** — 그 매장이 받은 단가표 · 견적서 중 가장 최근 게시본, 해당 품목 · 단위가 있을 때.
2. 그 외 → **매장에 지정된 카탈로그 가격**.
3. 지정 없음 → **기본가(기본 카탈로그)**.
- 유효기간이 지나면 약속가는 자동으로 빠지고 2 · 3의 **최신 가격**(현재 매입가 기준)이 적용된다.
- **연장**(대표 결정 11/18 13:38) — 연장 창에서 고객사가 고른다:
  - ⓐ **약속가 그대로 연장**: 가격은 그대로, 유효기간만 늘린 새 게시본. 매입가가 올라 이익이 낮아진 품목 수 · 최저 이익률을 함께 보여 줌(경고만, 막지 않음).
  - ⓑ **최신 가격으로 연장**: 연장 시점 최신 가격으로 다시 계산 → 바뀐 품목 미리보기(전/후 · 차이) → 새 게시본.
  - 둘 다 같은 링크 · 기록(누가 · 언제 · 어느 쪽)을 남긴다. 기본 선택은 없음(반드시 고름).
- 시가 품목(`order_pricing_mode='market'`) · 행사가 · 품목 마감은 기존 규칙 그대로.
- 이 순서는 **서버 함수 하나**에만 둔다(화면 계산 금지).

## 4. 가격 공개 판정 (대표 결정 11/18 13:38: 고객사가 직접 "외식업 확인"을 누른 매장만)

| 판정 | 조건 | 보이는 것 |
|---|---|---|
| **가격 공개** | 고객사 직원(권한 있는 사람)이 매장 정보에서 **"외식업 확인"**을 누름 | 전체 상품 + 매장 가격 |
| **확인 전** | 가입했지만 아직 안 누름 | 전체 상품 이름 · 규격 · 분류만. 가격 칸 "고객사 확인 후 공개" |
| **개업 준비** | 사업자 없음 | 고객사 대표번호 전화 버튼(기존) → 7절 |
- 자동 공개는 없다. 대신 고객사 화면에 **참고 표시**만: 고객사가 보낸 링크로 가입함 · 국세청 계속사업자 · 영업신고(일반 · 휴게음식점 · 제과점) 일치 여부.
- 확인 · 취소는 기록(누가 · 언제 · 메모). 취소하면 다음 화면부터 가격 숨김(이미 들어온 주문은 그대로).
- 고객사 "새 매장 확인" 목록에 확인 전 매장 수를 보여 준다(놓치지 않게).

## 7. 거래처(매출처 · 매입처) 공통 등록 · 개업 준비 (대표 결정 11/18 13:38)

**지금**: 매출처 빠른 등록은 사업자번호 없이 저장은 되지만 "개업 준비" 상태 · 개업 예정일 · 나중에 번호 보완 흐름이 없다. 매장이 스스로 가입하는 개업 준비 경로(`activate_preopening_store_owner_v1`, 플래그 OFF)만 매출처를 자동으로 만든다. 매입처(`product_suppliers`)는 주소 · 사업자 상태 · 사업자 형태 · 계산서 이메일 · 사업자등록증 칸이 없어 매출처와 다르다.

**바뀔 것**: 매출처 · 매입처는 **같은 등록 화면 · 같은 도메인 규칙**(customer 도메인의 거래처 공통 모델), 저장만 각자 테이블.
