# 백엔드 설계·코드 대조 점검 (2026-11-21)

기준: `origin/main` `3f846f6`까지의 저장소 코드와 설계 문서. 운영 데이터는 변경하지 않았다. 이 문서는 **정적 점검** 결과이며 전체 API 보안 인증이나 운영 종단 시험 통과 판정이 아니다. 각 결함은 해당 작업방에서 재현 시험을 붙인 뒤 수정한다. 11/21 후속 대조는 아래 6절에 기록한다.

## 3. 유지해야 할 계약

1. **매입**: 한 상품코드의 같은 날 서로 다른 매입 단가는 원본 행을 모두 이력으로 보존한다. 현재가는 가장 늦은 **유효 적용일**의 후보 중 사용자가 고른 한 행만 쓴다. 단위/환산 미확인은 이력만 저장하고 현재가를 보류한다.
2. **문서**: 발행 버전 가격은 고정한다. 매입가 변경은 기존 게시본을 소급 수정하지 않는다. 연장은 사용자가 기존가 유지/최신가 재계산 중 고르고 게시 전에 편집한다.
3. **주문·돈**: 가격·세금·재고·원장 계산은 서버 RPC에서 확정한다. 접수 때 작성중 전표, 출고 때 확정하며 중복 요청·부분 취소·회사 간 접근은 [15항목 점검표](../work-orders/2026-11-17-order-money-safety-gate.md)로 확인한다.
4. **권한**: UI 숨김은 서버 권한의 대체가 아니다. 모든 쓰기 경로는 회사 ID를 세션에서 확인하고 역할·기능 ON·대상 객체의 회사 일치를 검사한다. 공개 링크는 토큰 범위와 만료·철회를 따로 검사한다.
5. **운영 변경**: 마이그레이션 파일 병합, 운영 SQL 적용, 배포, 기능 ON은 별개다. 운영 DB에는 프로젝트를 명시한 승인과 현황판 잠금·적용 후 읽기 검증이 필요하다.
