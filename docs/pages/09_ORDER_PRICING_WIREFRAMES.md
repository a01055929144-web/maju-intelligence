# 09 견적·단가표·주문 — 화면별 요구사항 (와이어프레임 텍스트판)

- 기준: Claude 와이어프레임 22화면 (2026-10-29 21:30 판). 원본 캔버스는 대표가 공유 링크로 따로 전달합니다. 이 문서는 그 링크를 열지 못해도 같은 화면을 만들 수 있게 옮긴 것입니다.
- 함께 볼 문서: `docs/pages/pricing.md`(P0 구현 메모), Claude 설계 문서(공유 링크), 프로젝트 문서 `claude/order-pricing-design-2026-10-29.md`.
- 화면 번호는 캔버스 제목과 같습니다. 모든 화면은 기능 플래그 OFF가 기본이고 보류 메뉴에 링크를 추가하지 않습니다.

## 공통 원칙
1. 매장(링크) 화면·인쇄·온라인 전단지에는 **판매가와 노출 상품명만** 나갑니다. 매입가·마진·매입처·관리 상품명은 직원 화면에만 보입니다.
2. 금액은 원 단위 정수, 부가세는 줄 단위(기존 전표 규칙과 동일).
3. **마진율 = 매입가 대비 추가 비율.** 판매가 = 올림(매입가 × (1 + 마진율), 올림 단위). 예: 매입가 18,910 · 마진 12% · 10원 올림 → 21,180.
4. 가격 우선순위: 직접 단가 → 품목 마진 → 마진 그룹 → 회사 기본 마진 → 올림. 매장 화면에서는 거래처 계약 단가가 있으면 그것이 최우선.
5. 권한: 매입가·마진이 보이는 화면(①, ①-2, ①-3, ③, ③-2의 매입가 열, ⑬의 매입가)은 **대표(owner)와 관리자(manager)**. 영업직원은 판매가만 보이는 견적 작성까지.
6. 단체 발송·자동 매크로 없음. 카톡은 사람이 매입처/매장별로 '보내기'를 누르는 공유, 또는 정식 알림톡만.

## 1. 매입가 반영
### ① 매입가 업데이트
- 상단 버튼: 엑셀 양식 내려받기 / **엑셀 올리기** / 변경 확정(N건).
- 엑셀 올리기 두 방식: 통합 양식(매입처 열 포함) 또는 **매입처 파일 그대로**(매입처 선택 → 처음 1회 열 맞춤 저장 → 다음부터 자동 읽기). 최근 업로드 결과 표시(읽은 건수·확인 필요 건수).
- 왼쪽 매입처 목록(100곳 이상 가정): 검색, 그룹(가락시장/공산품 대리점/정육 등), 매입처별 이번 변동 건수·마지막 반영일, 30일 이상 미반영은 주황.
- 필터 칩: 변동 있음 / 인상 / 인하 / 신규. 품목 검색.
- 표 머리글: 선택 · 품목(코드) · 규격·단위 · 매입처 · **매입가[이전 | 이전 적용일 | 새]**(2단 머리글) · 변동(▲/▼ %) · 쓰는 곳(단가표 n · 견적 n).
- **열 보기** 메뉴로 열 숨기기(규격, 매입처, 이전 적용일, 과세, 쓰는 곳). 선택은 사용자별로 기억.
- 시세 품목은 새 매입가 자리에 '낙찰 후', 신규 품목은 '품목 연결'(⑬로 이동).
- 오른쪽: 영향받는 단가표·견적서 목록, 판매가 처리 방식(마진율 유지 재계산 추천 / 판매가 유지 + 확인 필요 표시).

### ①-2 마진 그룹 (P0 범위)
- 그룹 카드: 이름, 마진율 %, 올림 단위(1/10/100원), 연결된 분류.
- 분류(product_catalog.category) → 그룹 연결, 해제.
- 회사 기본 마진·올림.
- '다시 계산 필요 N개' + 변동분 일괄 계산 + 직전 계산 복구(마지막 실행만, 재시도 안전).
- 품목 표(50개 페이지): 품목/분류, 매입가, 그룹 우선 지정, 품목 마진, 판매가, 직접 단가.

### ①-3 행사 상품 · 묶음
- 행사 상품: ERP 코드가 `--`로 시작. 머리글 **관리 상품명(행사·직원용) / 노출 상품명(매장에 보임)** / 행사 매입가 / 일반 매입가 / 할인율 / 마진율 / 판매가 / 기간. 노출 상품명 옆 '행사' 배지.
- 매장·인쇄·온라인에는 노출 상품명 + '행사'만. 단가표에는 안 나오고 견적서에만 넣음.
- 묶음: 품목번호만 저장(가격은 쓸 때 계산), 엑셀로 만들기, 공용/내 것.

## 2. 만들기 · 인쇄 · 공개 범위
### ② 견적서·단가표 목록
- 상단: 주문 설정 / 직전 변동분 복구 / 변동분 일괄 계산 / + 견적서(매장 1곳) / + 단가표(여러 매장).
- 요약 카드: 게시 중, 다시 계산 필요, 이번 주 링크 주문, 만료 7일 이내.
- 표: 종류 · 이름(마진 그룹 요약·버전) · 공개 범위 · 품목 수 · 상태 · **유효기간(연도 포함, 만료는 'YYYY-MM-DD 만료')** · **매장 링크('27곳 · 주문 켬 24 · 열람 19')** · 최근 주문.

### ③ 단가표 만들기
- 왼쪽 품목 추가(검색·분류 칩) + **추천 템플릿 4종**(그대로 쓰기/편집해서 쓰기):
  1. 업종 추천 — 리드·거래처 업종과 메뉴판에서 추정한 품목
  2. 우리 거래처가 많이 사는 품목 — 같은 업종 공통 품목, 우리 가격이 싼 품목 먼저
  3. 재고 돌리기 — 많이 남음·유통기한 임박(⑭ 연동)
  4. 프랜차이즈·직영 세트 — 지점 공통 출고 품목 + 부식(직원 식사용)
- 가운데 표: 사진 · 분류(그룹) · 품목(추천/재고 돌리기 배지) · 규격 · 매입가(▲▼) · 마진% · 판매가 · 과세 · 표시/숨김.
- 오른쪽 설정: 종류, 유효기간, 공개 범위(전체/선택/특정 1곳), 링크 주문 받기. 마감·배송 요일·최소 주문·결제는 ⑫ 주문 설정 값을 따름.
- 게시하면 그 순간 판매가가 버전으로 고정.

### ③-2 견적서·전단지 만들기 (담당자별, 작성자만 보임)
- 받는 곳(리드/거래처 또는 받는 곳 없이 전단지), 품목 추가·묶음 불러오기/저장·행사 상품 넣기, 기준 가격(단가표/매입가 직접).
- 가격 3방법: ① 모든 품목 마진 일괄 ② 단가 직접 ③ 품목별 마진.
- 기준보다 낮은 가격은 주황 테두리 **표시만**(승인 절차 없음).
- 행사 품목은 노출명 + '행사', 아래 작은 글씨로 관리명.
- 버튼: 온라인·오프라인 미리보기 / 이미지·PDF / 링크 보내기.

### ④ 인쇄(A4) · ④-2 인쇄 전 편집·미리보기
- 기본 설정(회사에 저장): 로고, 회사명, 연락처, 담당자, 하단 문구.
- 디자인 테마 3개, 가격 표시/숨김.
- 온라인(휴대폰 웹)과 오프라인(A4)을 나란히. 같은 데이터, 제목·문구·품목 순서는 미리보기 위에서 직접 수정.
- QR: 주문 링크(유효기간까지) 또는 품목만 보기(가격 없음, 1년). **유효기간이 지나면 같은 QR로 들어와도 가격 숨김·주문 막힘, 품목만 표시.**
- 하단: 마감·배송 요일·최소 주문·시세 안내 문구(⑫ 값 자동).

### ⑤ 공개 범위 · 주문 링크 · 열람 기록
- 범위: 전체/선택/특정 1곳. 매장마다 별도 링크(복사·새 링크·회수).
- 표 열: 매장 · 배송 권역·요일 · 링크 · 열람 · 주문 · **결제 방식(선/후결제)** · 주문 받기.
- **보낸 링크 · 열람 기록**: 매장, 보낸 날짜·보낸 사람, 처음 열람, 최근 열람, 열람 횟수, 주문 수, 관심도(높음=최근 7일 3회 이상 열람·주문 없음 / 주문 중 / 미열람), 리마인드·다시 보내기(할 일로 등록 + 문구 복사, 자동 발송 없음). 정렬: 관심 높은 순/최근 열람/보낸 날짜.

## 3. 매장 화면 (앱 설치 없이 링크, 휴대폰 390px)
### ⑥-0 매장 홈
- 홈 화면에 추가(PWA 바로가기) 안내 + 버튼.
- 큰 '주문하기', '지난 주문 다시 담기', '저장 목록·즐겨찾기'.
- 주문 현황 4칸: 신청 / 접수 / 배송 중 / 도착.
- 미수금, 입금 계좌, '주문 내역·월말 명세서·거래원장'.
- 공지(휴무 안내 등).

### ⑥-1 첫 주문 전 매장 정보 (1회)
1. 사업자등록증 촬영/업로드 → 상호·대표자명 자동 읽기·확인
2. 대표자명 · 휴대폰(인증번호)
3. 배송지 확인(지도 핀 · 출입구 메모)
4. **적재 위치 사진(필수)**: 냉동·냉장 / 상온 / 싱크대 등, 위치별 1장 이상·여러 장. 기사가 주문마다 확인.
5. 새벽 배송 출입 비밀번호·키 위치(해당 시) — 암호화 저장, 배송 당일 담당 기사만 열람, 열람 기록.
- 신분증(주민등록증)은 받지 않음.

### ⑥ 주문하기 · ⑦ 주문 확인 · ⑦-2 결제 · ⑧ 내역
- 상단: 다음 배송일(권역 요일 기준) · 마감 시각 · 휴무 안내, 날짜 변경은 고를 수 있는 날만.
- 칩: 자주 주문 / 즐겨찾기 / 저장 목록 / 분류. 품목 카드에 수량 ± (44px 이상).
- 시세 품목: '시세' + 최근 출고가 + "싯가·경매가에 따라 달라질 수 있어요".
- 최소 주문금액 충족 표시(미달이면 ⑫ 설정에 따라 버튼 막기 또는 안내).
- 주문 확인: 배송일, 받는 곳, 마감까지 수정 가능, 줄 목록, 공급가·부가세·합계, 결제(선/후결제), 요청 사항.
- 결제(선결제 매장): 카드/계좌이체, 시세 품목은 확정 후 차액 결제, 결제가 끝나야 접수.
- 내역: 링크만으로 열람(1차), 결제 상태 배지, 같은 걸로 다시 주문, 명세서 보기, **월말 명세서 엑셀 · 거래원장 엑셀**(반품·보충은 고객사가 MAJU 전표를 쓸 때 반영).

## 4. 주문관리 · 매출 · 설정
### ⑨ 주문관리
- 배송일 이동, 마감까지 남은 시간, 알림(결제 완료 등), 카톡 주문 붙여넣기, 주문 직접 입력, 지금 마감.
- 요약 카드: 주문 건수·금액 / 결제 완료 / **선결제인데 미결제(빨강, 결제 요청 보내기)** / 후결제 / 시세 단가 입력 필요.
- 필터: 상태 탭, 결제, 경로, 담당·호차, 매장 검색. 선택 일괄: 접수/출고/명세서 인쇄.
- **표**: 선택 · 매장(권역) · 품목('깐마늘(대) 외 10개') · 금액 · 결제 배지 · 경로 · 주문 시각 · 상태 · **출고(고객사 판단, 미결제 기본 보류)**. 미결제 행 빨간 배경.
- 행 클릭 → 상세(출고 수량, 시세 단가 입력, 확정 → 매출 전표). 시세 단가가 비면 확정 불가.

### ⑩ 품목별 집계 · 매입처 발주 · 미주문 매장
- 품목별 주문 합계·매장 수·재고·부족·처리(재고/사입/발주).
- 엑셀 · **집계 이미지 저장** · 호차별 피킹 목록.
- **매입처 발주**: 부족분을 매입처별로 자동 분리, 매입처 선택 → 발주서 이미지 만들기 → 보내기(카톡 공유는 매입처별 공유창을 차례로, 알림톡은 매입처별 1건). 단체방·자동 매크로 없음.
- 미주문 매장(평소 이 요일 주문) + 문구 복사.

### ⑪ 거래처 주문·매출
- 상단 필터 줄: **거래처 검색(상호·전화·사업자번호), 담당자, 차량, 기간**, 조건 결과 합계.
- 거래처 상세 탭(주문·매출): 이번 달 매출, 주문 횟수·객단가·경로별, 미수 잔액, 평소 주문 요일, 월별 매출, 많이 사는 품목, 주문 목록(전표 링크).

### ⑫ 주문 설정 (고객사가 직접)
- 마감: 배송 전날/당일/2일 전 + 시각.
- 배송 권역 표: 권역 · 요일 칩(월~토) · 방식(주 3회/주 1회 고정) · 마감 · 최소 주문 · 매장 수 · 매장 배정.
- 휴일: 요일 선택 / 고정 휴일(공휴일, 가락시장 휴장일 불러오기) / 일자 지정. **달력에서 하루 클릭 = 그날, 끌기 = 기간**, 시작~종료일 입력도 가능. 휴일과 겹친 배송일 처리(다음 배송일로 / 앞으로 / 건너뜀).
- 최소 주문금액(기본, 미달 시 막기/안내만), 권역별·매장별 예외.
- 결제: 선결제(카드·계좌이체) / 후결제(월말·주 단위·배송마다), 신규 매장 기본값. PG 계약 전에는 후결제만.
- 시세 품목 안내 문구(매장·확인·인쇄에 공통 사용).

## 5. ERP 기본
### ⑬ 상품관리
- 표: 사진 · **노출 상품명** · 관리 상품명·코드 · 규격 · 과세 · 매입처 · 재고 · 판매(판매 중/부식).
- 필터: 분류(부식 포함), 매입처, 사진 없음, 행사만.
- 상세: 사진 여러 장(JPG/PNG/WEBP/HEIC/GIF, 자동 축소), **이미지 URL 가져오기 = 사본 저장 + 출처 URL 기록**, 노출명/관리명, 분류, 과세, 규격, 바코드, 매입처 여러 곳(기본 지정, 최근 매입가·일자), 시세 품목 여부.

### ⑭ 재고관리
- 탭: 현재고 / 입출고 내역 / 실사. 입고 등록, 재고 조정.
- 표: 품목 · 보관(냉동/냉장/상온) · 현재고 · 출고 예정(미확정 주문) · 입고 예정 · 가용 · 안전 재고 · 유통기한 · 상태(부족/많이 남음/기한 임박).
- 재고 돌리기 → ③ 추천에 올림. 부족 → ⑩ 매입처 발주.

### ⑮ 거래처관리
- 탭: 매출처(매장) / 매입처.
- 매입처 표: 매입처 · 그룹 · 담당자·연락처 · 발주 방법(카톡 공유/알림톡/팩스/전화) · 발주 마감 · 품목 수 · 최근 매입가 반영(오래되면 주황) · 이번 달 매입 · 미지급.
- 엑셀 올리기, 매입처 추가.
