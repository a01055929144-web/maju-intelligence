# CX-103 ERP 메뉴·탭 재구성 — 대표 검토안

이 문서는 구현 전 정보 구조만 확정하기 위한 검토안이다. 대표가 표를 확인하기 전에는 메뉴·화면·라우팅 코드를 수정하지 않는다.

## 지켜야 할 원칙

1. **기존 주소 유지**: 아래 기존 URL은 삭제하거나 다른 의미로 바꾸지 않는다. 새 메뉴와 탭은 기존 URL을 그대로 링크한다. 나중에 대표 URL을 추가하더라도 기존 URL은 같은 탭으로 보내는 호환 진입점으로 남긴다.
2. **공용 탭 재사용**: 화면 상단 탭은 `components/ui/tabs.tsx`의 `Tabs`를 사용한다. 이 부품의 좌우 방향키·Home·End·`role=tablist`·`aria-selected`·선택 탭 `tabIndex=0` 동작을 유지한다.
3. **권한 유지**: 메뉴를 합쳐 보여도 접근 권한을 넓히지 않는다. 탭 클릭 뒤 각 기존 페이지와 API가 수행하는 서버 권한 검사를 그대로 통과해야 한다. 메뉴 숨김은 보조 수단일 뿐 권한 판정이 아니다.
4. **한 화면 복제 금지**: 기존 화면을 새 URL에 복사하지 않는다. 첫 구현은 메뉴/탭 링크 재구성만 하고, 데이터·저장 함수·API는 옮기지 않는다.
5. **기본 OFF 유지**: 현재 보류 ERP 화면은 기존 회사별 hold-module 조건을 그대로 따른다. CX-103 때문에 새 회사에 ERP가 자동으로 켜지지 않는다.

## 제안 메뉴와 탭

| 왼쪽 ERP 메뉴 | 화면 안 탭 | 연결할 기존 주소 | 현재 화면 | 대표 확인 사항 |
|---|---|---|---|---|
| 상품관리 | 상품 | `/revenue/products` | 상품 목록·분류·가져오기 | 기본 탭으로 제안 |
| 상품관리 | 재고 | `/operations/inventory` | 현재고·실사·단위 환산 | 기존 보류 모듈 조건 유지 |
| 상품관리 | 재고 이력 | `/operations/inventory` | 재고 화면의 기존 기록 기능 | 재고 화면 안 탭으로 둘지 확인 필요. 별도 주소는 만들지 않음 |
| 상품관리 | 엑셀 | `/revenue/products` | 상품 화면의 기존 가져오기 기능 | 예전 `?tab=imports`는 현재 상품 기본 탭으로 열리므로 새 계약으로 쓰지 않음 |
| 거래처 | 매출처 | `/crm/timeline?section=partners` | 공용 거래처 틀 기반 매출처 | `PartnerDirectory` 틀 유지 |
| 거래처 | 매입처 | `/purchasing/suppliers` | 매입처·상품·원가·업로드 이력 | 매출처와 같은 공용 틀로 보이되 기존 저장 흐름 유지 |
| 거래처 | 공용 틀 | `/crm/timeline?section=partners` | 목록·기본 정보·품목/단가·전표·원장·메모 | 별도 세 번째 화면이 아니라 두 거래처 화면이 공유할 탭 구조를 뜻함 |

| 전표 | 매입 | `/operations/documents` | 현재 한 화면의 전표 유형 필터 | 위와 같음 |
| 전표 | 반품 | `/operations/documents` | 매출 반품·매입 반품 | 기존 반품 유형 필터와 저장 흐름 유지 |
| 정산 | 입출금 | `/operations/documents` | 현재 거래처원장 안 입금·지급 등록 | 기존 원장 트랜잭션 재사용 |
| 정산 | 미수 | `/operations/documents` | 별도 화면 계약 없음 | CX-97 범위에서 확정 전 새 탭·링크 생성 금지 |
| 정산 | 상계 | `/operations/documents` | CX-69 권한 경계가 선행 | CX-69 계약 재사용, 독립 권한 신설 금지 |
| 정산 | 원장 | `/operations/documents` | 매출처·매입처 원장 | 현재 파트너 선택·기간 조회 유지 |
| 통계 | 매출 자료 | `/revenue/transactions` | 매출 요약·매칭·분석·원장표 | 현행 URL과 조회 범위 유지 |
| 통계 | 영업 성과 | `/sales/performance` | 영업 성과 | ERP 통계에 포함할지 대표 확인 필요. 영업 메뉴와 중복 노출 금지 |

탭 선택 상태를 URL에 남길지는 대표 승인 뒤 정한다. 추가 쿼리 계약을 만들더라도 위 기존 주소는 기본 탭으로 계속 열려야 한다.

## 현행 권한 매핑

| 대상 | 현재 왼쪽 메뉴 역할 | 현재 페이지 서버 경계 | 재구성 뒤 원칙 |
|---|---|---|---|
| 상품 `/revenue/products` | owner · manager · sales | 고객사 세션은 `manage_sales` 필요, 없으면 404 | 그대로 유지 |
| 재고 `/operations/inventory` | owner · manager, 보류 모듈 | 고객사 세션은 `manage_sales` 필요, 없으면 대시보드 이동 | 그대로 유지. sales에게 새로 노출하지 않음 |
| 매출처 `/crm/timeline` | owner · manager · sales | 기존 거래처 화면·API의 회사 범위와 권한 사용 | 그대로 유지 |
| 매입처 `/purchasing/suppliers` | owner · manager | 고객사 세션은 `manage_sales` 필요, 없으면 대시보드 이동 | 그대로 유지. sales에게 새로 노출하지 않음 |
| 전표 `/operations/documents` | owner · manager, 보류 모듈 | 고객사 세션은 `manage_sales` 필요, 없으면 대시보드 이동 | 매출·매입·반품 탭 모두 동일 경계 유지 |
| 정산/원장 `/operations/documents?tab=ledger` | 전표와 동일 | 페이지 경계 + 원장 API의 회사 범위 검사 | 입출금·미수·상계 탭도 더 넓은 권한을 만들지 않음 |
| 매출 자료 `/revenue/transactions` | owner · manager, 보류 모듈 | 로그인·회사 선택 경계, 내부 조회는 회사 ID 범위 | 현행 경계를 먼저 보존. 별도 강화는 CX-103과 분리 |
| 영업 성과 `/sales/performance` | 현행 영업 흐름 | 기존 페이지·API 경계 | 통계 편입 여부와 무관하게 기존 권한 유지 |
| 관리자 미리보기 | 고객사 메뉴 역할과 별도 | 관리자 세션 + 명시적 `companyId` 요구 | 그대로 유지 |

## 최신 `main` 대조 결과

2026-11-18 `main`의 `lib/customer-navigation.ts`와 각 기존 페이지를 대조했다. 대표 확인 전에는 아래 현행 표시 계약을 바꾸지 않는다.

| ERP 사용 여부 | 역할 | 상품 `/revenue/products` | 매출처 `/crm/timeline` | 매입처 `/purchasing/suppliers` | 확인 결과 |
|---|---|---|---|---|---|
| OFF | owner | 표시 | 표시 | 표시 | 세 항목은 `coreErpItems`라 hold-module 조건과 무관하게 ERP 묶음에 남음 |
| OFF | manager | 표시 | 표시 | 표시 | owner와 동일 |
| OFF | sales | 표시 | 표시 | 숨김 | 매입처의 현행 `workspaceRoles`는 owner·manager뿐이며 넓히지 않음 |
| ON | owner · manager | 표시 | 표시 | 표시 | 위 세 항목에 재고·매입/매출관리·매출 자료가 추가됨 |
| ON | sales | 표시 | 표시 | 숨김 | hold 항목과 매입처는 추가 노출하지 않음 |

- 기존 주소는 최신 `main`에서도 각각 상품, 매출처, 매입처의 실제 진입점이다. CX-103은 이 주소를 삭제·변경하거나 새 대표 주소로 대체하지 않는다.
- 메뉴 표시와 서버 접근 판정은 별개다. 상품·매입처 페이지의 현행 `manage_sales` 검사와 각 API의 회사 범위 검사를 그대로 둔다.
- `/crm/timeline?section=partners`는 최신 `main`에 이미 존재하는 통합 화면 선택값이다. 새 URL 계약으로 간주하지 않는다.
- ERP OFF 회사에서 상품·매출처·매입처를 함께 숨기는 구현은 현행 계약 위반이다.
- 이 대조는 고객사 메뉴만 대상으로 했다. 08방 관리자 화면과 07방 프로필 파일은 CX-103 구현 범위에 포함하지 않는다.

## 구현 시 변경 허용 범위

- `lib/customer-navigation.ts`: ERP 메뉴 묶음과 기존 URL 링크만 변경한다.
- 각 ERP 화면: 공용 `Tabs`와 URL 선택 상태 연결만 추가한다.
- 기존 페이지 경로·API·저장 함수·DB는 변경하지 않는다.
- 06방 PR #1077이 수정하는 관리자 메뉴 파일은 건드리지 않는다.
