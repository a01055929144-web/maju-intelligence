판매가 변동 기준

고객사가 새 게시본을 링크에 반영한 뒤, 같은 품목의 직전 게시 판매가와 비교합니다. 비교할 값이 없으면 변동 정보는 표시하지 않습니다.

권한 경계

문서 열람은 유효한 링크로, 주문과 매장 자체 원가는 카카오 매장 구성원 확인 뒤. 유통사 매입가·마진·매입처는 노출하지 않습니다.

시안에서 저장하지 않는 것

로그인·주문·즐겨찾기·설정·원가 업로드는 실제 저장소와 연결되지 않았습니다. 위 값은 합성 예시입니다.
