## 1. 단가를 만드는 재료

| 재료 | 무엇 | 어디서 정함 | 저장 위치 | 상태 |

| 분류별 마진 | 폴더에 거는 마진(하위까지 적용 가능) | 마진 설정 › 분류별 마진 | `margin_groups` + `margin_group_categories` | 운영 |

| 거래처 등급 지정 | 매장마다 템플릿 하나(없으면 기본) | 거래처 상세 | `normalized_customers.margin_template_id` | DB 적용, 화면 CC-19c |
| 견적가(약정가) | 수락된 견적서 품목가, 기간이 정해짐 | 견적서 → 매장 수락 | `customer_price_agreements` | 운영 |

## 2. 판매가 계산 순서 (위가 이김)

| 순서 | 기본 템플릿(지금 회사 규칙) | 추가 템플릿(도매·VIP 등) |
| --- | --- | --- |
| 1 | 상품 직접 단가 | 템플릿 상품 직접 단가 |
| 2 | 상품별 마진 | 템플릿 상품 마진 |
| 3 | 분류별 마진 — **경로가 정확히 같은 연결만** | 템플릿 분류 마진 — **가장 깊은 상위 폴더** |
| 4 | 기본 마진 | 템플릿 기본 마진(회사 기본으로 새지 않음) |
| 계산 | 매입가 × (1 + 마진) → 끝자리 올림 | 같음 |
| 저장 | "판매가 반영"을 눌러야 `pricing_items.price`에 저장 | 저장하지 않고 그때그때 계산 |

## 3. 문서·주문에서 실제로 쓰이는 가격

| 상황 | 쓰는 가격 | 근거 |
| --- | --- | --- |
| 전체 단가표 작성 | 기본 템플릿 판매가 (오른쪽 "가격 기준"으로 변경 가능 — CC-19c) | 작성 화면 |
| 특정 매장 견적서 작성 | 그 매장 등급 템플릿 판매가 자동(CC-19c), 직접 수정 가능 | 작성 화면 |
| 문서 확정·발행 | 그 순간 가격을 **스냅샷**으로 고정. 나중에 마진을 바꿔도 발행본은 그대로 | `pricing_document_versions` |
| 매장이 일반 줄 주문 | 발행본 가격 → 그 매장 **유효한 약정가가 있으면 약정가로 바뀜** | `place_store_order` |
| 매장이 행사·임박 줄 주문 | 발행본의 행사가. 기간·재고·매장당 한도 확인 | `place_store_order` |
| 대상이 아닌 매장이 행사 줄 주문 | **지금: 확인 안 함(행사가로 받음)** → CC-29 후: 견적가 → 등급가 → 기본가, 행사 재고 차감 없음 | CC-29 |
| 싯가 품목 | 주문 때 금액 없음, 확정 때 입력 | 주문 줄 `is_market_price` |

## 5. 정리하다 발견한 점 (고칠 것)

| # | 문제 | 영향 | 등급 | 제안 |
| --- | --- | --- | --- | --- |
| 1 | 주문 함수가 **약정가를 행사 줄에도 덮어씀**. 약정가 확인이 행사 확인보다 먼저이고, 행사 줄이어도 가격을 되돌리지 않음 | 약정가가 있는 매장은 행사 줄을 눌러도 약정가(보통 더 비쌈)로 주문되고 행사 재고는 줄어듦 | P1 | CC-29 주문 함수 수정 때 같이: 행사 대상이면 행사가 우선, 대상 아니면 약정가→등급가→기본가 |
| 2 | 분류별 마진 매칭이 기본 템플릿은 **정확한 경로**, 추가 템플릿은 **가장 깊은 상위 폴더** | 기본 템플릿에서 상위 폴더에 마진을 건 뒤 새 하위 폴더를 만들면 그 하위 상품은 기본 마진으로 떨어짐(추가 템플릿은 상속) | P2 | 기본 템플릿도 "가장 깊은 상위 폴더"로 통일(`resolvePriceRule`·`effectiveMargin`·`pricing_p0` 재계산 SQL). 판매가가 바뀌는 상품 목록을 먼저 뽑아 확인 |
| 3 | 행사 목록 "정상가"는 행사 등록 때 넣은 정상 매입가 × 마진, 10원 올림 고정 | 실제 기본 판매가(직접 단가·1/100원 올림)와 다르게 보일 수 있음 → 할인율이 틀려 보임 | P3 | 행사 목록 정상가 = 그 상품의 지금 기본 판매가(매장 등급 있으면 등급가)로 표시 |

## 6. 우선순위 요약

판매가 = **직접 단가 > 상품 마진 > 분류 마진 > 기본 마진** (등급 템플릿이 있으면 그 템플릿 안에서 같은 순서)
주문가 = **발행본 스냅샷** 위에 **행사(대상일 때) > 약정가 > 발행본 가격** (CC-29 + 위 1번 수정 후 기준)
