# 매입가 변동률 단일 계산 규칙

작업: CX-06
Owner Domain: pricing
화면 연결: R2

## 확정 규칙

1. 대상일의 마지막 유효 매입가를 직전 유효 매입일의 마지막 유효가와 비교한다.
2. 정정 전 행, 취소, 반품은 제외한다. 정정 후 확정된 행만 `valid`로 전달한다.
3. 같은 날 여러 유효 매입이 있으면 기록 시각이 가장 늦은 값을 사용한다. 시각도 같으면 ID 정렬상 마지막 값을 사용해 재계산 결과를 고정한다.
4. 변동률은 `(현재가 - 직전가) / 직전가 × 100`이다. 유효 가격은 0보다 큰 유한값이어야 한다.
5. 절댓값이 0.5% 미만이면 `steady`로 판정하고 등락 표시를 노출하지 않는다. 정확히 0.5%부터 상승·하락으로 표시한다.
6. 대상일에 매입이 없으면 마지막 유효가를 유지하되 `no_purchase`로 반환하고 등락률은 만들지 않는다.
7. 첫 유효 매입은 `first_purchase`, 유효 이력이 없으면 `unavailable`이다. 둘 다 등락률을 만들지 않는다.

날짜는 저장 계층에서 한국 영업일 기준 `YYYY-MM-DD`로 전달한다. 순수 함수는 DB 상태나 화면 표현을 알지 않으며, 주문 링크와 매입 이력 화면은 R2에서 이 함수를 함께 사용한다.

## 대표 확인

| 항목 | 제안 | 확인 상태 |
| --- | --- | --- |
| 보합 기준 | 절댓값 0.5% 미만은 표시하지 않음 | 확인 필요 |
| 재고 초기값 | 매입 거래가 아니므로 변동률 계산에서 제외 | 확인 필요 |
| 당일 매입 | 확정된 실제 매입만 포함 | 확인 필요 |
| 정정 처리 | 정정 전 행은 제외하고 정정 후 확정 행만 유효 처리 | 확인 필요 |

대표 확인으로 기준이 바뀌면 이 문서와 도메인 상수·테스트를 함께 변경한다. 운영 DB, 기능 플래그, 화면은 이 작업에서 변경하지 않는다.
