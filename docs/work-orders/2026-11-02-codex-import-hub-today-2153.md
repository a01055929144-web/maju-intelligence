## 1. 엑셀 가져오기 · 데이터 옮기기 — 한곳으로 모은다 (필요함, Claude 검토 결과)

**지금 상태(흩어져 있음)**
- 설정 › "엑셀 업로드"(`/`, 옛 거래처 · 매출 · 매입 업로드)와 "업로드 이력"
- 상품관리 안의 가져오기(4대상 선택 #139, 미리보기 수정 #147 · #148)
- 거래처 품목 가져오기 #154
- 매입가 반영 엑셀 #171

같은 일을 하는 입구가 여러 곳이고, 새 고객사가 **처음에 무엇부터 올려야 하는지** 알 수 없다.

**바꿀 것: 설정 › "데이터 가져오기" 한 화면**(와이어프레임 ExcelImport · ImportPreview)
- 가져올 대상(카드)과 권장 순서:

| 순서 | 대상 | 비고 |
|---|---|---|
| ① | 전체 상품 | |
| ② | 매출처(거래처) | |
| ③ | 매입처 | |
| ④ | 거래처 원장(거래처별 품목 · 최근 단가) | |
| ⑤ | 재고 | |
| ⑥ | 과거 매출 자료 | 옛 업로드, 통계용 |

  - 카드마다 지금 건수 · 마지막으로 가져온 날 · [양식 받기] · [올리기].
- 흐름은 하나로 같다: 파일 → 열 맞추기(회사 표준 칸, WO-25) → **미리보기 · 수정** → 같은 것 · 의심 · 오류 처리 → 반영 → 되돌리기.
  - 기존 부품(#139 · #147 · #148 · #154)을 재사용한다.
- 각 화면의 업로드 버튼은 **같은 가져오기 화면을 대상이 선택된 상태로 연다**:
  - 상품관리 › 전체 상품 업로드 → ① 상품
  - 거래처 화면 → ②
  - 재고 화면 → ⑤
- **매입가 반영의 엑셀만 예외로 그 화면 안에 둔다.** 매입가 변경 후보를 만드는 기능이라 성격이 다르다.
- 업로드 이력: 대상 · 파일 · 건수(추가 · 갱신 · 건너뜀 · 오류) · 올린 사람 · [되돌리기] · [오류 줄 받기].
- 옛 `/` 엑셀 업로드는 이 화면으로 넘어가게 한다. 기존 기능(매출 자료 업로드)은 ⑥으로 유지한다. **기존 데이터와 경로는 지우지 않는다.**
- **새 고객사 시작 체크리스트**(첫 화면에도 나옴, 2절):
  ① 전체 상품 → ② 매출처 → ③ 매입가 반영 → ④ 단가표 만들기 → ⑤ 주문 조건 → ⑥ 매장 링크 보내기.
  - 끝난 단계는 ✓ 표시.

## 2. 로그인하면 첫 화면 = "오늘 할 일" (맞음)

**위치**: 고객사 로그인 뒤 첫 화면(`/dashboard`)의 이름과 내용을 **"오늘 할 일"**로 바꾼다. 지금 "오늘 현황"의 숫자 카드는 아래쪽 "오늘 숫자"로 내린다.
- 사이드바 맨 위 메뉴도 "오늘 할 일"이다.

**할 일 카드**(위에서부터 급한 순서, 0건이면 숨김, 각 카드 → 해당 화면으로 바로 이동)
1. **새 주문 확인** N건 (O-4)
2. **오늘 마감 · 발주** (마감 시각까지 남은 시간)
3. **확인 필요** — 수락 리드 · 거래처 매칭 애매(S-2 `needs_review`)
4. **배송 미배정 신규 거래처** (D-1)
5. **관심 높음** — 열람 3회 이상 · 주문 없음(링크 관리)
6. **오늘 다시 연락할 곳** (T-2)
7. **오늘 영업할 곳 Top 20** (T-1)
8. **다시 계산 필요 문서** (M-1)
9. **시작 체크리스트** (데이터가 없을 때만 맨 위)

**역할별로 보이는 것**
- 대표 · 관리자: 전부
- 영업 직원: 3 · 5 · 6 · 7 + 자기 담당만
- 경리: 주문 · 미수 관련
- 기사: 지금처럼 모바일 오늘 코스(`/mobile/today`)가 첫 화면

**모바일**: 같은 카드를 세로로(390px). 영업 직원이 폰으로 로그인하면 6 · 7이 맨 위.

**데이터**: 새 테이블 없이 기존 조회를 모은다. 카드별 건수는 서버에서 한 번에 가져온다(느린 카드는 나중에 불러온다).
