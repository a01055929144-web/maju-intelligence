## 우선 고칠 흐름 5개

1. `가는 길`이 오늘 배송 코스가 아니라 현재 위치 반경만 보므로, 이름과 실제 결과가 다르다.
2. 후보를 골라도 `들르기 → 우회 시간·거리 확인 → 코스 추가`가 없어 행동이 끝난다.
3. 모바일 첫 화면의 4개 카드는 실행 카드가 아니라 필터라서 전화·문자·DM·방문까지 한 번 더 목록과 상세를 찾아야 한다.
4. 지도 실패가 목록까지 막아 영업 기록과 연락 같은 지도 비의존 업무도 시작할 수 없다.
5. 390px 가로 오류는 없지만 KPI·큰 지도·고정 하단 메뉴 때문에 첫 업무와 다음 행동 사이 세로 이동 및 가림이 크다.

## 15:56 확장 우선순위

1. T-1 공용 우선 타겟이 없어 PC·모바일·기사에서 같은 “오늘 영업할 곳”을 사용할 수 없다.
2. M-1 현장 견적은 존재하지만 새 견적을 `sales_quotes`에 저장해 `pricing_documents` 정본·게시 version·주문 링크 흐름과 갈라진다.
3. M-2는 코스 1km 우선 타겟, 코스 들르기 추가, 단가표 링크 보내기 세 행동이 모두 없다.
4. 거래 시작 뒤 D-1 미배정 목록과 추천 배정으로 이어지지 않아 신규 거래처가 오늘 배송 코스에 들어가는 과정이 끊긴다.
5. 모바일 구현은 T-1·가격 문서·코스 결과를 자체 계산하거나 직접 저장하지 말고 각 소유 영역의 공용 API를 호출해야 한다.

## 확인 증거

- Playwright 390×844: 가로 스크롤 없음(`clientWidth=390`, `scrollWidth=390`), 화면 밖 조작 요소 0개.
- 가상 실행에서 카카오 지도 키 부재 오류가 반복됐고, 지도 실패 뒤 리드 목록이 `영업 후보를 불러오는 중입니다`에 머묾.
- 소스 확인: `route`는 `distanceKm(현재 위치, 리드) <= 0.5`, 목록은 `visibleLeads.slice(0, 50)`이며 `들르기`, 우회 미리보기, 코스 추가 행동은 없음.
- 소스 확인: 모바일 현장 견적은 `/api/sales-quotes` POST/PATCH를 사용하며, T-1 우선 타겟·D-1 미배정 추천 화면은 없음.
