- 캔버스 v53: Playwright로 S-2 신규 리드, S-3 영업 리드, S-4 영업 기록 아트보드 내부 구조를 확인했다.

## 영업 흐름에서 끊기는 곳 Top 5 (초안)

다른 담당 결과가 들어오면 심각도와 실제 흐름 기준으로 다시 정렬한다.

1. **리드 → 실제 견적서 만들기 연결 없음** — 현재 리드 화면은 견적 요청·초안·발송을 영업 기록으로 남기지만 `pricing_documents` QuoteEditor로 바로 이어지지 않는다. 리드에서 실제 견적 작성·게시 흐름이 시작되지 않는다.
2. **지도 ↔ 리드 목록 동시 작업 구조 없음** — S-2/S-3 와이어프레임은 같은 지도 옆 목록에서 후보를 검토하고 단계 액션을 실행하지만 현재는 표와 지도를 전환한다. 지도 위치를 보면서 연속 영업하기 어렵다.
3. **영업 기록 수동 추가 입구 없음** — S-4의 `+ 기록`이 없어 전화·방문·카톡 기록을 원장에서 직접 보완할 수 없다. 현재는 리드/모바일 쪽 기록 진입에 의존한다.
4. **리드 필터의 규모·리마인드 축 없음** — 지역·업종·개업일·상태는 있으나 와이어프레임의 규모(평), 리마인드 전용 필터가 없어 후보 선별과 후속 누락 확인이 분리된다.
5. **기사 가는 길 영업 기록의 합류가 화면에서 불명확** — S-4는 모바일 컨택 원장으로 설명되지만 기사 방문·사진이 같은 기록으로 들어오는지 사용자가 확인할 입구·출처 표시가 없다. 02 담당의 실제 저장 경로 확인 후 확정한다.

## 다른 담당 결과 합치기 규칙

- 01 지도: D-1 행과 Top 5 후보를 갱신한다.
- 02 모바일: 모바일 영업·DriverLeads 행, S-4 기사 기록 합류 여부를 갱신한다.
- 04 스크린샷: QuoteEditor 행과 리드→견적 흐름의 실제 진입 가능 여부를 갱신한다.
- 06 현황·성과: S-1/S-5 행과 전환 지표 누락을 갱신한다.
