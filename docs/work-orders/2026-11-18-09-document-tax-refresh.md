# 초안 현재 세금 구분 반영

원인: 일반 문서 행은 상품을 담았을 때 세금 스냅샷을 보관한다. 행사 행은 RPC가 행사 원본 세금으로 정규화하므로 문서 표의 직접 선택이 저장 후 되돌아갈 수 있다. 기존 발행본은 별도 불변 스냅샷이다.

기존 편집기의 더보기→현재 세금 구분 반영: 현재 문서의 상품만100개씩 기존 회사 catalog로 읽고 행사 원본도 읽는다. 상품 미확정/삭제/다른 행사 연결/상품과 행사 불일치이면 초안을 전혀 바꾸지 않고 고칠 화면을 알린다. #1149의 행사 명시적 정정 뒤 다시 누를 수 있다.

일치하는 원본에 대해 면세/과세 변경 개수를 확인→취소 또는 초안 반영. 저장 단가/이름/규격/수량·발행본은 유지하고 세금 값만 바꾼다. 자동 저장하지 않으며 기존 초안 저장과 revision을 그대로 쓴다. 조회/확인 중 다른 편집이 있으면 오래된 결과로 덮어쓰지 않는다. 행사 행 직접 세금 선택은 잠그고 행사 수정 버튼을 제공한다.

새 DB 칸/RPC/운영 SQL·데이터 쓰기/자동 보정/기능 ON/배포 없음. 05 #1148 반영 main 9a284b4 기준이며 #1109 연장 Draft를 선행 조건으로 두지 않는다. 표시 설정 저장 SQL 초안 #1150 및 신규 문서 VAT/행사 고정가 해석과 분리한다.

검증: 순수 도메인 시험(기본값 추정 금지·일치/불일치·입력 불변·300줄), 기존 CI 실행 document-actions E2E 1440/390(불일치 오류·명시적 확인·취소·입력 반영·저장·발행본 불변·unknown), 기존 P1 실제 PG17(행사 정정 후 자동 갱신0·명시적 초안 저장·가격/발행본 보존). CI 전에는 완료로 간주하지 않는다. 원상품 조회와 나중 초안 저장의 원자적 동시성까지 보장하지 않으며 사용자 확인 시점 스냅샷이다.
