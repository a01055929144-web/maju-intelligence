# Stage C 합성 구성원 주문 연결

- 기준: main 7659300 (#352/#355/#357).
- 확인된 누락: bearer 주문 화면에 구성원 카카오 로그인 입구가 없고, 주문 내역에는 저장된 작성자 표시가 없었다.
- 변경: 기존 07 context로 검증한 구성원만 같은 회사/매장 주문의 작성자를 조회한다. 링크 소지만으로 구성원 이름을 공개하지 않는다. 이름/역할은 현재 구성원 행 기준이며 주문 당시 이름의 스냅샷이라고 주장하지 않는다.
- 계정 범위는 검증된 링크의 company/customer에서 서버가 조회한다. 기존 카카오 입구를 새 탭으로 열어 인증 URL에 공유/주문 토큰을 전달하지 않고 원래 주문 탭에서 재확인한다. OAuth callback/인증 계약은 바꾸지 않는다.
- 기존 작성자 없는 주문은 기존 링크 주문, 다른 매장/조회 불가 작성자는 확인 필요. 현재 주문자로 추정하지 않는다.
- 전역 회원 OFF/회사 제외 상태에는 새 계정/작성자 조회나 로그인 UI 없음. SQL/03 수락 API/07 인증 파일 변경 없음.
- 합성 E2E: PC 1440/390 각각 점주·직원 4개. 문서 열람(수락 0회) → 명시 수락 → 주문 링크 → 비로그인 403 → 같은 매장 OAuth 경계(새 탭) → 상태 재확인 → 같은 주문 키 재시도 → 작성자 내역. OAuth/수락/주문은 모두 모킹하며 실제 provider/운영 데이터/세션을 쓰지 않는다.
- 이 검증은 실제 카카오 인증이나 운영 첫 주문 성공의 증거가 아니다. 기존 API/PG17 회원 주문 검증과 합성 화면 경로를 연결한 것이다.
