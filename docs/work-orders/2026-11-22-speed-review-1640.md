## 4. 개선 (바로 적용)
1. **방별 상시 대기열(아래 5절)**: 한 건 끝나면 **묻지 않고 다음 줄**. 대표 승인이 필요한 줄은 "승인 대기"로 표시만 하고 **건너뛰어 다음 줄**.
2. **대표 승인 하루 2번 묶음(11:00 · 17:00)**: 승인 대기 목록 한 곳(현황판 맨 위 "승인 대기" 표). 병합 · SQL · 기능 ON · 배포를 한 번에 답.
3. **잠금 · 기록 PR 합치기**: 배포 · SQL 1번 = PR 1개(잠금 → 적용 → 결과를 같은 PR에). 현황판은 **날짜별 파일**(`docs/dispatch/board/2026-11-22.md`)로 나눠 충돌 줄이기.
4. **CI 당번**: main CI 빨강 = 모든 방 병합 멈춤 + 컨트롤타워가 30분 안에 원인 PR. 매시 확인.
5. **파일 잠금 만료 2시간**: 잠금 표에 시작 · 만료 시각. 만료 지나면 다음 방이 가져감.
6. **Draft 48시간 규칙**: 48시간 움직임 없는 Draft는 정리(병합 · 닫기 · 대기열 뒤로).
7. **활성 지시서는 R17 하나 + 이 대기열** · 나머지는 "참고"로.
8. **`lib/store.ts` 분리 지시서**(도메인별 한 조각씩) → 쉬는 방 상시 작업으로.
