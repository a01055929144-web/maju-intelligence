# A-0 첫 PR — 리드 문서 선택·견적 복사

Ponytail: 사용함

## 구현 범위

- `LeadDocumentActions({leadId, recipient, companyId?})`는 단가표 보내기·견적 보내기 두 입구를 제공한다. T-1·기사 화면 담당자는 이 컴포넌트를 재사용한다.
- 기존 영업 채널 패널에서 사용하므로 리드 상세와 모바일 영업에 함께 적용한다. 같은 패널을 쓰지 않는 T-1·기사 화면은 각 담당자의 연결이 필요하다.
- P1 권한 API를 재사용해 페이지별 문서를 조회하고, 게시 버전의 내용으로 선택·행사/임박 필터·미리보기를 한다. 편집 중 초안이나 만료된 게시본은 보내기 대상으로 쓰지 않는다.
- 견적은 게시 단가표를 복사해 기존 P1 편집기로 받는 곳·가격을 조정하고 저장·게시한다. 공용 원본은 변경하지 않는다.

## 아직 실행하지 않는 경계

03의 승인 초안은 PR #180 `docs/work-orders/db-approval/sales-to-order-acceptance.md`이다. main에는 리드별 발송 기록·서명 링크 API 계약이 아직 없으므로 발급 버튼을 비활성화하고 미발송 상태를 명시한다. 기존 거래처용 P2 링크를 리드용으로 바꾸어 쓰지 않는다. 견적 게시만으로 리드 연결·발송 완료를 기록하지 않는다.

실제 공유 링크·카카오 문구·QR, 발송 기록과 연락 기록 연결, sheet/quote 수락 CTA·매장 정보 입력·수락 후 주문은 03 계약과 07 권한 확인 뒤 연결한다. 이 첫 PR을 A-0 전체 완료로 간주하지 않는다.

운영 DB·SQL·환경 변수·기능 플래그·기존 점수 재계산은 변경하지 않는다. `QUOTE_ACCEPTANCE`는 OFF 유지한다. 03/07 API 파일, `lib/store.ts`, `lead-score.ts`는 수정하지 않는다.
