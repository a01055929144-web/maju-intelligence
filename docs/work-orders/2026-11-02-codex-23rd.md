# Codex 작업지시서 — 23차 (2026-11-02 04:08 대표 지시)

22차에 이어서 적용한다. 22차와 다르면 이 문서를 따른다. 화면: 캔버스 v53의 OrderSummary · OrderSheetImage · BuyVoucher · UnitSettings.

## A. 출고 준비 열 순서 (22차 A 변경)

- 기본 열 순서: **품목 · 수량 · 단위 · 전일가 · 매출처 · 비고** · (삭제 −).
- 화면 문구는 "거래처"를 "매출처"로 바꾼다(매출처별로 나눠 보기 · 매출처 줄).
- 열 편집(공통 표)으로 순서를 바꿀 수 있다. 기본값은 위 순서다.

## B. 발주서 이미지 (21차 order_sheet 변경)

- 출고 준비와 **같은 구조 · 같은 열 순서**로 만든다. 다만 **전일가(단가) 열은 뺀다**: 품목 · 수량 · 단위 · 매출처 · 비고.
- 합계 줄: `■ 합계 · N곳`. 품목 이름은 반복하지 않는다. 총수량은 수량 칸, 단위는 단위 칸에 넣는다. 단위가 섞이면 줄을 나눈다.
- 비고만 노란색으로 강조한다(21차 정정 그대로). 품목 비고는 첫 줄의 비고 칸에 넣는다.
- [매출처별 / 합계만] 전환. PNG · 인쇄 · 카톡 글에 같은 순서를 쓴다.

## C. 입고 · 매입전표 (BuyVoucher, 20·22차 변경)

1. **기준 단가를 고칠 수 있게 한다.** 회색 입력 칸이다.
   - 위쪽 체크박스 "고친 기준 단가를 N일 기준 단가로 저장"은 기본 켬이다.
   - 켜 두면 등록할 때 `product_base_prices`에 `source=voucher`로 저장한다.
   - 실제 단가는 따로 저장한다(22차 C).
2. **"재고와 섞일 때 매입가" 패널을 없앤다.** 계산은 화면에 보이지 않게 자동으로 한다(D의 중앙값).
   - 줄 금액 아래 작은 글씨로 kg당 단가 · 실중량만 보여준다.
3. **[⚙ 단위 환산 설정] 버튼을 표 위 도구줄 맨 앞에 둔다.** 강조 테두리를 쓴다. [열 편집]이 그 옆에 온다. 머리 오른쪽 버튼에서는 뺀다.
4. **[입출금] 버튼**을 머리 오른쪽에 둔다. 16차의 입출금 팝업(MoneyPopup)을 그 매입처로 연다.
5. **등록하면서 지급**
   - 표 아래에 패널을 둔다. "같이 지급 (출금)" 체크박스, 방법(계좌이체 · 현금 · 카드 · 예치금에서 빼기(잔액 표시)) · 금액(기본값 = 전표 합계) · 날짜 · 계좌 · 메모.
   - 버튼 이름: 체크하면 "매입전표 등록 · 지급", 체크를 풀면 "매입전표 등록".
   - 저장: 매입전표 + `ledger_entries`(지급, voucher_id 연결)를 **한 트랜잭션**으로 저장한다.
     - 일부만 지급하면 남은 금액은 미지급으로 남긴다.
     - 예치금 차감은 매입처 예치금에서만 한다(잔액보다 많이 뺄 수 없다).
   - 전표를 삭제하거나 취소하면, 연결된 지급 기록을 함께 처리할지 확인 창으로 묻는다. 자동으로 지우지 않는다.
   - 매출전표에도 같은 방식("등록하면서 입금")을 적용한다.
   - 플래그 `VOUCHER_INLINE_PAYMENT_ENABLED`(기본 OFF). 돈 관련 기능이므로 플래그를 끈 채로 병합한다.

## D. 단위 환산 설정 (22차 B 변경)

- **기준값은 일단 "중앙값 (추천)"으로 고정한다.** 화면에는 고정 뱃지와 "나중에 고객사 설정에서 변경"만 보여준다.
  - 22차의 기준값 선택(회사 · 카테고리 · 품목별 select, 7가지 미리보기)은 **화면에서 숨긴다.**
  - DB 칸(`company_unit_policies.cost_basis` 등)은 22차대로 만들고, 기본값을 `median`으로 둔다.
  - 나중에 고객사 설정에서 바꿀 수 있게 연다(플래그 `UNIT_COST_BASIS_ENABLED`).
- 중앙값 대상: 박스 실중량(최근 5회 입고 실중량) · 섞인 재고 매입가(남은 재고 · 이번 입고들의 단가).
  - 실중량 계산 예: 9.3 · 9.5 · 9.6 → 9.5kg. 기록이 없으면 입력한 고정값을 쓴다.
- 표 레이아웃:
  - 열: ☐ · 품목 · 판매 단위 · 기본 매입 단위(작은 선택) · **환산(`1 박스 = [9.5] kg` 입력)** · 살 수 있는 단위(칩, 한 줄) · 최근 기록 → 중앙값.
  - 줄 높이를 같게 맞춘다. 칩은 줄을 바꾸지 않는다. 1440px 폭에서 가로 넘침이 없어야 한다.
  - 일괄 적용 막대(한 줄): 단위 + · 기본 단위 · 박스 실중량 % · 정한 품목은 그대로 · [적용].
