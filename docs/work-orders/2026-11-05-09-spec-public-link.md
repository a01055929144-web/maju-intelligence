## 별도 후속: 유통사 매입가 등락 방향

기존 `store_order_settings`를 회사별 동의 저장소로 재사용한다. 현재 컬럼에는 공개 동의가 없으므로 기본 false 컬럼, service_role 전용 방향 조회 함수, down, DB 승인표를 별도 초안으로 준비한다. 운영 SQL 승인·적용과 기능 활성화는 이 규격 PR에 포함하지 않는다.

계약은 회사별 opt-in과 서버 기능 플래그가 모두 켜졌을 때만 `{productId, direction: "up" | "down"}`을 받는다. 동일 단위·세금 기준의 직전 유효 매입가와 비교하며 반품·오류·정정 취소는 제외한다. 이전 유효값 없음·보합은 응답에서 제외한다. 원가·차액·변동률·마진·공급처·매입일은 반환하지 않는다. 클라이언트가 보낸 방향이나 원시 매입이력을 신뢰하지 않는다. 판매가와 별도인 '유통사 매입가 상승/하락'이라고 표시한다.
