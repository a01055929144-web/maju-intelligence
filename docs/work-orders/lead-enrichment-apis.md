### 하지 않는 것
- 배달앱(배민 · 쿠팡이츠) · 네이버 플레이스 리뷰 화면 수집: 공식 API가 없고 약관 위반이다.
- 카드사 매출 데이터: 유료 계약이 필요하다(나중에 검토).

## 연결 방법 (Codex)

- 보강 결과는 리드에 칸으로 저장한다. 출처 · 가져온 시각 · 매칭 신뢰도를 함께 둔다.
  - 새 칸은 승인 표에 올린다: `store_area_source`, `employee_count`, `monthly_search_volume`, `hygiene_grade`, `franchise_brand` 등. 이미 있는 칸이 있으면 그것을 쓴다.
- 점수(L-1 · L-3)에는 **값이 있을 때만** 반영한다. 없는 값은 0점이 아니라 "모름"으로 표시하고, 등급이 부당하게 떨어지지 않게 한다.
- 호출은 서버 배치(야간)와 리드 상세를 열 때로만 한다. 호출 한도 · 실패 재시도 · 캐시(같은 매장 30일)를 둔다.
- 우선순위 1을 먼저 붙인다: **인허가 면적 칸 확인 · 카카오 재매칭**. 2는 대표가 키를 발급하면(네이버 검색광고 API · 공공데이터포털 활용 신청) 바로 붙인다.
