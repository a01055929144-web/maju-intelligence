# 2026-11-04 견적서·단가표·마진·행사·인쇄 — 와이어프레임 다시 그리기 (텍스트)

대표 요청(20:19): 화면·레이아웃·버튼 위치 재설계. 견적서·단가표·템플릿을 직관적으로 만들기.
'문서 설정' 입력 대신 **회사 정보에서 가져온 항목을 목록에서 넣고 빼기**, 없는 정보는 그 자리에서 추가.

## 0. 공통 틀 (모든 단가 화면)

```

│ 단계 표시: ① 품목 담기 → ② 가격 정하기 → ③ 보여줄 정보 → ④ 미리보기·보내기 │
├───────────────┬──────────────────────────────┬───────────────┤
│ 왼쪽 (280px)   │ 가운데 (넓게)                 │ 오른쪽 (320px) │
│ 찾기·담기       │ 표 (지금 하는 일)              │ 실시간 미리보기 │
└───────────────┴──────────────────────────────┴───────────────┘
```
- 버튼 위치 고정: 주 버튼은 오른쪽 위 1개(파랑), 나머지는 ⋯ 안. 삭제는 줄 끝 휴지통 아이콘.
- 설명 문구는 한 줄 이하. 입력칸 이름은 회사 정보와 같은 말(용어집 따름).
- 모바일(390px): 왼쪽·오른쪽은 아래 시트로 접힘.

3. 1번 목록 [+ 새로 만들기 ▾] 하나로
4. 5번 마진 설정, 6번 행사·템플릿
