# CX-38b 주문 금액 스냅샷 → 전표·원장 일치 — DB 승인 요청

## 목적

과세 포함 단가와 소수 수량을 주문행에서 전표로 옮길 때 단가를 먼저 역산해 1원이 달라지는 경로를 막는다. 기존 문서·주문 데이터는 자동 보정하지 않는다.

## 변경 초안

- up: `docs/sql-drafts/2026-11-19-CX-38b-order-document-money-snapshot.sql`
- down: `docs/sql-drafts/2026-11-19-CX-38b-order-document-money-snapshot.down.sql`
- PG17: 기존 `2026-11-16-CX-38-order-sale-documents.pg17.test.sql`에 합성 포함가 회귀를 추가한다.

`business_document_lines`에 행 단위 `price_includes_tax_snapshot`을 추가하고, 주문행의 단가·포함 여부를 그대로 저장한다. 공급가·세액은 주문행과 같은 정수 원 반올림식을 사용한다. `save_business_document`의 기존 식별자·권한·보안 속성은 유지한다.

CX-66 부분 출고 스냅샷 매칭도 전표 단가와 포함가 여부를 함께 비교한다. CX-38b를 먼저 적용하고 CX-66 부분 출고를 적용하며, 되돌릴 때는 반대 순서로 CX-66 부분 출고를 먼저 제거한다.

## 돈 안전 표본

합성 과세 포함 단가 100원 × 0.500:

- 주문행: 공급가 45원 / 세액 5원 / 최종 50원
- 전표행·전표 머리·원장: 45원 / 5원 / 50원
- 취소 후 해당 전표 원장 순액: 0원
- 부분 출고 0.500·잔량 취소 0.500: 전표·원장 45원 / 5원 / 50원, 재고 이동 -0.500

## down 조건

포함가 스냅샷이 한 건이라도 있으면 `cx38b_down_refused_included_price_evidence`로 중단한다. 증거가 없는 경우에만 이전 계산식과 함수 정의로 돌아간다.
