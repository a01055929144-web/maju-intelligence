# CX-126 거래처 공통 등록 SQL 승인 검토안

상태: 2026-11-21 운영 DB 적용 완료. 재실행 금지. 기능 ON·배포는 승인되지 않았다.

## 변경

- `normalized_customers`: 개업 예정일을 추가한다.
- `product_suppliers`: 주소·상세 주소·상태·상태 확인 시각·사업자 형태·계산서 이메일·사업자등록증·개업 예정일을 맞춘다.
- 상태는 사업자 확인됨(`active`)·개업 준비(`registration_pending`)·휴업·폐업 네 종류다.
- 번호 보완과 상태 변경을 남길 공통 기록표를 추가한다. 기존 행은 유지한다.
- 운영의 기존 active 매입처는 사업자 형태·계산서 이메일이 NULL이어도 업그레이드와 기존 저장을 허용한다.
- 신규 active 등록의 필수값 검증은 등록 API에 유지하며, 기존 행을 자동 보정하거나 삭제하지 않는다.

| 확인 | 현재 |

| 대상 운영 프로젝트와 대표 승인 문구 | `fcmdvveqmcgtioelzqun` 명시 승인 · 2026-11-21 적용 완료 |
| 기존 두 테이블 열·제약 최신 정의 재확인 | 적용 직전 선행 객체 존재·신규 객체 0개 확인 |
| 기존 active 공급처 NULL 열 업그레이드·재저장 | PG17 회귀 통과 · 운영 38건 유지 확인 |
| CX-126 SQL → CX-120·123·122 순서 | 컨트롤타워 관리 |
