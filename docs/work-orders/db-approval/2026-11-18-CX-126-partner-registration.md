# CX-126 거래처 공통 등록 SQL 승인 검토안

상태: 검토용 초안. 운영 DB 적용·기능 ON·배포 승인이 아니다.

## 변경

- `normalized_customers`: 개업 예정일을 추가한다.
- `product_suppliers`: 주소·상세 주소·상태·상태 확인 시각·사업자 형태·계산서 이메일·사업자등록증·개업 예정일을 맞춘다.
- 상태는 사업자 확인됨(`active`)·개업 준비(`registration_pending`)·휴업·폐업 네 종류다.
- 번호 보완과 상태 변경을 남길 공통 기록표를 추가한다. 기존 행은 유지한다.

## 적용 전 승인표

| 확인 | 현재 |
|---|---|
| 대상 운영 프로젝트와 대표 승인 문구 | 미승인 |
| 기존 두 테이블 열·제약 최신 정의 재확인 | 적용 직전 필요 |
| CX-126 SQL → CX-120·123·122 순서 | 컨트롤타워 관리 |
| 기능 허용 회사 | 기본 OFF, 미승인 |
| 원복 | 새 값·기록이 있으면 거절 |

PG17은 네 상태 중 개업 준비 저장, 확인된 사업자의 필수 칸, 기록표 RLS를 일회용 DB에서 확인한다. 운영 데이터 쓰기와 자동 보정은 없다.
