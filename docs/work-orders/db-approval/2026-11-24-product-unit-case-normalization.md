# 상품 단위 대소문자 정리 — 운영 승인 준비

운영 프로젝트 `fcmdvveqmcgtioelzqun` 읽기 전용 집계 기준. 이 문서는 적용 권한이 아니다.

| 대상 | 영향 |
|---|---:|
| 상품 | 169개 (매입 단위 169, 판매 단위 166) |
| 현재 문서 초안 | 1개 · 2줄 |
| 견적서 초안 | 0개 · 0줄 |
| 기존 게시 버전 | 소문자 4줄 · **변경 제외** |
| 비초안 견적 | 소문자 0줄 · **변경 제외** |

소문자 분포: 매입 `ea` 43, `kg` 119, `Box` 1, `box` 5, `pack` 1 / 판매 `ea` 42, `kg` 117, `Box` 1, `box` 5, `pack` 1.

## 초안 경계

- 상품 `purchase_unit`·`sales_unit`과 그 상품을 이미 담은 현재 문서 초안·견적서 초안 줄만 `upper()`로 통일한다.
- 비공개 백업 스키마에 상품·문서·견적 줄의 전후 행을 저장한다.
- 영향 지문(회사 1, 상품 169, 문서 1/2줄, 견적 0/0줄)이 달라지면 적용 전 중단한다.
- `pricing_document_versions`, `customer_price_agreements`, 비초안 견적은 수정하지 않는다.
- down은 적용 후 다른 수정이 없을 때만 원래 단위 표기를 복구한다.
