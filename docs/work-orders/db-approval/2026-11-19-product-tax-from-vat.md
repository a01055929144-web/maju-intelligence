# 기존 상품 세금 구분 대조 및 정정 대기

상태: **운영 미적용 · 승인 대기**. 적용 파일: `docs/sql-drafts/2026-11-19-product-tax-from-vat.sql`. 운영 프로젝트는 승인 요청에만 명시한다. 이 문서는 운영 쓰기를 승인하지 않는다.

2026-11-19 읽기 대조: 활성 상품 713개 면세·34개 과세. 그중 면세 상품 379개(활성 378개)는 연결된 매입 이력 722행 전부 부가세 양수·과세로 기록됐다. 별도 1개는 이력 내 과세·면세가 섞여 대상에서 제외한다. 공급가액 비율로 세금 구분을 다시 추정하지 않는다.

적용 전: 같은 읽기 집계를 다시 실행해 379/378/722/회사 1곳과 대상의 세금값이 유지됐는지 확인한다. 적용 SQL은 백업 스키마를 새로 만들고 전체 대상의 변경 전 행을 보존한다. 건수가 달라지거나 세금값 외의 필드가 변하면 한 트랜잭션을 되돌린다. 상품 가격·매입 이력·기존 발행 문서는 수정하지 않는다. 기존 초안은 사용자 확인 후 세금 구분 반영이 필요하다. 복구 초안은 `docs/sql-drafts/2026-11-19-product-tax-from-vat.down.sql`이며, 정정 이후 대상 행이 한 칸이라도 달라졌으면 복구를 중지한다.

검증 상태: 읽기 사전 점검 완료. 폐기형 PG17의 합성 379상품·722이력 적용과 복구 통과. 근거 행의 부가세를 바꾸어 대상이 378개가 된 경우 적용이 중단되는 것도 확인했다. 시험 파일은 `tests/sql/product-tax-from-vat.pg17.test.sql`. 운영 프로젝트를 명시한 대표 승인이 끝나기 전에는 실행하지 않는다.
