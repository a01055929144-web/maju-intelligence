## 배포 경계

현재 대표 회사에서 `STORE_ORDERING_ENABLED`가 켜져 있다. 기존 주문 RPC를 유지하므로 SQL을 먼저 적용해도 현행 주문은 계속 동작한다. 새 앱은 `STORE_MEMBER_SESSION_ENABLED=true`와 회사별 `FEATURE_STORE_MEMBER_SESSION_COMPANY_IDS`가 함께 켜진 회사에서만 새 RPC를 사용한다. 그 외 회사는 기존 RPC를 사용한다. **새 앱 코드는 신규 SQL 적용·읽기 확인 전에 병합·배포하지 않는다.** SQL 적용 후 앱을 배포하고, 마지막에 대상 회사의 회원 플래그를 켠다. 회원 플래그를 켜기 전까지 기존 주문 동작을 확인한다. 기존 7인자 RPC 제거는 별도 후속 승인·전환 단계로 미룬다.

회원 기능이 켜진 회사에서 서버는 서명된 주문 링크로 회사·거래처를 확정한 다음, 카카오 세션에 묶인 활성 매장 구성원을 조회한다. 새 RPC는 주문 저장과 같은 트랜잭션에서 매장 계정·구성원·사용자의 활성 상태를 다시 잠그고 검사한다. `ordered_by_member_id`에 실제 주문자를 남긴다. 회원 기능이 켜진 회사에서는 공개 링크만으로 주문할 수 없다. 회원 기능이 꺼진 회사의 공개 링크 주문은 기존대로 동작한다.

검증 범위는 잘못된 매장/회사/사용자, 탈퇴·정지 상태, 같은 키 재요청, 주문자 기록, 권한 변경과 동시 주문, 데이터가 있는 상태의 down 거부다. 실제 운영 주문 쓰기는 별도 승인 전까지 수행하지 않는다.

## 호환안 검토 확인표

- 기준 원문: 컨트롤타워 로컬 호환 커밋 `084640cfa4aad909c37545143481f1eb61ff8c03`. 구 함수 제거안 #349는 운영 적용하지 않는다.
- PG17 확인 항목: 구 7인자 함수의 본문 해시·OID·실행 권한이 up/down 뒤에도 동일하고 기존 호출이 정상 주문을 저장함. 회원 주문 자료가 있는 down 거부 뒤에도 두 함수가 보존됨.
- API 확인 항목: 회원 전환 OFF/회사 제외는 구 RPC만 사용, ON 회사의 회원 없음/탈퇴/신규 RPC 오류는 구 RPC로 우회하지 않음. 클라이언트의 회사·회원·전환 여부는 신뢰하지 않음.
- 신규 함수 확인 항목: 실제 P0/P1/P2/S2 migration 기반의 회사/매장/회원/사용자 경계, 주문 작성자·가격 스냅샷, 동일 키와 두 연결 경합. 기존 회원 주문 행 백필 없음.
- 최종 실행 결과와 CI 링크는 대체 PR 본문을 기준으로 확인한다. PG17/CI 통과는 운영 적용 승인이나 실주문 E2E 완료가 아니다.
- 운영 적용 전: 07 회원 코드 및 신규 함수/기존 테이블 접근 권한을 확인하고, 대상 SQL·회사·복구 경로가 명시된 별도 승인을 받아야 한다. 이 확인표에는 승인 완료 표시를 하지 않는다.

## 적용 이력·원문 동일성 — 2026-11-08

- 컨트롤타워가 승인 SQL의 운영 적용과 읽기 검증 완료를 보고했다. 이 작업에서는 운영 DB 접속/적용/재실행을 하지 않았다.
- 새 `place_store_member_order` 10인자 함수 1개, service_role만 EXECUTE, SECURITY INVOKER를 확인했다는 보고를 기록한다. 기존 `place_store_order` 7인자 함수의 OID·정의 해시·권한은 적용 전후 동일하다고 보고됐다.
- 보고 시점 운영 주문·회원 자료는 0건, 회원 기능은 OFF다. 이 값은 컨트롤타워의 확인 결과이며 이 작업에서 운영 조회를 추가 수행한 것이 아니다.
- 원문 기준: `084640cfa4aad909c37545143481f1eb61ff8c03`의 up SQL. 실행부(`begin;`부터 파일 끝까지, LF 기준) SHA-256: `5657e6f16b627641db5240b5279e8e437286254440207dc494cdffdebf485c79`. 운영 완료/재실행 금지 헤더만 갱신했으며 실행부는 바이트 동일하다.
- 이미 적용한 SQL을 운영에서 재실행하지 않는다. 이후 변경은 별도 검토·승인·새 변경 이력으로 남긴다. down SQL도 별도 승인 없이 실행하지 않는다.
- 코드 병합/배포·회원 ON·실제 첫 주문 E2E는 이 적용 보고로 승인되거나 완료되지 않는다. 공개 PR 본문에는 운영 프로젝트 식별자를 기재하지 않는다.
