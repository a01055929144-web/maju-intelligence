# CX-81 리드 외부정보 일괄 작업 DB 승인 요청

- 상태: 검토용 초안, 운영 미적용
- 기본값: 기능 OFF이며 회사 allowlist가 함께 일치해야 동작
- 범위: 목록 전체 선택 상한과 같은 최대 5,000건, 회사별 KST 일일 한도, 1건씩 순차 claim, 작업 이력, 중간 취소, 실패 건 재시도
- 실행 시간: 한 호출은 최대 45초 안에서만 새 항목을 claim하고 멈춘다. 남은 `pending` 항목은 같은 작업 ID로 `resume`한다.
- 동시성: 같은 작업에 `running` 항목이 있으면 추가 claim하지 않아 재개 요청이 겹쳐도 외부 호출을 병렬화하지 않는다.
- 입력: UUID 정규 형식, 허용된 action·operation, 1~5,000개 리드, 일일 한도 1~1000만 허용한다. 5,000건 초과는 일부를 버리지 않고 요청 전체를 거부한다.
- 격리: 모든 조회·변경 키에 `company_id` 포함, 서비스 역할 전용 RPC
- 인스타그램: 후보 JSON만 작업 결과에 보관. 자동 확정·자동 발송 없음
- 되돌리기: 이력 행이 하나라도 있으면 down 거부
- UI 연결: 확인 못 함 (01-room CX-79/80 소유 파일 미수정). UI는 응답의 `remainingItems`와 `maxItems`를 표시하고, `errorCode=daily_limit_exceeded`이면 다음 KST 날짜에 같은 `jobId`로 `resume`해야 한다.

승인 후에도 별도 운영 적용 절차와 feature flag 승인 전에는 실행하지 않는다.
