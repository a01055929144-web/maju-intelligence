# CX-81 리드 외부정보 일괄 작업 DB 승인 요청

- 상태: 검토용 초안, 운영 미적용
- 기본값: 기능 OFF이며 회사 allowlist가 함께 일치해야 동작
- 범위: 최대 50건, 회사별 KST 일일 한도, 1건씩 순차 claim, 작업 이력, 중간 취소, 실패 건 재시도
- 격리: 모든 조회·변경 키에 `company_id` 포함, 서비스 역할 전용 RPC
- 인스타그램: 후보 JSON만 작업 결과에 보관. 자동 확정·자동 발송 없음
- 되돌리기: 이력 행이 하나라도 있으면 down 거부
- UI 연결: 확인 못 함 (01-room CX-79/80 소유 파일 미수정)

승인 후에도 별도 운영 적용 절차와 feature flag 승인 전에는 실행하지 않는다.
