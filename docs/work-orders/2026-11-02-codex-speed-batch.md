### WO-21 아이디 로그인 · 계정 관리 (12차) — 플래그 OFF, DB 승인 필요
- 로그인 페이지를 분리한다.
  - `/login` (고객사): 아이디+비밀번호 + **배송기사는 카카오 버튼**. 모바일에서는 카카오 버튼을 위에 둔다.
  - `/admin/login` (관리자): 아이디+비밀번호만. 고객사 화면에 이 페이지 링크를 두지 않는다.
- `app_users.login_id`: unique, 소문자 `^[a-z0-9_]{4,20}$`. 카카오 전용 계정은 null.
- 관리자도 `app_users`(maju_super_admin/maju_operator)에 둔다. env는 최고 관리자가 0명일 때 처음 1회 부트스트랩용으로만 쓴다.
- 비밀번호:
  - 10자 이상, 기존 scrypt를 그대로 쓴다.
  - 5회 틀리면 10분 잠금.
  - 임시 비밀번호로 들어오면 바로 변경하게 한다(`must_change_password`).
  - 아이디·비밀번호를 바꾸거나 계정을 끄면 `session_version`을 올려 기존 세션을 끊는다.
- 배송기사: 기존 카카오 초대(`acceptStaffKakaoInvitation`)를 쓴다.
  - 초대 없이 카카오로 로그인하면 거부한다("등록된 배송기사가 아니에요"). 개인 워크스페이스는 만들지 않는다.
  - 초대 링크는 7일 유효하고, 전화번호 끝 4자리를 확인한다.
- 계정 관리(`/admin/accounts`): 만들기 · 아이디 변경 · 비밀번호 재설정 · 잠금 풀기 · 끄기.
  - 배송기사를 고르면 카카오 초대 링크를 만든다.
  - 임시 비밀번호는 1회만 보여준다.
  - 운영자는 관리자 계정을 바꿀 수 없다(403).
- 관리자 계정의 아이디·비밀번호는 대표가 배포 후 직접 정한다. 시드나 마이그레이션에 값을 넣지 않는다.

- 구를 누르면 요약이 나온다. 고객사별 표와 합계. 집계는 서버에서 하고 관리자만 본다.

### WO-13 매입·매출 전표 (5~10·15·16차) — 돈 관련 부분은 플래그 OFF
- **전표 목록**:
  - [전체 인쇄], 체크하면 선택 바(양식 · 한 장씩/이어서 · 흑백) → [선택 인쇄]
  - 🖨 인쇄 횟수 표시, "아직 안 뽑음" 필터. 기본 기간은 오늘.
- **전표 입력**:
  - 왼쪽: "오늘 전표 / 거래처 전체" 탭 · [+ 새 전표]
  - **상단 거래처 정보 줄**: 상호 · 사업자번호 · 대표·연락처 · 결제 조건 · 이번 전표 · **현잔액(미수/미지급)** · **예치금 잔액** · 최근 입금
  - 입력 표를 크게(줄 44px · 글자 14px). 품목 찾기 창은 820px이고 상품명·규격·단위를 따로 검색한다.
  - 강조 배지(켜고 끄기, 끄면 흐리게): **견적(보라) → 단가표(초록) → 최근 출고/입고(파랑) → 출고/입고 이력(회색, 한 번이라도 나간 품목) → 반품(빨강)**. 숫자 1~9로 바로 넣는다.
  - **반품**: 수량이 음수면 반품 배지를 달고 붉은 줄로 표시한다. 그 매장에서 반품된 품목을 다시 넣으면 경고한다. 합계에 "반품 −N 포함"을 표시한다.
  - 상품 히스토리: 이 거래처 / 매입 / 매출 / 전체, 30/90일/전체.
- **[💰 입출금] 버튼은 화면 맨 위**에 둔다. 누르면 팝업:
  - 입력: 입금/출금/상계/예치금 충전/예치금 사용·환불 · 계좌/카드/현금 · 날짜 · 금액 · 연결 전표 · 메모 · "잔액 A → B" 미리 보기
  - 오른쪽에 입출금 히스토리 + [수정] [취소]
  - 마감한 달은 대표만 수정할 수 있다.
- 기존 기능 유지: 엑셀형 단축키, 역마진, 원장, 입출금 화면.
