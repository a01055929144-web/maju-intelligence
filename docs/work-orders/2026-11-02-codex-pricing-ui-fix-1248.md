## 0. 규칙 정정 — "기능 우선, UI는 나중"의 뜻 (AGENTS.md 0-0-1 보완)

- **지금 와이어프레임대로 만드는 것**: 화면 구성.
  - 어떤 블록 · 카드 · 탭 · 필터 · **표 열** · **버튼**이 있는지
  - 업로드 같은 기능 입구
  - 화면 이름과 메뉴 위치
- **나중으로 미루는 것**: 모양.
  - 색 · 간격 · 글자 크기 · 아이콘 · 그림자 · 정렬을 다듬는 일
- 그래서 **이미 있는 옛 화면을 그대로 켜는 것은 "기능 우선"이 아니다.** 와이어프레임에 있는 버튼 · 열 · 업로드가 빠졌다면 기능 누락이다.
- 화면 기준: 캔버스 v53(https://claude.ai/artifact/BmDLKrUjKFCALq2tHt8MUm)

## 1. 사이드바: 묶음을 기본으로 펼친다 (WO-20 정정)

- 지금은 모든 묶음이 `<details>` 접이식이고, 현재 페이지가 속한 묶음만 열린다. 대표가 메뉴를 찾기 어렵다.
  - 원인은 speed-batch WO-20의 "현재 묶음은 펼친다" 문구가 다른 묶음은 접는 것으로 해석된 것이다.
- 바꿀 것:
  - **모든 묶음을 기본으로 펼친다.**
  - 묶음 이름을 누르면 접을 수 있고, 접은 상태는 사용자별로 기억한다(localStorage, try/catch).
  - 현재 페이지가 속한 묶음은 접혀 있어도 항상 펼친다.
  - 사이드바 전체 축소(72px) 기능은 그대로 둔다.
- Playwright: 처음 들어오면 모든 묶음이 펼쳐져 있는지, 접은 뒤 새로고침해도 유지되는지, 모바일 메뉴에서도 펼쳐져 있는지.

## 2. `/revenue/pricing` = **매입가 반영** (MainManual 와이어프레임대로 다시 구성)

지금 화면은 P0 관리 폼(마진 그룹 · 기본 마진 · 재계산 표)만 있다. **엑셀 업로드가 없다.**

**머리 버튼**: [엑셀 양식] [엑셀 올리기] [저장 (N건)]
- 회사가 ERP 미연동이면 머리에 `ERP 미연동` 뱃지와 안내 띠를 둔다.
- 연동 회사 화면(Main)은 이번에는 뱃지만 바꾸고, 나머지는 같은 화면으로 둔다.

**엑셀 올리기**
- 기존 상품 가져오기의 열 맞추기 부품(`/revenue/products`의 매입처 가져오기 · `excel-mapping-preview`)을 **재사용**한다. 새로 만들지 않는다.
- 맞출 열: ERP 코드 · 품목 · 규격 · 단위 · 매입처 · 매입가.
- 올린 값은 바로 저장하지 않는다. 아래 표의 **"변경 후" 칸에 후보로 채운다.**
  - "바꾼 방법" = 엑셀
  - ERP 코드 → 품목명+규격 순서로 맞춘다.
- 맞는 상품이 없는 줄은 "신규" 탭에 둔다. [상품으로 만들기]는 #164의 일괄 생성 경로를 재사용한다.
- [엑셀 양식]은 지금 상품 목록을 같은 열로 내려받는 파일이다.

**영향받는 문서 카드**
- 변경 후보 때문에 값이 바뀌는 단가표 · 견적서 · 행사 · 임박 문서를 카드로 보여준다. 카드 내용: 종류 · 이름 · 바뀌는 품목 수.
- 확정 전에는 아무것도 바뀌지 않는다는 안내 한 줄.

**보기 · 필터**
- 탭: 변동 있음 · 인상 · 인하 · 신규 · 전체
- 매입처 선택, 바꾼 방법(직접 · 엑셀 · 전표) 선택, 검색, ⚙ 열 편집(공통 표)

**표 열**(공통 표 WO-01)
- ☐ · 품목 · 규격 · 단위 · 매입처 · 현재(매입가) · 적용일 · **변경 후(입력)** · 변동(▲▼ %) · 바꾼 방법(+ 근거: 파일명 · 전표번호) · 쓰는 곳(문서 링크)
- 합계 줄: 품목 수 · 현재 합 · 변경 후 합 · 평균 변동
- 페이지 크기 30 · 50 · 100

**저장(N건)**
- 체크한 줄만 저장한다. 순서:
  1. `product_catalog.purchase_price`와 매입처 원가 이력을 갱신한다(기존 경로 재사용).
  2. 바뀐 품목만 P0 재계산을 한다(기존 `recalculate`).
  3. 영향받는 문서는 "다시 계산 필요"로 표시한다.
- 저장 뒤에는 직전 저장을 **되돌릴 수 있게** 한다(P0 `restore` 재사용).
- 아래에 판매가 처리 규칙 한 줄: 직접 정한 판매가는 그대로 두고, 마진으로 계산하는 품목만 다시 계산한다.

**변경 후 후보 보관**
- 저장하기 전 후보는 화면 상태로만 둔다(DB 변경 없음).
- 새로고침하면 사라진다는 경고를 띄우고, 나가려고 하면 확인 창을 띄운다(`useUnsavedChangesWarning`).

**마진 설정은 옆 화면으로 옮긴다**
- 지금 화면에 있는 마진 그룹 · 카테고리 연결 · 기본 마진 · 품목별 마진/직접가 폼은 **`/revenue/pricing/margins`(마진 그룹)**로 옮긴다. 코드는 재사용한다.
- 사이드바 "주문·단가"를 **매입가 반영** / **마진 그룹** 두 메뉴로 나눈다.

## 3. `/revenue/pricing/documents` = **견적서·단가표** 목록 (Sheets 와이어프레임대로)

**머리 버튼**: [주문 설정] [직전 변동분 복구] [변동분 일괄 계산] [+ 견적서] [+ 단가표]

**카드 4개**: 게시 중 · 다시 계산 필요(문서 수 · 품목 수) · 이번 주 링크 주문(건수 · 금액) · 만료 7일 이내
- 아직 데이터가 없는 값은 `0` 또는 `–`로 둔다.

**필터**
- 종류 탭(전체 · 단가표 · 견적서 · 행사 · 임박) · 상태 · 공개 범위
- 날짜 기준(작성일 · 유효기간) + 오늘 · 7일 · 30일 · 이번 달 · 기간 지정
- 이름 · 매장 검색

**선택 막대**: 선택 N건 · 엑셀(내보내기) · 다시 계산 · 기간 연장 · 복사

**표 열**
- ☐ · 종류 · 이름(편집 화면 링크) · 공개 범위 · 품목 수 · 평균 마진 · 평균 할인율 · 이번 달 주문 매입가 · 이번 달 주문 판매가 · 상태 · 작성일 · 유효기간 · 매장 링크(곳 · 주문 · 열람)
- 합계 줄 · 페이지 30 · 50 · 100

**편집 화면**
- 지금 있는 P1 편집기(`pricing-documents-workspace`)로 연결한다. 편집기 화면 구성(QuoteEditor 와이어프레임)은 다음 PR로 한다.
- 단, 편집기 안에 **품목 엑셀 내보내기**와 **품목 엑셀로 담기**(ERP 코드 · 품목명으로 맞춤)는 이번에 넣는다.
