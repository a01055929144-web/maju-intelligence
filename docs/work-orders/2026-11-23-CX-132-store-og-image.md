# CX-132 ② 매장용 OG 이미지

Ponytail: 사용함

- pricing 소유. #1314의 서명 별칭과 검증된 메타데이터 경계를 재사용한다. 새 DB·SQL·키·외부 QR 서비스 없음.
- 기존 전역 `app/opengraph-image.tsx`(유통사 영업 운영 안내)은 수정하지 않는다. 같은 MAJU M 표식·녹색 배경과 1200×630 PNG 방식을 사용한다.
- 공개 문서의 OG/Twitter에만 `/q/<메타데이터 ID>/image`를 붙인다. 이미지 필드는 회사가 DOCUMENT_SHARE_BRANDING_COMPANY_IDS에 허용된 일반 공개 문서에만 존재한다. 기본 OFF·리드 영업 미리보기/다른 회사는 새 이미지 없음.
- 이미지: MAJU 앞, 식자재 단가 비교·주문, 발행 회사·문서명, 숨긴 줄을 제외한 발행 품목 수, 가격 유효기간, 작은 운영 비브(BIV). 단가·연락처·고객·토큰·임의 하단 정보는 렌더러 입력에 없다.
- 기존 문서의 발행본/가격/공유 행/링크/QR을 수정하지 않는다. 링크의 현재 게시 head 읽기를 기존 공개 열람과 공유해 연장 후 유효기간/제목이 서로 어긋나지 않도록 한다. 원래 발행 버전 식별은 그대로 보존한다.
- 이미지 URL에 문서 토큰이나 서명 별칭을 넣지 않는다. 회수·만료·회사·보관·공개 입구 경계는 기존 검증을 재사용한다. 응답은 no-store/no-referrer/noindex다.
- 다음 ③ 화면에서 같은 기본 문구를 재사용하도록 중앙 브랜드 상수와 검증된 일반 열람의 `brandingAvailable:true` 읽기 계약만 준비한다. OFF/리드 응답에는 키가 없고, 화면 표시는 이 PR에 넣지 않는다. 서버 파일을 한 번만 연결해 다음 단계에서 다시 수정하지 않는다.

## 확인

- 실제 ImageResponse PNG의 형식/1200×630과 회사·문서 필드 출력, OFF/허용된 이미지 없는 경우/조회 오류 차단을 단위 시험한다. PNG 근거: `readonly-pg17/cx132-og/store-share.png`.
- 현재 head 메타데이터와 공개 열람의 제목/유효기간 일치·숨김 제외·원본 행 불변, 브랜드 OFF 응답 보존을 합성 API 시험한다.
- 로컬 npm 실행 없음. 원격 단위/lint/Next 타입/build/Stage A와 기존 PC1440/390 회귀를 확인한다. 이미 통과한 #1314의 실제 카카오톡 발송/캐시 갱신은 여전히 미실행이며 총괄방 운영 관문 뒤 확인한다.
- 운영 DB 쓰기·기능 ON·배포 없음. Security Audit 미설치: 기존 검증 경계 재사용과 공개 입력 화이트리스트를 수동 검토한다.
- 기술 근거: [Next ImageResponse 공식 문서](https://nextjs.org/docs/app/api-reference/functions/image-response).
