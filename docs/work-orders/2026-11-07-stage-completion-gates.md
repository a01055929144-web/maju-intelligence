## 병렬 작업 충돌 방지

1. 04는 업로드·상품·실제 파일 미리보기, 09는 문서·매장 주문 UI, 05는 전달 기록, 03은 수락·전표, 07은 인증·회원 경계, 02는 배송 생산자, 01은 지도·코스 소비자를 소유한다.
2. 06은 퍼널, 08은 관리자 오류를 담당한다. D/E 원천 ID가 생기기 전에는 합성 지표를 운영 수치로 제시하지 않는다.
3. `lib/store.ts`, 메뉴, 백엔드 계약, 중앙 DB 승인표와 이 체크리스트는 컨트롤타워가 조정한다. 같은 파일은 먼저 병합한 쪽의 최신 main을 기준으로 다시 맞춘다.
4. 운영 변경은 명시 승인 → PG17·CI → 적용 후 읽기 검증 순서다. 실데이터 쓰기는 기존 승인 범위와 최종 화면 확인을 함께 지킨다.
