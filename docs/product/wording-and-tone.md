# MAJU 용어·말투 기준 (11/3 확정안)

## 말투
- 안내·설명: 합쇼체 "~합니다", 요청은 "~하세요"/"~해 주세요". 반말·"~해요" 쓰지 않음(현재 UI 0건).
- 버튼: 동사 명사형 2~6자 — 저장, 연결 해제, 견적서 작성, 기본 문구 저장. "~하기" 붙이지 않음.
- 오류: 무엇이 안 됐는지 + 다음 행동. 예) "업로드하지 못했습니다. 잠시 후 다시 시도해 주세요."
- 영어·개발어 노출 금지: Unauthorized, flag, SQL, DB 등 → "로그인이 필요합니다", "준비 중입니다".

## 용어

|---|---|---|
| 고객사 | MAJU를 쓰는 회사(관리자 화면에서만) | 유통사(운영 화면), 업체 |
| 회사 / 우리 회사 | 운영 화면에서 자기 회사 | 고객사(운영 화면) |
| 거래처 | 이미 거래 중인 매장(영업·배송 화면) | 고객, 업체 |

| 출발지 | 배송 출발 창고 주소 | 창고 주소(설명에서 "출발지(창고)" 허용) |
