# 회사 정보 통합 스펙 (11/3 대표 결정)

## 왜 필요한가
회사 기본 정보가 있어야 영업이 정확해진다. 각 값이 어디에 쓰이는지:
| 회사 정보 | 쓰이는 곳 |
|---|---|
| 취급 품목 | 리드 업종 적합 점수, DM 추천 품목 |
| 주요 거래 매장군 | 리드 업종 필터 기본값 |
| 배송 지역 + 영업 지역(확장 희망) | **리드 수집 지역(가장 중요)** — 저장 즉시 company_lead_search_regions 와 동기화 |
| 배송 요일·마감·시간대 | DM·견적·주문 링크 안내 문구 |
| 결제 주기(기본 협의)·최소 주문 | DM·견적·주문 링크 |
| 소개·대표 이미지·연락 담당자 | DM·팸플릿·주문 링크 첫 화면 |
홈 '오늘 할 일'에 "회사 정보 n/12 — 채우면 리드 정확도가 올라갑니다" 카드 노출.

## 운영 계정 (대표·관리자 수정, 직원 보기)
- 기본: 상호·사업자번호·대표자·업태·종목·종사업장·설립일·사업장 주소 = 보기만(🔒 관리자에게 요청). 대표 전화*·팩스·이메일·출발지*·연락 담당자(이름/연락처/상담시간, 여러 명)·소개·대표 이미지 = 입력.
- 품목: 취급 품목(종합식자재·농산·수산·축산·커피/베이킹·유제품·음료/주류·자재/용품), 매장군 11종, 주력 품목.
- 배송: 배송 요일*, 주문 마감, 익일배송 마감, 시간대, 방식(직배송/택배), 배송 지역, 영업 지역(확장 희망 — 리드 수집에 바로 반영), 코멘트.
- 결제: 방식(카드/현금/계좌이체), 주기*(선결제/당일/7일/10일/15일/월말/협의, 기본 협의), 최소 주문, 첫 주문 최소, 코멘트. 입금 계좌 = 보기만.
- 상담: 요일·시간, 채팅 문의 가능, 신규 매장 대응 가능, 휴무 안내.
- 서류: 사업자등록증·통장사본 = '제출 완료'만 표시.
- `*` 첫 로그인 필수 4개.

## 관리자 (모든 고객사, 모든 항목 편집)
- 위 전부 + 🔒 항목 편집, 서류 열람(60초 링크, 열람 기록), 계정 탭(이름 변경·재설정·연결 해제·기사 초대), 관리자 메모(등급·가격 경쟁력·ERP·요금제·계약일·체험 종료·내부 메모).
- 항목별 "마지막 수정 주체·시각" 표시.

## 보류 (문서로만, 다음 차수)
- 관리자 [매칭] 탭: 취급 품목·매장군·배송/영업 지역·마감·결제 주기·최소 주문·신규 대응으로 매장↔고객사 조건 일치 수 계산, 실제 연결 작업.
- 참고 양식: 매칭 정보 수집 엑셀 3종(월푸상사·채근담·코리아유통 기입본).
