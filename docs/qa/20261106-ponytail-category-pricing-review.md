## 범위와 기준

- 코드: 상품 분류 편집·저장 API, 마진 그룹 편집, 가격 문서 API, 매장 주문 화면·API.

- Ponytail: 기존 분류·가격 경로를 재사용하고, 확인된 오류 한 곳을 최소 변경으로 고쳤다. 새로운 스키마·의존성은 추가하지 않았다.
- 이 작업 폴더는 PR #277의 커밋을 기반으로 한다. PR #276의 최신 마진 화면은 GitHub `main` 파일을 읽기 전용으로 확인했다. 두 변경을 합친 로컬 빌드와 운영 화면은 아직 검증하지 못했다.

## 병합 전 남은 검증

1. 최신 `main` 위에 이 수정만 재적용해 #276·#277 통합 빌드와 CI Playwright를 통과시킨다. 현재 환경의 GitHub CLI 접속은 이름 조회 오류로 막혔다. 공개 GitHub 파일 업로드도 자동 승인 검토가 정확한 브랜치·파일 내용의 명시적 승인 부족을 이유로 거절했으므로 우회하지 않았다.
2. 실제 회사의 분류 이름 변경 → 저장 → 새로고침 후 이전 경로가 사라지고 새 경로에 상품이 보이는지 확인한다. 운영 데이터 변경은 이 검증에 포함하지 않는다.
3. 마진 그룹은 상품 748개/5,000개 규모에서 네트워크 요청 수와 완료 시간을 측정한다. 지연 또는 부분 저장이 확인되면 단일 트랜잭션 API 설계를 승인 표로 올린다.
