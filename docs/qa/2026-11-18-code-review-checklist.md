기준: main `09d4fbc` · 정적 코드 확인 1차. 이 문서는 새 기능 지시서가 아니다. 수정 배정은 [R15 우선순위](../dispatch/2026-11-18-R15-codex-priority-sequence.md)와 [중앙 현황판](../dispatch/2026-11-10-R1-board.md)의 파일 소유·진행 중 PR을 먼저 대조한다.

## 사용법과 완료 판정

- 상태는 `미점검 → 코드 근거 확인 → 재현/시험 확인 → 담당 PR → CI 초록 → 병합 → 배포/운영 확인` 순서로 기록한다. 정적 분석만으로 운영 장애나 수정 완료를 단정하지 않는다.
- 발견 항목마다 **기준 커밋·파일/행·조건·예상 결과/실제 코드 동작·영향·재현 방법·담당방·겹치는 PR·수정 PR·검증·배포 상태**를 적는다. 근거가 부족하면 `가설`로 둔다.
- 같은 파일을 쓰는 기존 작업이 있으면 별도 코드를 시작하지 않고 그 방의 다음 작업으로 전달한다. 총괄방은 현황판만 관리한다.
- 운영 DB 쓰기·기능 ON·배포는 이 점검표로 승인되지 않는다. 기능 코드는 Ponytail, 관련 CI와 권한·돈 안전 검사를 거친다.
