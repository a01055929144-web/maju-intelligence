# Canonical 병합 보완 dry-run

운영 DB 읽기 전용 집계. 병합 실행·삭제·상태 변경은 하지 않았다.

## 안전 규칙 적용 결과

| 회사 | 안전 병합 그룹 | 포함 행 | 상세주소·개업일·업태 차이로 제외된 그룹/행 |
|---|---:|---:|---:|
| 04ebb7bb… | 4,274 | 6,673 | 76그룹 / 80행 |
| 898d85fc… | 1,307 | 1,308 | 13그룹 / 13행 |

원천키와 사업자번호 중복 그룹은 두 회사 모두 0건이며, 현재 병합 후보는 안전 검사를 통과한
상호+주소 근거다. `merged_into_lead_id` 방식으로만 병합하고 행은 삭제하지 않는다.

## 영업·폐업 혼합 상태

정규화 상호+주소 후보 모집단에서 영업·폐업이 섞인 그룹은 본사 554그룹(1,849행), 시범사
53그룹(122행)이다. 출처 이력의 `raw_payload.lastModified`로 최신 상태를 비교할 수 있는 그룹은
본사 23그룹(최신 폐업 22, 최신 영업 1), 시범사 0그룹이다. 나머지 본사 531그룹과 시범사
53그룹은 자동 상태 확정을 금지하고 `폐업 확인 필요`로 둔다. 이 수치는 2026-10-23 운영 DB
읽기 전용 집계이며, 최종 안전 병합 계획을 실행하기 전에 같은 규칙으로 다시 계산해야 한다.
