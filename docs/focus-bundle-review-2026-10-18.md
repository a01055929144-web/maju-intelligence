## 화면 범위와 직접 URL

| 구분 | 경로 | 처리 |
|---|---|---|
| 핵심 | `/dashboard?view=leads&leadType=permit`, `leadType=keyword`, `/revenue/contacts` | 유지 |

숨긴 진입점은 사이드바 10개 보류 메뉴, 지도 거래처·리드 견적 버튼/드로어, 리드 상세 견적 빠른 액션·견적 진행 카드, 모바일 영업의 견적 KPI·결과·전달자료·작성기, 설정의 거래처 히스토리 바로가기다. API는 변경하지 않았다.

지도 상단의 `지도`/`코스`는 각각 `영업 동선`(신규·영업 리드와 거래처)과 `배송 동선`(코스·배송 상태)으로 구분했다. 거래처 메뉴가 숨겨져도 지도 카드의 거래처 추가·상세 편집·주소 변경과 오늘 코스의 거래처 데이터 사용 경로는 그대로 유지된다.

## 보강 결과

2026-10-18 크론 60건은 지역 매칭 24, 미매칭 36, 상호명 단독 0, 전화 발견/성공 10건이었다. 적재 직후 `metadata.trigger=ingest` 이벤트는 최근 7일 0건으로, Vercel 60초 종료 전에 후속 작업이 완료되지 않았거나 신규 적재가 없었던 것으로 보인다. 다음 일일 크론이 이어받는다. 배포 후 다음 크론 수치는 별도 확인 대상이다.

최근 신규 20건을 새로 수동 보강하는 작업은 운영 데이터를 변경하므로 이번 읽기 전용 측정에서 실행하지 않았다. 기존 이벤트만으로는 동일 20건의 전후 전화 확보를 신뢰성 있게 재구성할 수 없다.

## 영업시간·브레이크 타임 조사

- Google Places의 `regularOpeningHours.periods`는 요일별 여러 영업 구간을 구조화해 반환하므로 같은 요일의 두 구간 사이를 브레이크 타임 후보로 계산할 수 있다. 단, 실제 브레이크가 아니라 분할 영업일 수 있어 담당자 확인이 필요하다.
- 현재 코드는 Legacy Place Details에서 리뷰 필드를 요청한다. `opening_hours`는 Legacy Contact 필드이며, 신규 API의 `regularOpeningHours`는 Place Details Enterprise SKU다. 신규 API 기준 월 1,000회 무료 Enterprise 호출 이후 과금 대상이므로 필드 추가는 비용 등급 변화로 본다.
- 카카오 Local 키워드 응답은 이름·주소·좌표·전화·장소 URL만 제공하고 영업시간은 없다. 네이버 지역 검색도 영업시간을 제공하지 않고 전화 필드조차 빈 값으로 유지된다.
- 현재 DB에는 리드 영업시간 구조가 없어서 신규 10곳/영업 10곳 저장 데이터 표본 확보율은 0/10, 0/10이다. 외부 Google 호출 20건은 유료 가능성과 운영 데이터 변경 승인 전이므로 실행하지 않았다.

공식 근거: Google Places field tiers 및 Place Details 문서, Kakao Local API, Naver Local Search API. 저장 구조 초안은 `docs/sql-drafts/lead-business-hours-structure.sql`이다.

방문 결과는 현재 `call/dm/visit/hold/exclude/quote` 행동과 자유 메모로 저장할 수 있지만, 요청한 `부재/관심/단가표 전달/재방문 예정/거래 시작/거절`을 방문 결과 하나의 표준 집합으로 강제하지 않는다. 다음 묶음에서는 `visit` 결과 enum과 다음 액션일을 연결하는 것이 가장 작은 완성도 개선이다.

리드↔거래처는 이미 사업자번호·상호·주소 기반 `findLeadCustomerDuplicate`와 `matched_customer_id`를 사용한다. 신규 거래처 생성 모든 경로에서 같은 매칭 함수를 호출하도록 모으고, 매칭 시각·방법을 남기는 초안은 `docs/sql-drafts/lead-customer-match-audit.sql`에 작성했다.

### 큰 개발 없이 올릴 우선순위 3개

1. 방문 결과 6종을 PC·모바일에서 동일하게 기록하고 연락 원장의 후속일과 연결한다.
2. 신규 리드 기본 화면에서 폐업·대상 외 업종을 접고 전화 있음/카카오 매칭 상태를 우선 노출한다.
3. 거래처 전환 완료 카드에 배송지 주소·권역·오늘 코스 반영 여부를 한 번에 확인시킨다.
