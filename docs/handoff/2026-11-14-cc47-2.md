## 1. 47-2 ① 거래처 마커 상호명 알약

### 요구(지시서 그대로)
- 등급 보기: `[C] 상호` / 차량 보기: `[1] 상호`(차량 색, **미배정은 "미"**, title 은 `1호차` / `미배정`).
- **level ≥ 7(축소)** 이면 알약 대신 **배지만**(원형) — 기존 `computeCompactLeadMarkers` 규칙을 재사용(리드 쪽은 `leadMarkerCount > 800 || level >= 7`; 거래처는 **level ≥ 7만**).
- **숫자만 원**(`/^\d+$/` 분기)은 앞으로 **배송 순서 전용**.
- 유지: ✓ 오늘 배송완료 배지, 선택 강조(`outline`·`transform`·`zIndex`), M2b 번호 핀(`applyPinBadge`), z-index(`markerZIndex`/`overlayZIndex`), #770 위치 추정(`applyApproxBadge` ≈·점선·title).

### 설계
1. **`KakaoMapMarker`(components/kakao-address-map.tsx 맨 위 타입)에 선택 필드 2개**
   - `showName?: boolean` — 지도 화면의 거래처 마커만 true(코스·오늘 코스 등 다른 `KakaoAddressMap` 사용처는 그대로 원형).
   - `displayName?: string` — 알약에 찍을 상호(차량 보기에서는 `name`이 `배송차 · 상호`라 title 용이고, 알약에는 상호만 필요).
2. **`createMarkers`(components/sales-route-map-workspace.tsx, `^function createMarkers` ≈ 10499줄)**: 거래처 마커에 `showName: true`, `displayName: store.name` 추가. 지금 `label`은 등급 보기 = `store.grade`, 차량 보기 = `vehicle?.label || "?"`, `markerColor`는 차량 보기에서 차량 색. **`"?"` → 알약 배지에서 "미", title 은 "미배정"**, 숫자 라벨 → title `${label}호차`.
3. **`createMarkerOverlay(marker, compactLead = false)`(≈ 1710줄)에 3번째 인자 `compactCustomer = false`** 추가. 거래처 분기 순서:
   - `tone === "customer" && showName && !compactCustomer` → **알약**: `[배지(등급/차량번호/미)] displayName` — 배경은 `toneClass`(등급 색 `gradeStyle` 또는 `markerColor`), 흰 테두리, `max-width:160px; overflow:hidden; text-overflow:ellipsis; white-space:nowrap`, `completedBadge` 유지, 이름은 `escapeHtml`.
   - 그 밖의 거래처(축소·`showName` 없음)는 **지금 코드 그대로**: `/^\d+$/` 분기(원 30px) · `marker.grade` 분기(원 26px).
4. **오버레이 목록**: 리드가 `leadOverlayEntriesRef`(338/566/587/703줄)로 하는 것과 같게 `customerOverlayEntriesRef: Array<{ element, marker, overlay, approx }>` 추가. `placeMarkerAtPosition`(≈ 610줄)에서 `tone === "customer" && showName`이면 등록(`approx` 인자 값 함께), 지도 재생성 때(566줄 `leadOverlayEntriesRef.current = []` 자리) 비운다.
5. **줌 변경 처리(`onZoomChanged`, ≈ 700줄)**: 지금은 리드 쪽 변화가 없으면 `return`해 버리므로 **거래처 쪽을 먼저** 처리하도록 순서를 바꾼다.
   - `const nextCustomerCompact = map.getLevel() >= 7;` 가 바뀌었을 때만 모든 거래처 항목을 `createMarkerOverlay(entry.marker, false, nextCustomerCompact)`로 다시 만들어 `entry.overlay.setContent(el)`(오버레이·좌표·zIndex는 그대로).
   - **새 요소에 다시 붙일 것(빠뜨리기 쉬움)**: ① 클릭 리스너(`onMarkerClickRef`) ② `markerElementsRef.current.set(id, el)` ③ `applyPinBadge(el, pinNumbersRef.current?.get(id))` ④ `entry.approx`면 `applyApproxBadge(el)` ⑤ **선택 강조**: `highlightedElementRef.current === 옛 요소`이면 새 요소에 같은 `outline`·`outlineOffset`·`transform`·`zIndex`를 주고 ref를 새 요소로 교체 ⑥ 호버(`hoveredElementRef`)도 같은 방식(현재 호버 중이면 `setHoverStyle`).
   - 리드 쪽 기존 처리는 그대로 두고 그 뒤에 이어서 실행.

## 2. 47-2 ② 목록 순번 `RowNumber`

### 요구
지도 오른쪽 **거래처 / 신규 / 영업 목록**의 상호명 왼쪽에 순번. 공통 표 번호 칸 모양을 하나로 빼서 **표와 목록이 같이** 쓴다. **검색 결과 번호 핀(M2b)·오늘 코스 순서 번호는 그대로**.

### 설계
- 새 `components/ui/row-number.tsx`: `export function RowNumber({ value, className }: { value: number; className?: string })` → `<span className="text-right text-xs tabular-nums text-slate-400 …">{value}</span>`. 공통 표(`components/common-data-table.tsx` 465줄의 `<td className="sticky z-10 border-b border-slate-200 bg-inherit px-2 text-right text-xs tabular-nums text-slate-400" …>{rowNumber(currentPage, pageSize, rowOffset + rowIndex …)}</td>`)는 **`td`는 그대로 두고 안쪽 숫자만 `RowNumber`**로(셀 클래스·`left`·sticky는 표 쪽 책임). `rowNumber()` 계산 함수는 그대로.
- 순번 규칙(페이지 시작 + 오프셋)은 `rowNumber()`를 재사용; 지도 목록은 페이지가 없으므로 `index + 1`.
- 적용 위치: `StoreManagementPanel`(≈ 5879줄)·`LeadListPanel`(≈ 6090줄)의 행 렌더(상호명 왼쪽). 두 패널은 M4a에서 `map-side-panel.tsx`로 옮겨질 예정이므로 **순번은 행 마크업에 `RowNumber` 호출 한 줄만 추가**해 M4a 이동이 쉽게.
- 접근성: 순번은 장식이므로 `aria-hidden`이 아니라 읽혀도 무방(표 번호 칸도 그대로) — 표 쪽 기존 동작과 동일하게 둔다.
- 테스트: `RowNumber` 렌더(`renderToStaticMarkup`, tests/search-input.test.ts 방식) 1건 + 표/목록 e2e는 기존 것 유지. 새 e2e를 만들면 **`ci.yml` 674행 목록에 추가**.
