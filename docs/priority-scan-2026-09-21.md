1. **로그인 상태 표현 정정** — `자동 로그인`을 실제 동작에 맞는 `로그인 상태 유지`로 변경하고 기본 체크를 해제한다. 최근 로그인 이메일 힌트와 세션 유지 선택을 명확히 분리한다.
2. **직원 초대 가입 간소화** — 회사·직원 확인, 카카오 인증 버튼, 한 줄 안내만 남긴다. 반복 제목·단계 카드·중복 보안 설명을 제거한다.
3. **대기 상태 가시화** — 라우트 전환에는 `작업 진행 중`, 로그인 요청에는 `로그인 확인 중`, 카카오 이동에는 `카카오로 이동 중`을 표시한다.

## P1 — 다음 성능 라운드

1. **서버 응답시간 계측** — `/dashboard`, `/crm/timeline`, `/`, `/api/customers`의 서버 처리시간을 구간별로 기록해 DB 조회·직렬화·클라이언트 렌더 병목을 분리한다.
2. **지도 첫 화면 데이터 축소** — 첫 화면에 필요한 거래처 좌표·등급·담당자만 먼저 전달하고 첨부·메모·상세 정보는 선택 시 조회한다. **완료(2026-09-21):** 지도 홈을 `getCustomerMapSummaries` 경량 쿼리로 전환해 원장 상세·첨부·리뷰 컬럼을 초기 조회에서 제외했다.
3. **대형 지도 컴포넌트 추가 분리** — `sales-route-map-workspace.tsx`의 차량 관리, 거래처 상세, 코스, 히스토리를 독립 청크로 분리해 초기 JS 실행량을 줄인다.
4. **중복 조회 제거** — 같은 요청에서 회사 설정·거래처 마스터를 여러 화면 모듈이 반복 조회하지 않도록 request cache와 전용 경량 쿼리를 적용한다.

## P2 — 운영 안정성

1. 저장·업로드·거리 계산처럼 5초 이상 걸릴 수 있는 작업에 단계 문구와 경과 상태를 공통 적용한다.
2. 모든 주요 비동기 버튼에 중복 클릭 방지, 15초 타임아웃, 실패 단계 재시도를 통일한다.
3. 직원 초대 가입 완료 후 담당자·차량 매칭 결과를 한 화면에서 확인하고, 실패 시 관리자에게 바로 알린다.
4. 차량 마스터 ID를 직원 초대와 거래처 배정의 정식 참조키로 전환해 이름 변경 시 연결이 끊기지 않게 한다.

1. PC 로그인 화면의 회사 계정/직원 계정 구분을 탭 또는 단일 진입 선택으로 줄인다.
