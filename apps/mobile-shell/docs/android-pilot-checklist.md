# Android 파일럿 배포 체크리스트

## Play Console 신고 준비

- 백그라운드 위치 사용 목적: 근무 중 배송·영업 코스 진행과 차량 위치 공유
- 대표 기능 화면 및 `근무 시작 → 상시 알림 → 화면 끄기/내비 → 근무 종료` 시연 영상
- 권한 요청 직전 앱 내 고지, 개인정보처리방침 및 위치정보 이용약관 공개 URL
- 근무 종료 뒤 0건 전송, 12시간 자동 종료, 직원 본인 기록 조회·철회 증빙

## 파일럿 시험

1. 걷기 10분: 경로·정지 판정·정확도 확인
2. 차량 30분(화면 끔): 전송 간격과 누락 확인
3. TMAP/카카오내비 5분: WebView 대기 중 네이티브 전송 확인
4. 터널/비행기 모드: 로컬 대기 후 시간순 재전송, 중복 없음
5. 10분 정지: 60초 간격과 마커 고정 확인
6. 근무 종료·로그아웃: 이후 전송 0건
7. 배터리: 30분 전후 잔량으로 시간당 소모율 기록

## 배포 방식

- 1차: Firebase App Distribution의 내부 파일럿 그룹
- 2차: Play Console 내부 테스트 → 비공개 테스트 → 운영
- APK/AAB 서명 키는 저장소에 넣지 않고 CI 비밀 저장소에서 관리

네이티브 큐·제조사별 절전 대응이 부족하면 Transistorsoft 같은 유료 SDK를 별도 비용/라이선스 검토 후 비교합니다.
