# 위치정보 수집·이용 동의 문안 초안

## 직원에게 보여줄 짧은 안내

MAJU는 배송·영업 근무 중 차량 위치와 이동 경로를 회사 지도에 표시하기 위해 위치를 수집합니다.
`근무 시작`을 누른 뒤부터 `근무 종료`, 로그아웃 또는 12시간 자동 종료 전까지만 수집하며, 근무 밖 위치는 수집하지 않습니다.

- 수집 항목: 위도·경도, 정확도, 기록 시각, 속도·방향(기기 제공 시)
- 이용 목적: 오늘 코스 진행, 배송·영업 지원, 운행 기록 확인
- 보관 기간: 서버 개인정보처리방침에 명시된 기간(현재 설계 1년) 후 삭제
- 제공 범위: 소속 회사의 권한 있는 관리자와 업무 화면
- 철회: 앱의 `근무 종료` 또는 위치 동의 철회에서 언제든 중지

동의하지 않아도 계정과 일반 화면은 사용할 수 있으나 위치 기반 코스 진행 기능은 제한될 수 있습니다.

> 법무 검토 전 초안입니다. 개인정보처리방침과 위치정보 이용약관의 사업자 정보·보관 기간을 일치시킨 뒤 배포해야 합니다.
